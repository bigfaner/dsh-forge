# 等效证据口径：视觉件不可达时的替代取证

> 真机取证中视觉件（元素截图/状态徽标）不可稳定捕获时，以机械可验证断言为主证据，视觉件降级为等效证据留痕——不以视觉件强求（零 spec 改动纪律）。

## 证据分层

| 层 | 形态 | 要求 |
|---|---|---|
| 主证据 | DOM 锚存在性断言 + aria 断言 + 长时段持续采样读数 | 机械可验证、可复跑；e2e spec 全绿 |
| 等效证据 | 目标视觉形态以回放轨（回放驱动到目标状态）截图归档留痕 | 替代真机实时捕获，仅作场景留痕 |
| 场景留痕 | 真机实时截图（可得时） | 不作主证据 |

## 纪律

- 不以视觉件强求：主证据齐备即判定成立，不因截图不可达阻断走查。
- 分层写明：判定记录中主证据与等效证据分层列出，不得混写为单一证据。

## 判据（正反例）

- ✅ 徽标状态断言 = DOM 锚选择器 + 采样 N 次读数一致 + spec 断言全绿；视觉形态回放截图归档佐证。
- ❌ 因真机徽标闪烁不可截图而反复重试走查、或改 spec 迁就截图（零 spec 改动纪律破）。
- ❌ 只贴一张截图不加任何 DOM/aria 断言即判定通过。
