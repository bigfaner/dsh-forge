dsh-forge M1 桌面纯壳 — UI 原型

M1 仅设计 4 个壳级最小面;主窗口功能面 100% 继承上游 dsh GUI(本原型中以灰底占位窗口示意,不代表真实 GUI)。设计体系 = 上游 dsh tokens,右上角 ◐ 可切换亮暗主题。

UF1 系统托盘

关窗驻留、托盘菜单恢复/退出;左键聚焦与恢复行为;Linux 托盘创建失败静默降级。

UF2 系统通知

等待输入 / 回合完成两类通知;10 秒窗口按会话去重合并;权限被拒/DND 静默降级与托盘计数兜底;点击定位会话。

UF3 更新提示横幅

有更新 / 无更新 / 检测失败 / 已关闭四态;不自动消失、可关闭、Esc 可关(焦点在横幅内);跳转发布页。

UF4 宿主崩溃恢复覆盖层

显式状态机:崩溃提示 → 恢复中 → 完成 / 失败;mask + 对话框、focus trap、读屏播报;恢复完成后 toast 告知。
