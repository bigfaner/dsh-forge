# 5.2: UF4 崩溃恢复覆盖层组件

## Description
UF4 崩溃恢复覆盖层组件:状态机映射呈现、focus trap(Tab/Shift+Tab)、role=alertdialog/aria-modal/aria-live=assertive、Esc/mask 点击不关闭、失败态原因块(≤120 字符/max-height 96px)+ 重启按钮、恢复完成 toast、上游 Modal 几何(r24/w380/mask blur)。
