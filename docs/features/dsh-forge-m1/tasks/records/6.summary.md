1. host-exit recovery wiring lives in main/index.ts (bootHost single function: start→auth→carriage bind; retry-scheduled effect drives real restart; bootInFlight prevents double spawn) rather than a new module — closes the 5.gate carry-over.
2. Fake feed is an env seam (DSH_FORGE_RELEASE_FEED_URL) swapping only the feed source; openRelease allowlist stays build-time frozen; openExternal intercepted via main-process evaluate in e2e, no production seam added.
3. SC3 enumerates host children via OS process tables (win32 CIM / unix ps) filtered by host-entry.mjs command line; host pid self-written by the fixture host to a pid file.
4.
