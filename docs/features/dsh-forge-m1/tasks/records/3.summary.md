## 3. Key Decisions

1. webPreferences is a frozen exported constant so tests statically assert the security baseline and window code cannot relax it; webSecurity:true matches upstream deepseek-harness desktop exactly.
2. Supervisor spawn deps (spawnChild/resolveNode/hostEntryPath/timeouts) are injected for mock-subprocess unit tests; handshake accepts both 'ready' (vendored entry) and 'smoke-ready' (fixture) message types; real-subprocess integration test auto-skips when builtin Node is not acquired.
3. Shutdown ladder is fully time-bounded (shutdown msg -> SIGTERM -> SIGKILL -> resolve) so shutdown() can never hang and never leaves an orphan host; attempts counter feeds RecoveryContext.
4. dsh-app:// carriage reuses upstream privileges and authenticateWebHost/forwardWebRequest rather than reimplementing auth; carrier boot facts come from the host ready payload (url + injections), keeping the shell a pure carrier.
5. Single-instance claim is placed at module scope before whenReady; the whenReady body is guarded by ownership so the quitting second instance starts no profile/host lifecycle; focusShellWindow never touches window content so an active UF4 mask survives.
