## 3. Key Decisions

1. Overlay components are plain classic scripts exposing injectable factories (document/root/dshForge/matchMedia/copy) so vitest drives them with a mock bridge while vite concatenates them onto dist/shell-ui.js in document order; the onMount registry in shell-ui.js keeps auto-wiring ordered behind the upstream boot gate.
2. Renderer never owns state machines: UF3 banner phase is owned by main (tech-design Cross-Layer Data Map) and UF4 mirrors Interface 2; push to live webContents with silent drop when the window is missing/destroyed, plus getState pull for late mounts.
3. queued-while-mask ladder per ui-design: update-available during a recovery mask enqueues instead of showing; queued->shown fires when the mask exits via recovered; an already-shown banner stays shown underneath the z1200 mask.
4. SPEC CONTRADICTION (crash.restarting copy) resolved in 5.2 to the ui-design wording because ui-design is the Reference File for the renderer component, then codified in 5.3 by changing i18n copy.ts (zh/en) so all surfaces agree.
5. Dismissed is a run-level terminal latch (F4-D2): subsequent update-available pushes are ignored until next run.
