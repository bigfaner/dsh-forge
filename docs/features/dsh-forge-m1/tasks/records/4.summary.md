## 3. Key Decisions

1. Locale handling frozen per spike-3: read-once at init, no watching, no writes; t() leaves unknown placeholders verbatim and falls back to the key string at runtime; yaml dep matches the upstream settings-file parser.
2. Tray left-click delegates to focusShellWindow so single-instance, tray, session-focus, and notification-click all share one two-state focus/restore path; quit funnels through before-quit so residency never produces orphan hosts; tray icon is an embedded 16x16 RGBA PNG data URL (Electron rejects grayscale, no asset plumbing through the vite cjs bundle).
3. Update-checker has zero new dependencies (hand-rolled semver + regex atom parsing), reduces feed entries by max semver rather than trusting order, and enforces https + exact host + path-prefix boundary before any openExternal; GH owner/repo frozen in constants.ts for task 6.3.
4. Crash-recovery is a pure table-driven machine matching Interface 2's signature exactly; attempts stay owned by host-supervisor with setAttempts() mirroring; recovered->idle overlay edge left to wiring (no event in Interface 2); timer seam (setTimer/clearTimer) keeps backoff unit-testable.
5. Session-focus fallback is the only M1 path (channel code does not exist per spike-3 rejection); toast rides the same injection root as UF3/UF4 (__DSH_FORGE_SHELL__.onToast).
6. Notifier dedup merges via OsNotification.setBody in place; 'unknown' permission backfill persists for the run; reset() closes live notifications and zeroes dedup so recovery-period events are not swallowed by the pre-crash window.
7. IPC verbs resolve release URLs main-side from the last update check; restartApp uses app.exit(0) after explicit host shutdown, bypassing before-quit to avoid double-teardown; dismissed is a run-level terminal latch per F4-D2.
