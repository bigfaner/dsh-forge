# 4.2: MVP 门第一步：飞轮 6 步链端到端走查（dogfood 模型）

## Description

MVP 门第一步：飞轮端到端 6 步链（注册 → 会话 → 召回 → 事件 → tab → 热度）100% 不间断走查——e2e 底稿 + 人工走查双轨。会话链路用 dogfood 低成本真实模型（Open Question ② 裁决：dogfood 为主，录制回放仅 flake 时评估、不预建）。断言：agent 自主 `search` → `read-abstract` 多步检索链（agentic search，SC10）、会话系统提示词含知识段、事件↔tab↔热度三方一致。

## Acceptance Criteria

- [ ] 6 步链 e2e 底稿全绿：注册（两段式）→ 发起会话 → agent 召回（知识段指引）→ 事件落库 → 召回 tab 条目 → 卡片热度 +1，单流不间断
- [ ] agent 自主完成 `search` → `read-abstract` 多步链（真实模型轨迹可查——SC10 e2e 断言）
- [ ] 会话系统提示词含 `forge:knowledge` 段（内容断言：流程指引 + 工具说明在场）
- [ ] 事件表 ↔ 召回 tab ↔ 热度三方一致断言通过（场景⑥端到端）
- [ ] dogfood 策略执行记录：模型/成本/失败处置（flake 时评估录制回放，不预建）
