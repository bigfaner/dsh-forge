# 2.11: UF-4 会话面板三 tab（对话真实往返 / 轨迹最简台账 / 召回占位）

## Description

`apps/web/src/views/session/` 业务子模块：顶部三页签面板——**对话 tab**（官方 ui-chat / ui-conversation 复用，mount props 与数据源按 1.5 S2 清单，真实 dsh 会话往返经 `__DSH_TRANSPORT__` carrier）、**轨迹 tab**（最简台账：本轮消息与工具调用时序列表）、**知识召回 tab**（P1 占位空态「本会话暂无召回」，3.8 接线真实数据）。三 tab 切换不重置会话状态。

## Reference Files

- docs/features/dsh-forge-p1-mvp/prd/prd-ui-functions.md — UI Function 4（Placement / Data Requirements / States / Validation Rules）
- docs/proposals/dsh-forge-redesign/prototype/index.html — 会话面板与页签布局结构基准
- docs/features/dsh-forge-p1-mvp/design/tech-design.md — Integration: boot manifest 掌舵（官方 ui-* 复用）与 1.5 S2 清单产出

## Acceptance Criteria

- [ ] 新会话发起 + 消息发送完成一次真实 agent 往返，回答呈现于对话 tab（SC6①；dogfood 或注入通道自证）
- [ ] 打开既有会话转录完整呈现（恢复链路，SC6②）
- [ ] 轨迹 tab 时序台账与转录数据一致（消息/工具调用交错时序）
- [ ] 三 tab 切换不重置会话状态（草稿/滚动位置保持）
- [ ] 召回 tab 占位空态就位（文案 + 后续接线位）

## User Stories

- Story 2: 在原生工作台进行真实 dsh 会话（AC 1/2：真实往返 / 恢复转录）

## Hard Rules

- 官方件复用优先：对话面用官方 ui-chat/conversation，禁重造会话 UI；props 漂移由 G1 pin 池守（2.13）。

## Implementation Notes

- 文件清单：`apps/web/src/views/session/`（面板组装 + 三 tab 容器 + 轨迹台账行组件）。
- ui-chat mount props / 转录数据源严格按 1.5 S2 清单实现；若清单列残留，以最小可用面实现并在执行记录标注残留项。
