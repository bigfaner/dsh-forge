# 2.5: web/zones 三区骨架：视图互换（UF-5）+ dock 页签跟随（UF-7 机制）

## Description

`apps/web/src/zones/` 基础子模块（布局机制，无域内容）：三区容器（左 rail 常驻可收起 / 中区一等公民视图槽 / 右 dock 轨道默认收起归零）、视图态机 `workbench/session ⇄ workbench/knowledge` 整体互换（知识模式右栏强制隐藏、状态保留、切回恢复）、dock 页签集按项目跟随（可见集 = 当前项目 + 全局页签，切换不打断面板）。M0 知识面板以空态占位入槽。

## Acceptance Criteria

- [ ] 视图互换为整体切换：知识模式下右栏不可见（已展开也隐藏），切回按记忆恢复原展开态
- [ ] 切换零状态丢失：会话草稿 / 浏览上下文 / 右栏展开态在往返后保持
- [ ] dock 默认收起轨道归零，可展开为页签条 + 内容区（内容占位）
- [ ] 页签可见集 = 当前项目页签 + 全局页签；项目切换页签集切换且中区面板不打断，切回恢复
- [ ] zones/ 无域内容——槽位渲染接口就位，视图内容经槽位注入（组件单测 + 槽位契约自证）

## User Stories

- Story 2: 在原生工作台进行真实 dsh 会话（AC 3：视图/项目切换不丢状态）

## Hard Rules

- 样式纪律硬规则：令牌唯一（零裸值，`--dsw-*`）+ 官方件复用优先（rail/页签/抽屉形态对齐官方 sidebar/dockkit 模式，禁重造官方已有件）。

## Implementation Notes

- 文件清单：`apps/web/src/zones/`（容器、视图态机、槽位定义、dock 跟随逻辑）+ `shell/` 视图态机对接；不改 views/flows（尚不存在内容）。
- 断言锚点：UF-5/UF-7 Validation Rules 全部三条（知识模式右栏不可见 / 状态保留 / 可见集口径）。
