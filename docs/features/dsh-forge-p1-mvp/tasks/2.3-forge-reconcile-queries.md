# 2.3: core·forge 域：启动对账 reconcileAtStartup + 项目查询面

## Description

`reconcileAtStartup()`（交互三）：读全部 projects → 逐项 `registry.get(workspace_id)` 校验 path——失配按 ws_path `list()` 找回单向修引用；找不回 `create(ws_path)` 幂等重建修引用；`list()` ↔ projects 反查孤儿（dsh 有、应用无）只提示不自动删。加查询面 `listProjects`（archived 过滤口径）/ `getProject` / `updateProject`（name/archived patch）。关键异常降级 `app_key_logs`（scope=reconcile）永不抛断启动。

## Acceptance Criteria

- [ ] ws_path 失配 → 按 path 找回，单向修 workspace_id 引用 + `app_key_logs` 记账（结果入 data_json）
- [ ] 找不回 → `create(ws_path)` 幂等重建并修引用
- [ ] 孤儿发现（dsh 有、应用无）→ ReconcileReport 提示数据齐备，不自动删
- [ ] list/get/update 与 Interface 1 一致（archived 过滤口径、patch 仅 name/archived）
- [ ] 对账全程永不抛断启动流程（异常降级记账）
