# 2.9: UF-3 段二：RegisterForm 注册表单（回填/默认值/派生/联动）

## Description

`flows/add-project/` 段二注册表单（charter 定稿口径）：工作区目录只读回填（可「重新选择」重开浏览器）；项目名自动取文件夹名（可改）；字段自上而下 = 文档位置（forge 目录，默认 `<工作区>/.forge`）→ 知识库目录（默认 `<工作区>/.knowledge`；均可直输或「浏览…」经文件浏览器改选）→ 任务清单与记录（`{dsh-forge-home}/{canonical-path 扁平化}`，只读自动派生：`/`、`\` → `-`、盘符冒号去除）；仓内/仓外由 forge 目录是否位于工作区内自动推导（无 radio）；**换选工作区联动规则**：未手改字段随新工作区重构、手改或浏览选定过的字段保留；不设「默认召回域」字段。

## Acceptance Criteria

- [ ] 回填与默认值全对：工作区只读、项目名=文件夹名可改、forge 目录与知识库目录默认值、任务清单只读派生行
- [ ] 扁平化派生正确（`/`、`\` → `-`，盘符冒号去除；边界用例自证）
- [ ] 仓内/仓外推导正确（forge 目录是否位于工作区内），随字段变更即时更新
- [ ] 换选联动两分支正确：未手改字段随新工作区重构；手改或经「浏览…」选定过的字段保留
- [ ] forge 目录/知识库目录非法路径拦截于表单态（不出表单）
- [ ] 无「默认召回域」字段；提交按钮文案 =「确认」

## User Stories

- Story 1: 注册我的代码项目（AC 1：表单确认 forge 目录与知识库目录）

## Hard Rules
