# 3.3: core·知识域：浏览查询面 listEntries / getEntryDetail / sessionRecall

## Description

浏览侧查询面：`listEntries`（domainPrefix 前缀 + keyword 过滤 → KnowledgeCard[]，兼作域树聚合数据源）、`getEntryDetail`（含 Markdown 正文按需读取，与元数据分离）、`sessionRecall`（召回 tab 数据源：统计头 = 召回次数（COUNT(DISTINCT call_id)）+ 覆盖条数（去重命中）；分组行 = 条目快照展开 + 动词明细 + 最近时间 + 热度徽章数据）。`ctx.forgeKnowledge` 服务完整注册（service.ts 装配点收口）。

- docs/features/dsh-forge-p1-mvp/design/tech-design.md — Interface 2（listEntries/getEntryDetail/sessionRecall 签名与注释）

## Acceptance Criteria

- [ ] listEntries 过滤语义与 UF-6 一致（目录路径前缀 + 关键词组合；域树聚合数据可得）
- [ ] getEntryDetail 正文按需读取，元数据与正文分离返回（正文区不含 frontmatter——数据侧保证）
- [ ] sessionRecall 统计头口径正确（次数 = COUNT(DISTINCT call_id)；覆盖 = 去重命中条目）
- [ ] sessionRecall 分组行含快照展开（title_snap/domain_snap）+ 动词明细 + 最近时间 + 热度数据
- [ ] ctx.forgeKnowledge 双服务面完整（与 Interface 2 逐项对齐）

- Story 4: agent 自动召回知识并留下使用痕迹（召回 tab 数据源）
