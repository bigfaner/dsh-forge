# 3.4: knowledge 插件：召回 tool 双件 + forge:knowledge 系统提示词段

## Description

`packages/knowledge` dsh 插件：`tools/`——`knowledge.search` / `knowledge.read-abstract`（参数 schema 与 KnowledgeService 同构；projectId 由会话上下文解析；域前缀为可选参数，agent 自主选域，省略 = 全域）；`prompt/`——`ctx.systemPrompt.section({ name: 'forge:knowledge', order: 500, text })` 知识段（契约内容源渲染：知识库存在声明 + agentic search 流程指引（先 search 相应域、摘要先行、按需 read-abstract、与 grep/glob 同位自主编排）+ 两 tool 用法说明）；`index.ts` 装配（`inject: ['forgeKnowledge']`，仅服务类型依赖）。
