# 3.2: core·知识域：search / readAbstract 检索面 + knowledge_recall_logs + 热度

## Description

检索能力面：`search`（domainPrefix 可选省则全域 + keywords 细分 + limit；索引缓存直读，摘要先行 SearchHit）与 `readAbstract`（EntryAbstract 不含正文）。两动词均于执行点写 `knowledge_recall_logs`：一行 = 调用 × 命中条目、call_id 分组（uuid）、零命中写 entry_id=NULL 哨兵行、快照字段（title_snap/domain_snap/frontmatter_id）抗索引重建、query_json/hit_count/duration_ms 调用级字段。`heatByEntry` = 按条目 COUNT（哨兵行不计）。索引缺失/过期触发 ERR_INDEX_STALE（静默重建联动）。

## Acceptance Criteria

- [ ] 域前缀过滤正确：选「前端」域不返后端域条目（场景④）；省略 domainPrefix = 全域
- [ ] 关键词细分命中（keywords 匹配）；SearchHit 摘要先行（title/summary/domainPath/score）
- [ ] read-abstract 返回不含正文（场景⑤）；entryId 未命中抛 ERR_ENTRY_NOT_FOUND
- [ ] search 命中 N 条写 N 行（同 call_id 共享调用级字段 + 快照）；零命中写哨兵行（hit_count=0, entry_id=NULL）
- [ ] 热度 = 按条目 COUNT 且哨兵行不计（场景⑥数据侧；search 命中与 read-abstract 各计一次）
- [ ] 检索走索引缓存直读（零文件扫描——SC2 运行断言）

## User Stories

- Story 4: agent 自动召回知识并留下使用痕迹（AC 3：使用事件落状态层 + 热度）

## Hard Rules

- 禁 import `core/src/forge/**`；recall_logs 只经本域写入（append-only，不更新不删）。
- 知识目录不可达/非法 → ERR_INVALID_KNOWLEDGE_DIR，检索异常降级 app_key_logs（scope=recall，只记关键）。

## Implementation Notes

- 文件清单：`packages/core/src/knowledge/`（search/readAbstract/日志写入/热度聚合）；单测覆盖场景④⑤⑥数据侧 + 零命中/快照/幂等重查。
- duration_ms 记录于执行点（M7 trace 前置）；query_json 快照同 call 各行重复。
