# 2.7: ForgeSidebar（UF-1）：槽位路线 A 替换 + 项目树/会话列表实时读

## Description

产品 client 插件 `forge-sidebar`：`ctx.slots.inject('sidebar.workspaces', …, ForgeWorkspacePanel)` 槽位路线 A 替换官方 sidebar 壳的 workspaces 洞位。面板内容：品牌行（整块 = 新会话快捷）、新会话、知识库入口（视图切换）、项目树 + 会话列表（dsh 行语言：标题/状态点/相对时间；实时读 dsh 账本零缓存零副本）、设置占位（P1 最简）；可收起 56px rail（复用官方折叠机制）。

## Reference Files

- docs/features/dsh-forge-p1-mvp/prd/prd-ui-functions.md — UI Function 1: 左栏导航 rail（Placement new-page / Data Requirements / States / Validation Rules）
- docs/proposals/dsh-forge-redesign/prototype/index.html — 左栏布局结构基准（行语言/导航项/收起态）
- docs/features/dsh-forge-p1-mvp/design/tech-design.md — Integration: 产品 sidebar 替换 → 官方 ui-sidebar 壳（槽位路线 A）(ref: Integration Specs)
- docs/features/dsh-forge-p1-mvp/design/tech-design.md — Interface 4（forge:projects/list 通道）

## Acceptance Criteria

- [ ] 槽位替换生效：官方 sidebar 壳 workspaces 洞位被产品面板占用，壳级折叠/导航/快捷键行为继承可用
- [ ] 项目树读 `forge:projects/list`；会话列表实时读 dsh 账本（零缓存零副本——SC2 断言）
- [ ] 品牌行/新会话点击 → 中区切换会话视图并新建会话；知识库入口 → 切换知识视图（M0 空态占位）
- [ ] 收起态 56px rail 图标保留悬停提示；展开 ~240px
- [ ] 会话行点击打开对应会话且不重置中区其它视图状态；空态（无项目）引导指向 hero

## User Stories

- Story 1: 注册我的代码项目（AC 1：左栏出现项目与会话列表）
- Story 2: 在原生工作台进行真实 dsh 会话（左栏选择项目/会话）

## Hard Rules

- 样式纪律：令牌唯一 + 官方件复用（列表行语言对齐官方 sidebar 行形态，禁平行发明）。
- 会话列表只实时读取不落地副本（无投影纪律 SC2）。

## Implementation Notes

- 文件清单：`apps/web/src/views/`（或 flows 邻位）sidebar 面板组件 + 插件注册（slot inject）；行组件优先包官方件。
- 轨迹 tab/召回 tab 无涉（UF-4 范围）；「＋」入口开添加项目模态的接线在 2.10 组装。
