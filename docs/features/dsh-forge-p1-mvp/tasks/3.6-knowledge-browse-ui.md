# 3.6: UF-6 浏览主体：工具栏 + 域目录树 + 卡片网格（热度徽章）

## Description

`apps/web/src/views/knowledge/` 浏览主体（P1 唯一「浏览」页签）：工具栏（关键词搜索 + 范围显示——P1 项目级）、左轨域目录树（~224px，目录即域 ≤3 层，选择 = 前缀过滤条件）、auto-fill 多列卡片网格（frontmatter 驱动：标题/摘要/关键词/状态/时间 + HeatBadge 热度徽章）。状态：空库引导（说明目录位置）/ 加载中骨架 / 过滤无结果（清除过滤入口）。

## Acceptance Criteria

- [ ] 域树节点选择 → 网格按目录路径前缀过滤（e2e：选「前端」域网格不含后端域条目——场景④ UI 侧）
- [ ] 工具栏关键词进一步细分；组合过滤无结果时空结果提示 + 清除过滤入口
- [ ] 卡片字段 frontmatter 驱动 + 热度徽章 = 使用事件计数（与 heatByEntry 一致——断言）
- [ ] 空库引导（说明知识目录位置）与加载中骨架两态就位
- [ ] 索引直读首显不阻塞（缓存先行瞬时呈现，重建中骨架态）

## Hard Rules

- 样式纪律：令牌唯一 + 官方件复用（输入/工具栏件包官方）+ 自绘仅限领域组件（知识卡片/域树行）且吃令牌。
- 域过滤 = 目录路径前缀匹配，不得引入其它过滤语义。
