# 4.1: Windows 安装包管线（electron-builder NSIS + extraResources + sqlite prebuilds）

## Description

打包管线（Windows NSIS 单平台，SC-MVP 第二步载体）：`pnpm build` 全量拓扑构建（contracts → core → knowledge → bundle；web vite；host tsc）→ electron-builder：web dist + profile 模板资产 + 插件 bundle + host main → `extraResources`；better-sqlite3 用 Electron prebuilds（缺席 electron-rebuild 兜底）。dev/build 双 profile 形态收口（开发链 workspace 产物 vs 安装包资源）。

## Acceptance Criteria

- [ ] `pnpm build` 拓扑序全量构建零错（tsc -b + vite + 插件 bundle）
- [ ] NSIS 安装包产出，`extraResources` 含 profile 模板 + core/knowledge 插件 bundle + web dist
- [ ] better-sqlite3 在打包环境加载成功（prebuilds 命中或 electron-rebuild 兜底路径自证）
- [ ] 安装包形态首启落地 profile 幂等（1.4 行为在打包形态回归）
