# 2.8: UF-3 段一：DirectoryBrowser 文件浏览器（已注册标记 = 预检可视化）

## Description

`apps/web/src/flows/add-project/` 段一：本机目录文件浏览器——目录列举、单击选中、双击进入、面包屑跳转；**已注册目录行级「已注册」标记 = ownership 预检可视化**（数据 = `forge:projects/list` 的 ws_path 集合匹配；命中语义 = 挂接既有，后续不登记补偿）；「下一步」进入注册表单（未选中禁用）。

- docs/features/dsh-forge-p1-mvp/prd/prd-ui-functions.md — UI Function 3 段一（浏览器态 / Data Requirements / Validation Rules）

- docs/features/dsh-forge-p1-mvp/design/tech-design.md — Interface 1（ownership 预检语义：registry.list 按 canonical path 匹配）

## Acceptance Criteria

- [ ] 目录列举 + 双击进入子目录 + 面包屑跳转路径正确
- [ ] 已注册目录显示行级「已注册」标记（ws_path 匹配），标记命中项进入表单后走挂接语义
- [ ] 单击选中唯一；未选中时「下一步」禁用
- [ ] 不存在/不可达路径拦截（错误条，不出浏览器态）
- [ ] 形态对齐官方列表行/popover 语言，令牌唯一（令牌 lint 过）

## User Stories

- Story 1: 注册我的代码项目（AC 1 前半：经文件浏览器选定工作区目录）

## Hard Rules

- 本任务仅段一组件与目录数据获取（本机目录读取经 RPC 或既有 dsh 面，不自开 Node fs 通道于 renderer）。

## Implementation Notes

- 文件清单：`apps/web/src/flows/add-project/DirectoryBrowser.tsx` + 目录数据源封装 + 单测（含面包屑/选中/标记态）。
- 浏览器亦被段二「浏览…」改选复用（2.9），接口按可复用组件设计（选中回调 / 起始目录）。
