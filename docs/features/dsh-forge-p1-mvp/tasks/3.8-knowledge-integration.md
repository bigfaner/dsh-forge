# 3.8: M1 集成：知识视图填入 + UF-4 召回 tab 真实数据接线

## Description

M1 收口集成：① 知识库视图自 M0 空态占位填入浏览面（UF-6 主体 + 抽屉；UF-5 机制下右栏隐藏/恢复语义回归验证）；② UF-4「知识召回」tab 自占位接真实 `sessionRecall` 数据——统计头（召回次数/覆盖条数）+ 按知识分组行（动词明细/最近时间/HeatBadge 热度）+ 点分组行跳转知识详情抽屉（索引未命中行级失效标注，不阻塞列表）；③ 事件即时累积（发送新消息后再看 tab 更新）。

## Acceptance Criteria

- [ ] 知识视图整体切换呈现浏览面；知识模式下右栏隐藏/切回恢复语义依旧成立（UF-5 回归断言不褪色）
- [ ] 召回 tab 数据与事件表一致（场景⑥三方一致 e2e：事件 ↔ tab ↔ 热度）
- [ ] 分组行点击跳转对应知识详情抽屉；索引未命中行显示行级失效标注不阻塞列表
- [ ] 召回 tab 条目随会话事件即时累积（新消息触发召回后再看即更新）
- [ ] 无召回会话保持「本会话暂无召回」空态

## User Stories

- Story 4: agent 自动召回知识并留下使用痕迹（AC 3：tab 出现条目且与事件一致、热度 +1）
