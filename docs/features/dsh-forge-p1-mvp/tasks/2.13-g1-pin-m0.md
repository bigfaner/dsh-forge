# 2.13: G1 契约面 pin 池 M0 批（boot manifest / slot 洞名 / registry 语义 / profile 形状）

## Description

契约面 pin 回归池（vitest 常驻池）M0 批，pin 对象 = 上游精确 pin 版本 `0.2.0-rc.2`：① boot manifest 注入格式（`{url, injections}` + `applyIndexInjections`）；② `__DSH_TRANSPORT__` carrier；③ slot 洞名（`sidebar` / `sidebar.workspaces` / 子洞）与 injected props；④ `ctx.workspaceRegistry` API（create 幂等 / delete 保目录保日志 / get / list 语义）；⑧ dsh profile 目录形状（`loadProfileDirectory` / `runProfile` 签名——S1 实测回填）。附 1.5 S2 清单（ui-* props）逐项入池或显式记残留。
