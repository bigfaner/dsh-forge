# 2.10: UF-3 组装：两段模态流程（状态机 + 取消点语义 + 确认执行 + 反馈）

## Description

添加项目流程编排（Page Assembly，模态覆盖中区）：两段状态机（浏览器 ⇄ 表单，可返回上一步）；**取消点 = 两段对话框任一（返回上一步或直接关闭，均在 dsh create 之前）→ 干净退出零副作用**；「确认」→ `forge:projects/register` 接线，进入不可交互中断的执行态（进度指示）→ 成功反馈（自动关闭 + 左栏出现项目与会话列表 + hero 消退）/ 失败反馈（原因 + 补偿已执行说明）。入口：hero CTA（2.12 接线）与项目树「＋」。

## Acceptance Criteria

- [ ] 取消点干净退出：两段任一返回/关闭均未调用 dsh create，dsh 侧与应用侧零残留（e2e 断言 + 单测）
- [ ] 「确认」后流程不可交互中断（执行态进度指示），registerProject 一次性执行
- [ ] 成功：反馈呈现 + 自动关闭 + 左栏项目与会话列表出现（实时账本）+ hero 相位消退
- [ ] 失败：原因 + 补偿结果说明呈现（typed error code 映射文案）
- [ ] Esc/✕ 显式关闭路径（仅取消点窗口内可用）；浏览器⇄表单返回保留已填状态

## User Stories

- Story 1: 注册我的代码项目（AC 1/2：确认注册 / 取消干净退出）

## Hard Rules

- 取消语义是安全边界：任何取消路径不得触发 register 调用或补偿动作（与 core ④ 的"流程窗口内取消"分支边界对齐——UI 侧取消点全在 create 之前）。
