# 3.1: core·知识域：frontmatter 解析 + rebuildIndex 可重建索引

## Description

`packages/core/src/knowledge/` 业务子模块：项目级知识目录扫描（projects.knowledge_dir）、gray-matter frontmatter 最小契约解析（summary/keywords 必填、title 缺省 = 文件名去扩展名、status 默认 draft、id 存而不强求、authors/updated 展示位 updated 缺省取 mtime）、域 = 目录路径派生 ≤3 层、digest 内容摘要、`rebuildIndex(projectId)` 按需一次性整表事务重建（删旧插新），`IndexReport` 容错计数。解析容错：不合格条目不入索引不硬拒（M4 才拒收）。

## Acceptance Criteria

- [ ] 合法条目全字段入 `knowledge_entries`（含 title 缺省规则、updated 缺省 mtime、UK project+rel_path 不冲突）
- [ ] 容错口径：缺 summary/keywords 或域超 3 层的条目不入索引且 IndexReport 计数（title 缺省单独生效——仅 title 缺仍可入）
- [ ] rebuild 幂等：重跑零重复零漂移（事务内删旧插新）
- [ ] digest 变更检测可用：外部修改文件后 digest 变化可识别（场景⑦数据侧）
- [ ] rel_path 规范化 + 前缀校验（禁 `..` / 绝对路径 / 符号链接逃逸——负样例自证）

## User Stories

- Story 3: 浏览项目知识库（索引数据地基）

## Hard Rules

- 禁 import `core/src/forge/**`（域互禁铁律——为未来沉淀抽包保留边界）。
- 索引缓存不落知识目录（SC2 豁免口径：缓存只在应用库）。

## Implementation Notes

- 文件清单：`packages/core/src/knowledge/`（解析器 / 目录扫描 / 重建事务）+ 单测（合法/缺字段/超层/幂等/逃逸负样例——对应 Testing 行 knowledge 覆盖项）。
- 解析器消费 contracts frontmatter 常量（1.3），不重复定义契约。
