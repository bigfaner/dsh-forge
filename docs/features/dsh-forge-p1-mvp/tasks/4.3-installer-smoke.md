# 4.3: MVP 门第二步：Windows 安装包启动冒烟（4 步）

## Description

MVP 门第二步：安装包 4 步冒烟——安装 → 启动 → 主界面可达 → 会话面板可用。冒烟脚本化入 e2e 池可重复执行（对安装后应用跑 Playwright `_electron`/驱动断言）。

## Acceptance Criteria

- [ ] 安装零错（NSIS 安装过程无失败/回滚）
- [ ] 启动零错（安装后应用启动无崩溃/白屏）
- [ ] 主界面可达：三区结构最简断言（左 rail / 中区 / 右 dock 轨道）
- [ ] 会话面板可用：面板渲染 + 新建会话入口可操作
- [ ] 冒烟脚本入 e2e 池（G2 门可重复跑，非一次性手工验证）

## User Stories

- Story 2: 在原生工作台进行真实 dsh 会话（安装形态下的可用性下限）

## Hard Rules

- 冒烟在干净环境口径（无既有 {app-data} 依赖；首启落地 profile 路径被真实覆盖）。
