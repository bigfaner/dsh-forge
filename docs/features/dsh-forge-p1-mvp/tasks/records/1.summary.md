## Conventions Established
- 验证映射记录格式（1.3 立，1.4/1.5 沿用）：compile=tsc -b / fmt=N/A（仓库无 formatter/justfile——justfile 属旧线父目录，redesign 门为 pnpm 脚本）/ lint=pnpm lint / targeted=vitest / e2e=pnpm test:e2e / coverage=v8——每条任务记录把 AC 显式映射到证据
- 契约层零逻辑零依赖以 scope.test.ts 机械自证：非 test 源文件禁 function/箭头/class、import 仅包内相对路径
- 结构 pin 测试（tests/structure/）机械执行 AC 与 Hard Rule：host main 行数≤110 + import 白名单 + 四 barrel + 禁顶层 await whenReady；host src 零 @dsh-forge/{core,knowledge} import；web 壳/插件产物形状构建期 pin
- 负样例自证常驻化：lint-selftest.mjs 每次 G0 种植 _lintneg_* 样例→断言拦截与 message→finally 清扫——新增 lint 规则须同步种植负样例
- 令牌纪律：色/字/距/圆角全取 var(--dsw-*)，行级 dsw-raw 豁免；token-lint 入 G0
- e2e 纪律：跑前查无活跃 electron 实例（单实例锁，不杀用户实例，blocked 记录处置）；globalSetup 先 vite build 保 dist 确定性；真链路覆盖优先于单测 mock（boot/run.ts 与 shell/boot.ts 编排面由 e2e 覆盖，不追单测覆盖率）
- electron 二进制经 ELECTRON_MIRROR 手动补齐（pnpm 11 本机不执行安装脚本）；dev.mjs 守卫双条件（dist/main.js + path.txt），缺二进制时打印补齐命令
- 门入口固定：pnpm lint / test / test:e2e = G0 / G1+单测 / G2；pnpm dev = vite build --watch + tsc -b --watch + electron dev profile（守卫式，DSH_FORGE_DEV_PROFILE）
- spike 代码隔离于 spikes/ 并在 README 与文件头注声明不得演化为产品代码；运行时包集合变更须同步 runtime-packages.ts 清单与漂移守卫
- 基础子模块三类改动判据（缺陷修复 / 性能 / ≥2 消费方证据的新基础能力）与「基础变更」显式标注义务（tech-design §Monorepo 规范第 4 条）——后续任务发现「必须改基础才能完成」时，先挪业务落点而非扩基础面
