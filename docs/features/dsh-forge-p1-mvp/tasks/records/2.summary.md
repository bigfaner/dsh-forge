## Conventions Established
- 交互逻辑三层形制（2.5–2.10 立并沿用）：*-model.ts 纯状态机/推导 + *-actions.ts 转移面（setState 同形注入）+ 薄装配壳——SSR 直渲测不了交互，转移语义在动作级单测；后续新视图/流程必须同形（sidebar/browser/form/flow 先例）
- 页内全局缝家族 __DSH_FORGE_*__（VIEWS/WORKBENCH/ADD_PROJECT_FLOW）：跨求值单元解耦唯一通道；宿主缺席一律 fail-soft warn 不炸壳
- keep-alive 切换形制：面板互换/页签切换/流程相位回退 = 同位元素 hidden 属性（display:none）不卸载（zones 双面板、dock、SessionPanel 三 tab、repick 表单同型）
- dsw-raw 豁免口径（2.7 固化）：官方行语言 2/4/6/8px 内联刻度与特定缩进（官方主题无间距标尺令牌）可豁免，理由必须记录于任务记录——sidebar/browser/form/flow.css 先例
- 新 RPC 通道三处一体不变式（contracts → web/rpc → host）+ 结构 pin allowlist 数同步扩；renderer 永不开 Node fs 通道
- 记账纪律：成功路径一律不记 app_key_logs；仅失配找回/孤儿发现/补偿失败/对账降级 warn|error 单事件单条；关键异常永不抛断用户流程
- e2e 条件留痕形制（2.12/2.14）：前置缺口以 skip 门承载（可观测条件如 data-dswf-phase），断言语义零弱化，转正条件记台账——不留静默跳过
- 防漂移 pin 三件套：蓝本逐条匹配（schema.sql ↔ MIGRATIONS）、断言零删改台账（SMOKE-LEDGER.md 行号主键）、敏感性自证（改断言对象 → 红 → 还原 → 复绿）
- 结构 pin 持续扩展惯例：新模块面 + Hard Rule 机械执行（MarkdownText 直用禁令、components 零业务语义、zones 无域内容、workbench 装配）入 tests/structure/web-shell.test.ts
