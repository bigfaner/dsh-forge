# 2.12: 工作台 Page Assembly：三区装配 + hero 相位（UF-2）+ SC1 骨架断言起步

## Description

单页工作台组装（Page Composition「工作台（单页三区）」）：shell 入口 + zones 槽位装配（ForgeSidebar → 左栏槽 / SessionPanel → 中区会话视图 / 知识面板 M0 空态占位 → 知识视图槽 / dock 占位 → 右栏）；**hero 相位（UF-2）**：项目数 = 0 时中区呈现引导相位（价值一句话 + 「＋添加项目」CTA → 打开 UF-3），注册成功永久让位；视图态默认会话视图。SC1 骨架断言组起步（三区/互换/页签跟随最简集）。

## Acceptance Criteria

- [ ] 三区装配结构与原型布局一致（左 rail / 中区 / 右 dock；布局对照，视觉让官方）
- [ ] hero 相位：项目数 = 0 呈现、CTA 打开添加项目流程；首个项目注册成功后消退不残留
- [ ] 知识库入口 M0 空态占位呈现（机制已立，浏览面 M1 填入）
- [ ] SC1 骨架断言组起步可跑并全绿（三区/视图切换与页签跟随最简集，逐条对应 smoke-ui 骨架组）

## User Stories

- Story 1: 注册我的代码项目（AC 1：hero 起点与左栏项目出现）
- Story 2: 在原生工作台进行真实 dsh 会话（原生首屏成立）

## Hard Rules

- hero 仅由项目数驱动（单一条件），不得引入其它呈现条件；注册成功即永久让位。
