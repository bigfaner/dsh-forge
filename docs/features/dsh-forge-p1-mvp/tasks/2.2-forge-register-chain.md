# 2.2: core·forge 域：registerProject 四步补偿链 + ctx.forgeProjects 注册

## Description

`packages/core/src/forge/` 业务子模块：`registerProject(input)` 四步补偿链内聚——① `registry.list()` 按 canonical path 预检（命中=挂接既有，`attachedToExisting=true`，不登记补偿）→ ② `registry.create(wsPath)`（幂等）→ ③ 事务写 `projects` 行 → ④ ③失败或流程窗口内取消且属本次新建 → `registry.delete(workspaceId)` 补偿（保目录保会话日志，幂等）。含 `RegisterResult` 与 `ctx.forgeProjects` Cordis 服务注册（service.ts 装配点）。

## Acceptance Criteria

- [ ] 新建路径全链成功：dsh 工作区创建 + `projects` 行落库（workspace_id 外键、ws_path canonical 化）+ `attachedToExisting=false`
- [ ] 幂等命中（canonical path 命中既有工作区）→ 挂接不登记补偿；后续任一步失败**不删既有工作区**（ownership 保护）
- [ ] ③ 写入失败（模拟）→ ④ 补偿删除，dsh 侧零孤儿，目录与会话日志保留
- [ ] 补偿幂等：重复 `registry.delete` 为 no-op
- [ ] 补偿失败 → `app_key_logs` warn/error 记账（scope=compensation，单事件单条，结果入 data_json）+ 抛 typed `ERR_COMPENSATION`
- [ ] `registry.create` 失败 → `ERR_WORKSPACE_CREATE` 中止，无补偿需要
