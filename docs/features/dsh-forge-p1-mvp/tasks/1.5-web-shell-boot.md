# 1.5: apps/web 壳接入（boot manifest 消费 + carrier + S2 契约清点）

## Description

`apps/web/src/shell/` 基础子模块：自有 vite 入口（按官方 `apps/web` 母本模式）+ boot manifest 消费（`applyIndexInjections`）+ `__DSH_TRANSPORT__` carrier 承载 dsh 面 RPC + 视图态机骨架。同时承担 **S2 spike 清点**：官方 ui-chat / ui-conversation 的 mount props 与轨迹 tab 数据源契约逐项清点，回填 G1 pin 池清单第 5 项（关闭 Open Question ① 或列残留）。`styles/` 令牌引入仅 `--dsw-*`。
