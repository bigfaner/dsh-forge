- [ ] `pnpm install` + `tsc -b` 全拓扑零错（五工件 references 连通，contracts 零依赖）
- [ ] oxlint 编码三条依赖铁律：基础↛业务、core 内知识域↛forge 域、web 内 views/session↛views/knowledge——违规样例文件被 lint 拦截（负样例自证后删除）

- [ ] lint 规则禁 web/core 引入 fs.watch/chokidar 类监听回流依赖（SC2 机械面）
- [ ] `pnpm lint` / `pnpm test` / `pnpm test:e2e` 脚本就位，对应 G0 / G1+单测 / G2 门入口
