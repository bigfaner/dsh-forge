# dsh-forge P1（MVP）：走线架 + 知识飞轮第一圈 — UI Functions

> Requirements 层：定义 UI **要做什么**（HOW it looks 归 ui-design）。布局基准 = 第一版重构原型（`docs/proposals/dsh-forge-redesign/prototype/`）；视觉风格与 dsh 官方一致（令牌体系 + 官方基础组件复用）。P1 交付最小面：统计/召回日志页签、抽取 chip、阈值 chip、反馈按钮、元数据编辑均为后续里程碑（见各 UF 的 Notes）。

## UI Scope

单页三区工作台（左栏导航 rail / 中区一等公民视图 / 右栏 dock 容器）+ 首用 hero 空态 + 添加项目流程（文件浏览器 + 注册表单，两段模态）+ 知识详情抽屉（滑入层）。共 7 个 UI Function。

## Navigation Architecture

- **Platform**: web

### Primary Navigation (shared across pages)

单页工作台：主导航 = 左栏 rail（常驻）；中区视图互换为**同页视图态切换**（非路由跳转，状态保留）。

| # | Label | Target | Icon Keyword |
|---|-------|-------------|-------------|
| 1 | 品牌行（整块 = 新会话快捷） | 会话视图 · 新建会话 | brand |
| 2 | 新会话 | 会话视图 · 新建 dsh 会话 | message-plus |
| 3 | 知识库 | 知识库视图（浏览页签） | library |
| 4 | 项目树 + 会话列表 | 项目切换 / 会话打开（dsh 行语言） | tree-list |
| 5 | 设置 | 设置入口（P1 最简占位，可折叠组） | gear |

### Secondary Pages (navigated from a parent page)

| Page | Entry Point (UF# or action) | Return Target |
|------|-----------------------------|---------------|
| 添加项目（两段模态：文件浏览器 → 注册表单） | hero 空态 CTA（UF-2）/ 项目树「＋」 | 取消 / 关闭即回工作台（hero 或项目态）；表单可「重新选择 / 返回」浏览器上一步 |
| 知识详情抽屉（滑入层） | 卡片网格点卡片（UF-6） | Esc / ✕ 关闭回浏览上下文（保持） |

### Navigation Rules

- 主导航常驻左栏，可收起为 56px rail（UF-1）。
- 中区「会话 ⇄ 知识库」为整体视图互换：知识模式下右栏隐藏（已展开也隐藏），切回会话视图即恢复（UF-5）。
- dock 页签跟随所属项目：可见集 = 当前项目 + 全局页签，项目切换 → 页签集切换不打断面板（UF-7）。
- 模态与抽屉均有显式关闭路径（Esc / ✕），关闭返回入口上下文。

## UI Function 1: 左栏导航 rail

### Placement

- **Mode**: new-page
- **Target Page**: 工作台（单页应用首屏）
- **Position**: 左栏全高；展开态 ~240px，收起态 56px rail

### Description

常驻导航：品牌行（整块可点 = 新会话快捷）、新会话、知识库入口（P1 无待审核徽标——审核台 M4）、项目树 + 会话列表（dsh 行语言：标题/状态点/相对时间）、设置入口（P1 最简占位）。可收起/展开。

### User Interaction Flow

1. 用户点击品牌行或「新会话」→ 中区切换到会话视图并新建会话。
2. 点击「知识库」→ 中区整体切换为知识库视图。
3. 展开项目节点 → 显示该项目会话列表（实时读 dsh 账本）→ 点会话行 → 中区打开该会话。
4. 点收起按钮 → 左栏折叠为 56px rail（图标保留，悬停提示）。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 项目列表 | list | 应用状态层（projects 表） | 名称 / 归档态 |
| 会话头（标题 / 状态 / 相对时间） | list | dsh workspace 账本（实时读） | 零缓存零副本 |
| 当前项目 / 当前会话 | selection | 应用视图状态 | 高亮与页签跟随依据 |

### States

| State | Display | Trigger |
|-------|---------|---------|
| 空态（无项目） | rail + 引导指向 hero（UF-2） | 首用 |
| 会话加载中 | 行级骨架 | 账本查询进行时 |
| 会话列表空 | 项目下「暂无会话」占位 | 新注册项目 |
| 收起态 | 56px rail | 用户切换 |

### Validation Rules

- 项目/会话搜索过滤（P1 最简：前缀/子串匹配）不改变选中态。
- 会话行点击必须打开对应会话且不重置中区其它视图状态。

## UI Function 2: 首用 hero 空态

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 中区（无项目时的默认相位）
- **Position**: 中区居中

### Description

零项目时中区的引导相位：产品价值一句话 + 「＋添加项目」CTA。注册成功后此相位永久让位于会话视图。

### User Interaction Flow

1. 首次启动（无项目记录）→ 中区显示 hero。
2. 点击 CTA → 打开添加项目流程（UF-3）。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 是否存在项目 | boolean | 应用状态层 | 决定 hero 是否呈现 |

### States

| State | Display | Trigger |
|-------|---------|---------|
| hero | 引导文案 + CTA | 项目数 = 0 |
| （隐退） | 会话视图 | 首个项目注册成功 |

### Validation Rules

- hero 仅在项目数 = 0 时呈现；注册成功即消失，不残留。

## UI Function 3: 添加项目（文件浏览器 + 注册表单，两段式）

### Placement

- **Mode**: new-page
- **Target Page**: 添加项目（工作台上的两段模态流程：文件浏览器 → 注册表单）
- **Position**: 模态覆盖中区

### Description

两段式注册流程。**第一段·文件浏览器**：选定工作区目录——单击选中 / 双击进入 / 面包屑跳转；**已注册目录带「已注册」标记 = ownership 预检可视化**（命中 = 挂接既有，后续不登记补偿）。**第二段·注册表单**：工作区目录只读回填（可「重新选择」重开浏览器）；项目名自动取文件夹名；文档位置 = forge 目录（默认 `<工作区>/.forge`）与知识库目录（默认 `<工作区>/.knowledge`）自上而下排列，均可直接输入或点「浏览…」经文件浏览器改选；**任务清单与记录 = `{dsh-forge-home}/{canonical-path 扁平化}`**（`/`、`\` → `-`、盘符冒号去除；表单最下方只读自动派生）；仓内 / 仓外由 forge 目录是否位于工作区内自动推导（无 radio）。不设「默认召回域」字段。底部按钮「确认」→ 执行四步补偿链（① ownership 预检 → ② dsh create → ③ 应用库写入 → ④ 失败/取消补偿）。

> **目录选取形态注记（走查裁决 2026-10-03，fix-14）**：第一段目录选取**原生优先**——桌面载体在场 `__DSH_DIRECTORY_PICKER__` 桥（复用 dsh 官方契约，同形零 fork）时，第一段 =「选择工作区目录」按钮 → 系统 OS 目录对话框（盘符 / 快速访问 / 网络位置全操作系统原生）；表单「浏览…」「重新选择」三 target 同桥直选。**已注册标记口径迁移**：系统对话框无法行级标记 → 挂接语义改为**表单相位已注册提示**呈现（「已注册」chip + 挂接说明）；取消点语义与 canonical 对账口径不变。桥缺席（非 Electron 载体 / 单测 / e2e 回退口径 `DSH_FORGE_DIRECTORY_PICKER=off`）→ 回退内嵌文件浏览器（上述原文形态与「已注册」行级标记零变化——dsh 官方 native / -browse 双面同型哲学）。

### User Interaction Flow

1. hero 空态 CTA / 项目树「＋」→ 打开文件浏览器 → 浏览（双击进入 / 面包屑跳转）→ 单击选中目录（已注册目录显示标记）→「下一步」进入表单。
2. 表单自动回填：工作区目录只读、项目名 = 文件夹名、forge 目录与知识库目录取默认值、任务清单与记录派生显示。
3. 可直接改输入或点「浏览…」改选两目录；点「重新选择」重开浏览器换工作区——**联动规则**：换选工作区时未手改字段随新工作区重构，手改或浏览选定过的字段保留。
4. 「确认」→ 进入不可交互中断的注册执行（取消点已过）。
5. 成功 → 反馈 + 左栏出现项目与会话列表；失败 → 失败反馈（补偿已自动执行，dsh 侧无孤儿）。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 工作区目录 | path | 文件浏览器选定 | canonical path = 对账 join key；表单内只读回填 |
| 已注册标记 | boolean | ownership 预检（registry.list 按 path 匹配） | 浏览器行级标记；命中 = 挂接既有（不登记补偿）。原生选取形态（fix-14 注记）= 表单相位挂接提示承载 |
| 项目名 | string | 自动取文件夹名（可改） | 展示名 |
| 文档位置（forge 目录） | path | 默认 `<工作区>/.forge`；可直输 / 浏览改选 | 仓内 / 仓外自动推导；P1 仅采集，消费（文档 tab）M2 |
| 知识库目录 | path | 默认 `<工作区>/.knowledge`；可直输 / 浏览改选 | 仓外独立目录 |
| 任务清单与记录 | path（只读） | `{dsh-forge-home}/{canonical-path 扁平化}` 自动派生 | 展示未来任务数据位置；任务域 M2 |
| workspaceId | uuid | dsh registry（② 产出） | 应用库外键 |

### States

| State | Display | Trigger |
|-------|---------|---------|
| 浏览器态 | 目录列表 + 面包屑 + 已注册标记 + 选中态 | 流程打开 |
| 表单态 | 回填字段 + 只读派生行 + 联动 | 选定目录进入第二段 |
| 执行中 | 进度指示（不可中断） | 「确认」后 |
| 成功 | 成功反馈 + 自动关闭 | ③ 成功 |
| 失败 | 失败原因 + 补偿结果说明 | ③ 失败（④ 已执行） |

### Validation Rules

- 工作区目录必选且为存在的本地目录；forge 目录 / 知识库目录非法路径拦截于表单态。
- 取消点 = 两段对话框任一（返回上一步或直接关闭，均在 dsh create 之前）→ 干净退出，无任何 dsh / 应用侧副作用。
- 「确认」后流程不可交互中断；失败自动走补偿（SC12）。

## UI Function 4: 中区会话面板（对话 / 轨迹 / 知识召回）

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 中区（会话视图态）
- **Position**: 中区全宽，顶部三页签

### Description

真实 dsh 会话面板：**对话 tab**（消息往返，官方会话组件复用）、**轨迹 tab**（最简台账：本轮消息与工具调用时序列表）、**知识召回 tab**（最简列表：统计头——召回次数/覆盖条数 + 按知识分组行——动词明细/最近时间/热度徽章）。

### User Interaction Flow

1. 用户在对话 tab 发送消息 → agent 往返（含 agentic search 检索链）→ 回答呈现。
2. 切「轨迹」tab → 查看消息/工具调用台账。
3. 切「知识召回」tab → 查看本会话召回的知识分组行；点分组行 → 跳转知识详情抽屉（UF-6）。
4. 发送新消息后再查看 → 事件即时累积。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 会话转录（消息/工具调用） | stream | dsh 会话域 | 恢复会话时完整呈现 |
| 召回统计（次数/覆盖条数） | aggregate | 应用状态层（使用事件） | 与热度同源 |
| 知识分组行（知识 id/标题/动词/最近时间/热度） | list | 使用事件 ⨝ 知识索引 | P1 无反馈按钮与会话沉淀（M7/M4） |

### States

| State | Display | Trigger |
|-------|---------|---------|
| 空会话 | 引导输入 | 新建会话 |
| 加载/恢复中 | 骨架 | 打开既有会话 |
| 无召回 | 「本会话暂无召回」占位 | 会话未发生召回 |
| 有召回 | 分组行列表 | 事件累积 |

### Validation Rules

- 三页签切换不重置会话状态；召回 tab 数据必须与事件表一致（断言）。
- 知识召回 tab 条目点击必须能打开对应知识详情（索引未命中时行级失效标注，不阻塞列表）。

## UI Function 5: 中区视图互换（会话 ⇄ 知识库）

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 中区视图态机制
- **Position**: 中区整体（含右栏联动）

### Description

中区一等公民视图整体切换：会话视图 ⇄ 知识库视图。知识模式下右栏隐藏（已展开也隐藏）、状态保留，切回会话视图即恢复。M0 以知识面板空态占位建立机制，M1 填入浏览最小面（UF-6）。

### User Interaction Flow

1. 左栏点「知识库」→ 中区整体切换为知识库视图，右栏隐藏（状态保留）。
2. 再次点「新会话」/会话行/品牌行 → 切回会话视图，右栏按记忆恢复。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 当前视图态 | enum | 应用视图状态 | 会话 / 知识 |
| 右栏记忆态 | snapshot | 应用视图状态 | 隐藏期间保留 |

### States

| State | Display | Trigger |
|-------|---------|---------|
| 会话视图 | 会话面板（UF-4） | 默认 |
| 知识视图 | 知识面板（UF-6） | 知识库入口 |
| 知识空态（M0） | 占位说明 | M1 之前 |

### Validation Rules

- 互换为整体切换，不得出现知识模式下右栏可见的状态（走查断言组）。
- 切换不得丢失任一侧状态（会话草稿 / 浏览上下文 / 右栏展开态）。

## UI Function 6: 知识库浏览（工具栏 / 域树 / 卡片网格 / 详情抽屉）

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 中区（知识库视图态 · 浏览页签，P1 唯一页签）
- **Position**: 工具栏（顶部）+ 左轨域目录树（~224px）+ auto-fill 卡片网格（主体）+ 详情抽屉（右侧滑入）

### Description

知识浏览最小面：工具栏（关键词搜索 + 范围显示——P1 项目级）、左轨域目录树（目录即域 ≤3 层，域由路径派生）、auto-fill 多列卡片网格（frontmatter 驱动：标题/摘要/关键词/状态/时间 + 热度徽章）、知识详情抽屉（摘要块 + 两列元数据 + Markdown 正文，统一包装渲染）。P1 不含：状态 chips 阈值（M4/M5）、「从会话抽取」chip（M4）、统计分析与召回日志页签（M7/M8）、元数据编辑对话框（M6）。

### User Interaction Flow

1. 进入知识库视图 → 呈现当前项目知识的卡片网格（索引直读）。
2. 点域树节点 → 网格按目录路径前缀过滤；工具栏输入关键词 → 进一步细分。
3. 点卡片 → 右侧滑入详情抽屉（浏览上下文保持）；Esc/✕ 关闭回网格。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 域树 | tree | 知识索引（目录路径派生） | ≤3 层；选择 = 前缀过滤条件 |
| 卡片字段（标题/摘要/关键词/状态/时间） | frontmatter | 知识索引 | frontmatter 驱动 |
| 热度 | count | 使用事件聚合 | 与事件计数一致（断言） |
| 正文 | markdown | 知识文件（按需读取） | 统一包装渲染，variant = body；正文区不含 frontmatter |

### States

| State | Display | Trigger |
|-------|---------|---------|
| 空库 | 「尚无知识」引导（说明目录位置） | 知识目录为空 |
| 加载中 | 网格骨架 | 索引重建进行时（缓存先行则瞬时） |
| 过滤无结果 | 空结果提示 + 清除过滤入口 | 组合过滤无命中 |
| 索引失效 | 静默重建（P1 无对账横幅，M6） | 外部修改后进面板 |

### Validation Rules

- 域过滤 = 目录路径前缀匹配（选「前端」域不得出现后端域条目——e2e 断言）。
- 详情抽屉正文区不得混入 frontmatter 字段（e2e 断言）。
- 热度数字必须等于使用事件计数（断言）。

## UI Function 7: 右栏 dock 容器（默认收起 + 页签跟随最简版）

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 右栏
- **Position**: 右侧轨道，默认收起（轨道归零）

### Description

dock 页签容器：默认收起；页签记录所属项目，可见集 = 当前项目 + 全局页签，项目切换 → 页签集切换（不打断面板，切回即恢复）。P1 为机制最简版：页签内容以占位为主（知识文档/审核台/文档页签均属后续里程碑），机制与跟随行为先行。

### User Interaction Flow

1. 用户展开 dock → 显示当前项目可见页签集。
2. 切换项目 → 页签集切换，中区面板不打断。
3. 切回原项目 → 原页签集恢复（含展开状态）。

### Data Requirements

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| 页签集（按项目） | map | 应用视图状态 | 全局页签常驻可见 |
| 展开态 | boolean | 应用视图状态 | 知识模式下强制隐藏（UF-5 联动） |

### States

| State | Display | Trigger |
|-------|---------|---------|
| 收起（默认） | 轨道归零 | 默认 |
| 展开 | 页签条 + 内容区 | 用户展开 |
| 强制隐藏 | 不可见（状态保留） | 知识视图态 |

### Validation Rules

- 知识视图下 dock 必须不可见（即使此前展开）；切回即恢复原展开态（断言）。
- 项目切换后可见集必须且只含当前项目页签 + 全局页签（断言）。

## Page Composition
