## Description

## Acceptance Criteria

- [ ] 标题栏 = 项目名 + 概要信息区常显(工作区/代码区路径超长省略 + title 全称;活跃 feature · 任务 done/total · 运行中 N;随数据实时,不随子 tab 切换变化)。
