# 4.2: 壳层 windows/:窗口注册表 + windowOpenDetached/GetRole/Recall 动词组 + 每窗事件 fan-out/carriage 泛化

## Description

Interface 5(T5 裁决:主进程 window-role 握手,不走 URL hash):新建 `apps/desktop/src/main/windows/`——窗口注册表(主窗 + detached 集)、`windowOpenDetached`(第二 BrowserWindow 同源 SPA 重载;首窗 960×640 居中)/`windowGetRole`(新窗 boot 经 preload verb 查询,typed 握手)/`windowRecall`(收回;OS 标题栏关闭 ≡ 收回);`dsh-forge:window-changed` 事件(detached-opened/closed);事件推送按 webContents fan-out(订阅登记逐窗,destroyed 自动退订);carriage/WS 改写逐 webContents 注册;单实例与 M1 壳行为对账(主窗关闭 = 退出,detached 随之关闭)。

## Acceptance Criteria

- [ ] 窗口注册表:主窗 + detached 集(增删查);`windowOpenDetached` 建窗(同源 SPA 重载;标题「<项目名> · <视图名>」)返回 windowId;首窗 960×640 居中主窗,此后记忆尺寸/位置。
- [ ] windowGetRole:新窗 boot 经 preload 查询(typed;不走 URL hash);`windowRecall(windowId)` 收回;OS 标题栏关闭 ≡ recall 同语义(事件兜底);windowId 失效 → ERR_WINDOW_NOT_FOUND。
- [ ] 事件泛化:workbench/window 事件按 webContents fan-out(订阅登记逐窗;destroyed 自动退订);carriage/WS 改写逐 webContents 注册(detached 窗内 verb/事件链路可用)。
- [ ] 安全:新窗同 `SHELL_WEB_PREFERENCES`(contextIsolation/sandbox);will-navigate 锁 `dsh-app:`;window-open 拒;role 不信任 URL。
- [ ] 单实例对账:主窗关闭 = 退出应用(detached 随之关闭);托盘/单实例锁行为零变更(M1 语义);开窗失败 → ERR_WINDOW_OPEN_FAILED toast/log。
