# 1.5: C7 组件:添加项目确认卡(证据三档文档位置预览行 + 黏性禁令 + 授权收窄 + 子仓 chips + 已注册快车道)

## Description

C7 添加项目确认卡组件层(Dialog r24,mock 侦测动词独立构建):代码区唯一输入位(拖拽/粘贴/浏览;剥引号/拒裸盘符与相对路径)+ 侦测行(信息陈述,非错误码)+ 项目名(自动取文件夹名,✎ 可改)+ 文档位置预览行(证据三档预选,✎ 展开才见模式+路径)+ 留痕灰字 + 高级折叠(自定义路径,仓外显式授权)。状态机六态:valid/registered/nogit(信息态)/missing/parent/custom-outside。

## Acceptance Criteria

- [ ] 状态机六态(mock DetectReport 驱动):valid(侦测陈述+预览行可添加)/ registered(「已注册项目」+ 禁用)/ nogit(「未检测到 git — 文档将由应用管理」信息态非错误)/ missing(路径不存在+禁用)/ parent(直接子目录 ≥2 .git 子仓 chips 一键选定)/ custom-outside(高级折叠内授权行)。
- [ ] 文档位置预览行三档证据门控:命中仓内 forge 树 = 沿用仓内 / 有 .git = 仓内新建 `<root>\docs`(懒物化)/ 无 .git = 应用管理主路径;✎ 展开才见模式+路径(默认收起)。
- [ ] 黏性禁令:换路径预选重估(手动选择清零/自定义清空/授权复位),仓内落点永不继承(无跨项目黏性)。
- [ ] 硬校验两条 + enabled 条件 = 存在 ∧ 未注册 ∧ 名称非空 ∧ 自定义已授权;提交失败留在卡内修正不静默;[添加项目] 成功 toast(含落位模式)原位生效。
- [ ] 高级折叠:仓外(⊄ 代码区)自定义路径 → 显式授权行(授权复位随换路径);留痕灰字「过程留痕 · 应用数据目录(本机,不进 git)」。
- [ ] vitest + jsdom 状态机主路径:证据重估矩阵/黏性禁令/授权复位/已注册快车道。

## Hard Rules

- 零 git 强制:无 .git 目录为一等公民,任何流程不得以「先 git init」为前置;`ERR_FORGE_NOT_DETECTED` 不得复现(废止)。
- 知识区不上卡(M4 不渲染);词汇统一「添加项目 / 文档位置」。
