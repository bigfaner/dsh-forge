# 4.5: 布局记忆引擎:ProjectLayout 采集(sidebar/tree/rightbar panes/detached)+ 恢复重放 + debounce 写入 + 删除清除

## Description

T4 布局记忆全链:client 布局引擎采集 ProjectLayout v1(sidebar 宽/收起、tree expandedProjects/expandedSessions/overflowOpen、rightbar widthPct/panes·tabs、detached 窗口集)→ debounce → setProjectUiState;恢复 = 重进项目时重放 open 操作序列(openTab/openResource/setWidth);detached 窗口集恢复(重进恢复拆出态);项目删除 → FK cascade 清除 + 拆出窗关闭联动;分组×排序视图选项留 localStorage(用户级,不入 blob)。

## Acceptance Criteria

- [ ] 采集:sidebar(宽/收起)/ tree(展开/收起/溢出)/ rightbar(widthPct/panes·tabs 结构)/ detached(窗口集)→ ProjectLayout v1;写入 debounce(不为每次拖动即时写)。
- [ ] 恢复:重进项目重放 open 操作序列(pane 结构/比例/收起态/detached 集复原);恢复态 = 离开前布局(SC4 断言口径)。
- [ ] 边界:恢复重放仅 forge 所属操作;原生 rightbar 自身持久化(会话域)不动(粒度不同双轨不冲突);恢复失败 → 默认布局(4.1 校验兜底)。
- [ ] 删除清除:项目删除 → project_ui_state FK cascade + 拆出窗关闭(4.3 联动)e2e 断言口径成立。
- [ ] 视图选项(分组×排序)= localStorage,不进 blob(边界断言:blob 内无该字段)。
- [ ] vitest:采集矩阵/重放序列/debounce/删除清除。
