# 1.3: IPC 动词面 v3·P1 批:probeProjectPath/registerProject + 生命周期五动词 + project_list_changed 事件 + allowlist 漂移

## Description

`dshForge.workbench.*` 白名单扩展(P1 批):侦测动词 `probeProjectPath`(消费 1.2 DetectReport)、注册动词 `registerProject`(v2 入参:anchor/displayName/docsPlacement 四值/customAuthorized;BEGIN IMMEDIATE;成功 → 投影期望 push 事件占位)与生命周期动词 `renameProject/archiveProject/restoreProject/removeProject/listProjects`;事件 `project_list_changed` 挂 `dsh-forge:workbench-events` 批量通道。channel-allowlist 双份常量 + 漂移测试延续(electron-ipc-security)。

## Acceptance Criteria

- [ ] 七动词注册齐全(probe/register/rename/archive/restore/remove/list)+ channel-allowlist 双份常量同步,漂移测试全绿;通道命名 `dsh-forge:workbench-<kebab-verb>`。
- [ ] registerProject 硬校验仅 2 条:存在+目录+可读(1.2 侦测)、跨项目唯一(三层比对);docsPlacement 四值 + repo-new/custom 必填 docsPath、custom 必填 customAuthorized=true;BEGIN IMMEDIATE 事务;成功发 `project_list_changed`。
- [ ] 生命周期语义:rename 纯 DB 零 fs;archive/restore 仅 archived 位(dsh 侧不动);remove = DB 删除 + FK cascade(投影 delete 与拆出窗关闭钩子分别在 3.x/4.x 层叠扩展,本任务留 hook 注记);list 返回 v3 扩展列(archived/sortOrder/projectionState/docsPlacement)。
- [ ] 错误码面:ERR_PROJECT_EXISTS(命中 → 已注册快车道 payload)、ERR_CODE_ROOT_UNREADABLE、ERR_PROJECT_NOT_FOUND 按设计触发;动词不因投影失败 reject(投影事件占位,3.x 接线)。
- [ ] 事件通道:`project_list_changed` 经 `dsh-forge:workbench-events` 批量(≤500ms)。
- [ ] vitest 动词矩阵:注册成功/已注册快车道/不可读/非法 docsPlacement/未授权 custom/生命周期四操作流转/list 扩展列。
