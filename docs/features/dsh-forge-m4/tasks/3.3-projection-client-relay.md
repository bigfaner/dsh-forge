## Description

## Acceptance Criteria

- [ ] WorkspaceChannel 声明:create/rename/delete(幂等)/insertBefore 四动词 duck-typed 结构面;契约漂移防护 = 声明对齐 vendored types.ts(编译期形状)。
- [ ] relay 流:订阅 `projection_push_required` → 按 plan 顺序执行(ensure(sort_order 升序)→ rename → reorder(insertBefore 链)→ delete)→ 逐项目 reportProjectionOutcome 回填。
- [ ] 错误映射:上游 `workspace/invalid-path`/`name-conflict`/`move-invalid` → ERR_PROJECTION_OP_FAILED(detail 携原码);单 op 失败不断流中止整个 plan 的状态回填(部分成功语义按 diff 幂等重推收敛)。
- [ ] follow 快照上报:订阅原生 workspace 快照流 → submitWorkspaceSnapshot(debounce;形状按入参契约);启动即上报一次(存量 pending 收数)。
- [ ] relay 生命周期:渲染未装载/启动竞态 = 不消费(内核 plan 保留);装载后拉取待推 plan 重放。
- [ ] vitest:plan 执行序矩阵(mock channel)/错误映射/outcome 回填/follow 上报 debounce。
