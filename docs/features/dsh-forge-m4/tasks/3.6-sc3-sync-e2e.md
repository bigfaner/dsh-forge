# 3.6: SC3 e2e·同步语义腿:注册同名同序 / 改名同步 / 归档保留 + forge 归档分区 / 删除移除 + 会话退未分组 / 派发归组

## Description

SC3 前半(同步语义)e2e 腿:注册后 dsh 侧存在同名条目且顺序一致(实况 workspace 快照断言);改名同步;归档 = workspace 保留 + forge 侧归档分区;删除 = workspace 移除 + 会话退未分组(历史不删除);派发会话在 dsh 原生 UI 归组正确。

## Acceptance Criteria

- [ ] 注册同名同序:多项目注册后实况 workspace 快照 = forge 项目列表同名且顺序一致(sort_order 权威断言)。
- [ ] 改名同步:forge 改名 → dsh 侧 workspace 同名(必答⑤ 第三行)。
- [ ] 归档语义:归档 → dsh 侧 workspace 保留 + 会话仍按项目分组;forge 侧项目入归档分区且项目会话列表不再展示。
- [ ] 删除语义:删除 → dsh 侧 workspace 移除;会话退未分组且历史不删除(会话文件仍在)。
- [ ] 派发归组:派发会话(cwd=anchor)在 dsh 原生 UI 归组到对应 workspace(DF002 断言)。
- [ ] 全量 e2e 前单实例锁纪律;SC3 同步腿全绿。

## User Stories

- Story 4: 注册即归组(SC3 注册/归组验收)
- Story 5: 归档不丢历史、改名不丢归档(SC3 生命周期验收)

## Hard Rules

- 实况断言 = dsh 侧 workspace 快照(非 forge 侧状态行);「不回流」断言归 3.7。
