# 2.4: 文档 tab + 依赖图 tab(slug/产物名 · 只读正文;DAG/泳道双模式,feature 下拉仅本项目)

## Description

右栏两种内容 tab:①文档 tab(概览目录树点文档名打开;tab 名 = `slug/产物名称`(目录树条目名,含子目录);路径栏 h38 + ↻ 重新读取 + 只读正文;仅当前项目文档,项目切换即关闭;可多开)②依赖图 tab(任务子 tab 唯一 [依赖图] 按钮打开;头部 feature 名即下拉(仅本项目 feature + 状态徽标 pill)+ DAG/泳道双模式分段钮;节点卡点击开任务抽屉;依赖边由任务 deps 结构化解析)。

## Acceptance Criteria

- [ ] 文档 tab:tab 名 = `slug/产物名称`(title = 全路径);路径栏 h38(路径小字 + ↻ 重新读取);只读正文渲染;仅当前项目目录树来源;可多开、重复打开激活既有。
- [ ] 依赖图 tab:DAG 模式(SVG 箭头连线 + 绝对定位节点卡,blocker 在左,列宽 200/间距 24)与泳道图模式(状态七态横向列,列头 = 状态点+名称+计数,空列「无此状态任务」)分段钮切换,模式随会话保留。
- [ ] feature 名即下拉:可选项仅本项目 feature,名称旁状态徽标 pill(状态 + done/total)。
- [ ] 节点卡两模式复用(状态点/标题/ID/「会话中」pill),点击均开任务详情 dock;依赖边由任务 deps 字符串结构化解析(同 feature 前置)。
- [ ] 联动:项目切换 → 文档/依赖图 tab 随切换关闭(2.2 联动规则消费验证)。
- [ ] vitest + jsdom:文档多开/激活既有、DAG 边解析、泳道七态分组、下拉过滤本项目。

## User Stories
