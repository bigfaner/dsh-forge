# 3.2: 投影 IPC 动词 + 对账 service:retry/getStatus/submitSnapshot/reportOutcome + projection_push_required/updated 事件

## Description

投影动词面(Interface 1 P3 批)+ 对账 service:`retryProjection`(幂等全量重推)/`getProjectionStatus`(状态行 + 偏差明细)/`submitWorkspaceSnapshot`(client 上报原生 workspace 快照,形状校验 + debounce)/`reportProjectionOutcome`(relay 回填 ok/error);事件 `projection_push_required { projectId, plan }`(relay 消费)与 `projection_updated { projectId, state, deviations? }` 挂批量通道。对账 = snapshot → 3.1 diff → 状态迁移(healthy/deviation);relay 不在场 → plan 保留(期望在库)禁静默丢弃。

## Acceptance Criteria

- [ ] 四动词注册 + allowlist 双份常量同步 + 漂移测试全绿;事件 `projection_push_required`/`projection_updated` 经批量通道(≤500ms)。

- [ ] relay 不在场(渲染未装载/启动竞态):plan 保留(期望在库)+ degraded(ERR_PROJECTION_CHANNEL_UNAVAILABLE,重试一次后);retryProjection = 幂等全量重推;禁静默丢弃。
