# 2.9: SC7 e2e 腿 + subagent 血缘语料 stub 扩展(parentSession/origin 头注入)+ 命名遵循率固定桩

## Description

SC7(任务↔会话反查)e2e 腿:subagent 血缘语料 = 会话 stub 协议扩展 `parentSession`/`origin` 头注入(真核心消费,journal 对拍);SC7 断言族——挂接历史呈现(active/ended 新→旧)/执行 subagent 标识(命名 + 血缘)/任务 → 顶层与 subagent 会话打开(1 次点击)/归拢不顶层 + 默认收起/C6 元数据条/命名遵循率(固定桩验证)。

## Acceptance Criteria

- [ ] stub 协议扩展:会话 stub 支持 `parentSession`/`origin` 头注入,真核心消费(非 mock 旁路),journal 对拍一致;能力核对项(Open Question)在实现前验证。
- [ ] SC7-挂接历史:任务详情呈现挂接历史(active/ended 新→旧);行展开血缘后代;[打开] 双通道断言。
- [ ] SC7-归拢:subagent 会话不出现在项目会话列表顶层、归拢于 parent 血缘树下且默认收起(e2e 断言)。
- [ ] SC7-元数据:subagent 会话视图展示所执行任务元数据(任务号/标题/状态);点击回任务详情(双向)。
- [ ] SC7-命名遵循率:固定桩验证(执行 subagent 以「任务 id + title」命名;e2e 以桩会话名断言,非真实 agent 执行)。
- [ ] 全量 e2e 前单实例锁纪律;SC7 腿全绿。

## User Stories

- Story 2: 从任务直达执行会话(SC7 全量验收)
- Story 7: 执行 agent 的任务身份可见(命名遵循率 + 双侧识别)

## Hard Rules

- 血缘为准断言:命名与血缘冲突语料(手工改名桩)→ 展示以血缘为准。

## Implementation Notes

- 文件清单:`tests/e2e/specs/m4/sc7-task-session-trace.spec.ts`(新)、stub 协议扩展落 `apps/desktop/e2e/fixtures/` 或共享 stub 模块(就近既有协议)、必要时 helper 追加。
- 命名遵循率 = 固定桩(不启动真实 subagent);「查看全部」上限 20 语料并入 stub。
