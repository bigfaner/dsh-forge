# 3.7: SC3 e2e·偏差与降级腿:手改不回流 + 偏差提示 / 投影故障注入降级不阻断注册 / 重试恢复两侧一致

## Description

SC3 后半(偏差与降级)e2e 腿:dsh 侧手工改名/删除 workspace → forge 不回流仅呈现偏差提示;投影写入失败(workspace 不可写/动词错误注入)→ 降级为无投影继续运行,注册不被阻断 + 可重试提示;恢复后重试投影成功即两侧一致。

## Acceptance Criteria

- [ ] 偏差不回流:dsh 侧手工改名/删除 workspace → forge 侧刷新后呈现偏差提示(状态行 deviation + 明细),零反向写断言(dsh 侧实况不被 forge 改回)。
- [ ] 降级不阻断注册:投影通道故障注入 → 注册流程完成(项目入列表)+ degraded 提示 + [重试投影] 可达(e2e 断言,PRD 降级流)。
- [ ] 重试恢复:故障恢复后 retryProjection 成功 → 两侧一致(healthy 状态行 + 实况快照一致)。
- [ ] verb 不因投影失败 reject 断言:注册/改名/归档在投影故障下本地生效。
- [ ] 全量 e2e 前单实例锁纪律;SC3 偏差降级腿全绿。

## User Stories

- Story 4: 注册即归组(投影写入失败 → 注册不被阻断,降级 + 可重试)
- Story 5: 归档不丢历史、改名不丢归档(手改不回流仅偏差提示)

## Hard Rules

- 故障注入只经测试通道/mock 上游动词错误码,不得为测试改产品降级逻辑。

- 文件清单:`tests/e2e/specs/m4/sc3-projection-degrade.spec.ts`(新)。
