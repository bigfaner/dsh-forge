# 1.2: 内核 projects-identity 域:D11 归一化管线 + 三层比对自愈 + 证据侦测(固定前缀有界探测)

## Description

新建 `apps/desktop/src/main/workbench/projects-identity/`:路径归一化管线(realpath.native → 剥前缀 → 正斜杠 → win32 大写折叠 pathKey,应用层单源)、三层身份比对(canonical → pathKey → (dev,ino) 命中仲裁回写自愈)、C7 证据侦测(gitRoot 仅顶层 .git 固定前缀有界探测;forgeTreeHit = `<root>/docs/features` 一次 readdir + manifest 存在性;childRepos 直接子目录 ≥2 .git)。产出 `DetectReport`(Interface 1 类型),供 1.3 动词与 C7 卡消费。主进程内执行全部路径校验(T4 缓解)。

## Acceptance Criteria

- [ ] 归一化矩阵单测全绿:win32 大写折叠 pathKey、junction、8.3 短名、UNC、裸盘符拒绝、相对路径拒绝、realpath 失败(网络盘离线)→ 字符串回退 + identity_verified=0 不阻断。
- [ ] 三层比对:canonical 命中 → pathKey 命中 → (dev,ino) 物理仲裁命中即「同一项目」并回写自愈(悬挂键 null 容忍,注册时回填);比对结果供唯一性校验消费。
- [ ] 证据侦测:gitRoot 仅顶层 .git(固定前缀有界探测,禁 glob、不读正文);forgeTreeHit = `<root>/docs/features` 一次 readdir + manifest 存在性;childRepos = 直接子目录 ≥2 `.git` → chips 列表。
- [ ] DetectReport 全字段产出:canonicalPath/pathKey/identity/exists/isDir/readable/registered(命中 → projectId + displayName 快车道)/gitRoot/forgeTreeHit/childRepos。
- [ ] vitest 覆盖率 ≥80%(归一化/比对自愈/侦测三矩阵;临时目录 fixture 驱动真实 fs)。

## User Stories

- Story 4: 注册即归组(侦测证据 → 文档位置预览行三档门控;硬校验跨项目唯一)

## Hard Rules

- 路径侦测不得成为 FS oracle:固定前缀有界探测,禁 glob、禁读文件正文(OneDrive 水合);裸盘符/相对路径在归一化入口即拒。
- 校验全部在主进程执行,路径经既有安全通道传递(无 shell 注入面)。

## Implementation Notes

- 文件清单:`apps/desktop/src/main/workbench/projects-identity/normalize.ts`、`identity-match.ts`、`detect.ts`、`index.ts`(新)+ `projects-identity/*.spec.ts`(新,临时目录 fixture)。
- childRepos 探测深度 = 直接子目录一层(有界);UNC/网络盘 realpath 失败走降级路径,不得抛出到动词层。
