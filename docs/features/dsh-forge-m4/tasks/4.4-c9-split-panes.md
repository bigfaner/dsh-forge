# 4.4: C9 分屏:右栏多 pane(board tab + 会话旁置 aside)+ pane 增删/比例钳制 30–70 + 分隔条键盘模型

## Description

C9 分屏(UF9,交付顺序先于多窗口——P4 内先后):原生 rightbar 多 pane 之上——①board tab kind 多 pane 实例(看板 + 会话旁置 `subagentchat` aside 先例:`ctx.sidebarRight.openResource(subagentChatAddress(address), { preferNewPane: true })`);②pane 增删与比例:工作台头 [分屏] 控制 + pane 头(区名 + [拆出] + [关闭]);拖拽调比例即时存(钳制 30%–70%,两侧 pane 最小宽 30%);③分隔条键盘模型(role=separator + aria-valuenow;←/→ ±2%、Shift ±10%、Home/End 复位 50/50);④全部 pane 关闭 → 回活跃区。布局随项目记忆(采集归 4.5)。

## Acceptance Criteria

- [ ] pane 增删:工作台头 [分屏] → 添加 pane 并选视图(会话/看板);pane 头(区名 + [拆出为窗口] 位 + [关闭]);全部 pane 关闭 → 回活跃区单视图。

- [ ] 分隔条键盘模型:role="separator" + aria-valuenow;聚焦 ←/→ ±2%、Shift+←/→ ±10%、Home/End 复位 50/50,钳制同拖拽;Enter/Space 无激活语义。
- [ ] 分屏不改变视图本身功能面(复用同一视图组件;原生 rightbar pane 机制)。
- [ ] vitest + jsdom:pane 增删流/钳制/键盘调整/旁置开 pane。
