# 2.2: 右栏 forge tabs 容器:tab kinds 注册(guide/overview/board/doc/depgraph)+ 开始页 + strip 机制 + 联动与宽度

## Description

右栏 = 原生 rightbar(dockkit)挂 forge tabs(Integration 5):`sidebar.right.pane.tab` 族注册五种 tab kind(guide 开始页/overview 项目概览/board 任务看板/doc 文档/depgraph 依赖图);「开始」页(罗盘水印 + 三卡片原位替换,可关闭,全关 = 无 chip 底板 + 隐藏 ＋);strip 机制(chips/×/＋ 紧贴最右 tab/⛶ 全屏/面板钮);整栏联动(跟随当前项目,切项目关旧 tab 回概览)与宽度(默认收起轨道归零/展开 45% 视口 300–70%/全屏覆盖会话列)。原生 rightbar 自身持久化(会话域)不动,双轨不冲突。
