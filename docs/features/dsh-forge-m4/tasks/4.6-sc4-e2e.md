# 4.6: SC4 e2e 腿:分屏同屏可操作 / 布局重进恢复 / 拆出窗口并行 + 单实例(主窗关闭 = 退出)

## Description

SC4(分屏/多窗口)e2e 腿:项目内分屏同屏(会话 + 看板组合两视图可操作);布局状态随项目记忆重进恢复(比例/收起);拆出窗口与主窗口并行操作互不干扰且同属单实例(主窗关闭 = 退出应用,detached 随之关闭)。

## Acceptance Criteria

- [ ] 分屏同屏:会话 + 看板双 pane 同屏且两视图均可操作(输入/点击各断言一次)。
- [ ] 布局恢复:调整 pane 比例与收起状态(subagent 收起/树展开)→ 离开重进项目 → 布局恢复(应用重启与项目切换两路径)。
- [ ] 拆出并行:拆出窗口与主窗口并行操作互不干扰(A 项目窗口不随主窗切 B 变化)。
- [ ] 单实例:主窗关闭 = 退出应用(detached 随之关闭);托盘/单实例锁零回归(M1 壳 e2e 原样绿)。
- [ ] 全量 e2e 前单实例锁纪律;SC4 腿全绿。

## User Stories

- Story 6: 分屏观察与布局记忆(SC4 全量验收)

## Hard Rules

- 双窗口 e2e 须防句柄泄漏(收尾显式关闭全部窗口;断言窗口计数归零)。
