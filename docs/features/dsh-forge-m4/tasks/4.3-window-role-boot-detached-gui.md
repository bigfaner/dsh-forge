# 4.3: client window-role boot + 拆出/收回 GUI:pane 头 [拆出为窗口] · boot role 分发 · OS 关闭 ≡ 收回 · 窗口语义(归档/项目绑定)

## Description

C10 client 面:①pane 头 [拆出为窗口] 动作 → `windowOpenDetached`(view = board/conversation;target 会话经 SessionTarget)→ 主窗 pane 移除;②新窗 boot = windowGetRole 分发(role.kind='detached' → 按projectId/view/target 渲染单视图;kind='main'/null → 正常工作台);③收回 = 独立窗口 [收回] 或 OS 标题栏关闭(≡ windowRecall,pane 即时回主窗原位不待重启);④窗口语义:绑定来源项目(不随主窗激活指针);归档项目窗口保持可用(标题追加「已归档」);删除项目 → 该项目全部拆出窗口关闭(3.4 hook 接线)。
