# 4.7: SC5/SC6 全量验收收口:零缩水终验(对照盘点基线)+ 性能断言(首屏 ≤2s@500 任务/切换不劣化/投影 ≤2s)+ quality-gate

## Description

里程碑收口(P4 gate):SC5 零缩水终验——既有 M1-M3 功能面在 IA 重构后完整可用,迁移后 e2e 全量全绿,对照 2.10 盘点基线二次断言(功能删除 0);SC6 性能断言——项目工作台首屏 ≤2s(500 任务规模)、视图切换不劣于重构前、投影操作 ≤2s;quality-gate 全量通过(compile/fmt/lint → 单测 retry-once → 回归);失败自动建 fix 任务。

## Acceptance Criteria

- [ ] SC5 终验:M1-M3 既有 e2e 全量全绿(含 M1 原样);对照盘点基线逐行二次断言零缩水(功能删除 0);孤儿视图清零复核。
- [ ] SC6 首屏:项目工作台首屏 ≤2s @ 500 任务规模(数据种子注入;性能断言腿)。
- [ ] SC6 切换:视图切换(项目切换/右栏 tab/看板↔会话)不劣于重构前基线(对照口径:1.8 迁移前取证的时基记录)。
- [ ] SC6 投影:投影操作(注册/改名/归档/删除)同步完成 ≤2s(失败降级不阻断路径同口径)。
- [ ] quality-gate 全量通过(compile/fmt/lint → 单测 → 回归;失败自动 fix 任务闭环)。
- [ ] 全量 e2e 前单实例锁纪律;里程碑收口记录(SC1-SC7 状态汇总)落盘点文档。
