## Acceptance Criteria

- [ ] 三级树渲染:项目行(h34,文件夹闭/开,hover 三角 caret 旋转 = 展开)/ 会话行(h32,状态点优先级 待输入>运行中>subagent 运行中,hover 时间位变 ⋯ = 重命名/分叉/归档)/ subagent 行(缩进 12/级,↳ 前缀,递归默认收起);顶层列表永不出现 origin=subagent 条目。
- [ ] 分组×排序:按项目树(默认)/ 按项目 / 单列表(↳ 内联)× 手动排序 / 最近更新;选项 localStorage 持久化(用户级,C3 口径)。
- [ ] 溢出折叠:每组 >5 条「⋯ 展开其余 N 个会话 / 收起」;激活会话祖先链默认展开;展开/收起与溢出态经 props/回调暴露(随项目记忆 P4 接线)。
- [ ] 归档项目:降透明 + ⚠ 角标只读分区,不挂会话;恢复/删除行菜单位(经 3.5 动词接线,本期 mock);未分组组头(会话纳管入口)。
- [ ] 区头:🔍 原地展开搜索(过滤项目名+会话标题,debounce 250ms,Esc 清空退出)/ ⚙ 视图选项 popover(分组×排序)/ ＋ = folder-plus C7 入口位;56px 收起 rail(◂/⊕/🔍/＋/⚙)。
- [ ] vitest + jsdom 视图主路径:三分组派生/溢出折叠/未分组组头/归档分区/搜索过滤/⋯ 菜单三项。

## User Stories

- Story 1: 项目一页可见(左栏全项目树枚举/切换)
- Story 2: 从任务直达执行会话(subagent 归拢于 parent 血缘树下默认收起)

## Hard Rules

- 上游组件不导出:行语言自绘,数据面只读消费 ctx.workspaces/ctx.sessions;不得 import 上游内部组件。
- 顶层列表永不出现 origin=subagent 条目(SC7 断言口径)。
