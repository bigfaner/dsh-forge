## Conventions Established
- 双宿主组件纪律:宿主上下文一律 props 化(单一联合类型 + 默认值兜底既有行为,组件内零宿主探测);宿主几何映射单源(无环共享家常量,dock 宽/inset/覆盖层锚定同源取值);零缩水以默认形态 verbatim 断言锁证;模态弹窗族窗口级自洽不随宿主穿透。
- 右栏消费上游 = 两段式公开面(stage one ctx 句柄 + stage two keyed 声明合并)vendored 零修改;原生既有能力(strip/宽度/全屏)AC 以源码证据核销不重写;原生不变量(空栏播种/关闭保护)经 extension band 保活而非复制,原型交互以原生等价语义落地并双注记。
- unlinked peer 结构孪生纪律扩展(1.6 先例):SlotMap 声明/资源地址构造器本地镜像,owner 收窄为所读子集(重复成员 = 显式编译错漂移警报而非静默),格式逐字节对拍 vendored 源 + 测试锁死;运行时全程 guarded 缺席整族静默不注册。
- multiple kind 的 params 键控去重归插件侧:原生页去重仅单页 kind 生效 → 插件生命周期注册表(body 挂载登记/卸载注销,隐藏 body 保持挂载保证登记存活);tab 标题走 keyed title 座位读 params;按 params 去重的 kind 均须插件侧注册表(2.4 DocTree 先例)。
- 推导域(lineage)纪律:纯函数只读不落库、恢复即重算;降级双因同型收敛(静默 + [forge-lineage] 结构化单行 log + 零抛错,degrade never throw);预算协作式 deadline 单 now() 缝(fake timers 可测,超时宁缺勿错);上限截断 + total 全量(查看全部语义)与 C3 溢出同构口径。
- seam 缺席纪律延续:可选座位/seam 缺席 = M2/M3 信息态逐字(既有断言零改全绿为构造性要求);能力在场才增强;present-wins 双缝(present 胜出、缺席回退内建路由),避免半吊子接线(只通单臂的点击会是静默 no-op)。
- 断言零删改纪律:断言本体逐字保留,仅宿主方言/前缀对拍形态随实现升级改写;交互失稳挂 test.fixme 台账(断言 + 迁移指针 + 复核注释)并升级 fix task 承接根因(1.8/2.9 两先例),不作断言收缩换绿。
- e2e 语料种盘纪律:预启动经 REAL vendored persistence backend 落盘(DSH_HOME 隔离、zstd 与 host 口径一致、真核心消费非 mock 旁路),runtime 注入错过一次性 bootstrap;journal↔artifact↔UI 三方对拍;能力核对(backend 可装载/头可写可回读/host 可 boot)先于实现。
