## Conventions Established
- 投影单向纪律结构面:dsh 实况仅为 diff 只读输入,域内不存在以实况为权威的 forge 侧写集产出;偏差仅呈现(DeviationRow 零落表,读时重算物化,结构保证 = 域内无持久化出口);收敛仅经显式 retryProjection(用户动作)或生命周期 hook push —— 零反向写以「偏差后零通道调用/零 push 事件」断言锁证;归档 ≠ 删除(归档/恢复/归档态改名/归档态 retry 四腿断言零通道调用 + workspace 原样保留)。
- 内核纯函数域纪律(3.1 Hard Rule):零 IPC/零 fs/零 relay(唯一 fs 相邻引用 = toComparableKey 纯字符串折叠);plan 自包含(reorder op 随每个 plan,单 plan 幂等全量重推收敛全部期望状态);diff 输出确定性((orderIdx, projectId) 升序与输入序无关 = 幂等前提);单写者(projection 域经 repos 写 projects 不越层)。
- relay 在场/重试纪律:在场判据 = 既有事件订阅登记非空(零新裸通道);缺席重试一次(500ms 竞态窗)后 degraded,禁静默丢弃;plan 保留 = 期望在库任何时刻幂等重推;装载后重放仅限 CHANNEL_UNAVAILABLE 语义(plan 从未被消费),op 失败型 degraded 是用户重试面 —— relay 侧不建本地重试策略(重试策略单源在内核)。
- duck-typed 结构孪生纪律(vendored 为准):WorkspaceChannel 重声明而非类型导入,漂移经 vendored 升级显式适配 + 模块头注记事实适配点;零 any 穿透(strict + exactOptionalPropertyTypes + tsc 干净);读写双缝分离(写走 raw remote 错误码精确可读,读走客户端 list 面)。
- 快照上报纪律:执行后快照本地合并先于 outcome 上报(写走 raw remote 不经乐观合并则必须自补合并,否则 outcome-ok 写陈旧哨兵 workspaceId);phase='pending'/快照从未建立不上报(空 ≠ 未知,局部快照会被读作「注册表仅此」);follow 收数 = debounce + 冲突时重读 + 等值门 + 拒绝重试 + 源缺席有界轮询。
- 竞态缺口裁决纪律(3.6→3.7 两段式先例):测试发现的收敛缺口先判真产品缺口 vs 测试时序问题 —— 真缺口内核最小修(以恢复设计不变量「单 plan 自包含收敛」为依据),测试侧静默门只用于取确定性路径且必须移交后续任务裁决,不以门掩盖产品缺口;日志门锚点 = 主进程结构化 log 首行(captureMainStdout 家族先例)。
- 故障注入纪律:env+控制文件缝(migration faults-stub 先例)随探测重读,未设置 = 生产行为不变;不为测试改产品控制流(渲染侧通道注错不可达即不造缝,以直驱回填动词替代);注错词表留后续扩展位(opError 形态)。
- 实况断言纪律:e2e 断 dsh 侧实况取原生 registry durable 读(宿主单写者原子重写,与 follow 流同源),零 forge 侧状态行断言;比对基线收窄到投影面(上游动词全部写径),宿主自留位(updatedAt/会话归属 churn)不入比对防误报;隔离世界全等为最强形,外来条目引入时缩为 forge 子集相对序。
- e2e 真链纪律延续:预启动 REAL persistence 种盘(2.9)、launch 前单实例锁探针 + workers:1 + reduced-motion + onboarding dismiss;新增时序纪律 —— 故障在场静置 >500ms 让重试定时腿确定性收口、漂移注入前置投影面静默门(活动行数稳定 ≥1.2s + 全 healthy,healthy 本身不证明静默)。
- 构建新鲜度纪律(3.6 教训):座位缺席 + sc1/sc2 连锁失败先查 apps/desktop/dist 与插件 lib mtime vs 提交时间线;e2e 前三件套重建(apps/desktop build + build:plugins + stage:plugin-tarballs);全绿复核定根因(非产品回归)。
- GUI 纪律:唯一重试动作(仅 degraded 呈现重试钮 BIZ-005)+ 偏差折叠零交互件(button/a=0 断言 BIZ-006);确认文案 PRD 必答逐字断言 + 破坏性动词永不受焦(取消钮初始焦点);语义别名色(color-mix 挂 --dsw-alias-* 双主题)而非静态 rgba;store 派生态复位 by construction 优于复位缝;生命周期动词 never-reject(hook try/catch + 结构化 log)与终态 no-op 宽容读(retryProjection 唯一 reject 面)分离。
