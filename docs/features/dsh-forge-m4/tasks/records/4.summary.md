## Conventions Established
- 布局记忆双轨纪律:forge 只重放自己所属的开操作,原生 rightbar 会话域持久化(per-session dockkit localStorage)与原生外分隔条一概不读不写不重放;视图选项(分组×排序)=localStorage 用户级恒不入 blob(白名单未知键拒绝+显式测试钉定=Hard Rule 执行面);采集缺席碎片落 Interface 4 默认永不发半形态(内核白名单会拒),v1 无槽即弃防整 blob 被判违规重置。
- 窗口语义纪律:OS 关闭≡recall 由单一汇流构造保证('close' 几何记忆→'closed' removeDetached 唯一移除口+detached-closed 恰一次)而非对齐测试;role 零 URL 面(「无从读取」落实禁 URL hash);主窗 createWindow byte-stable(无 detached 在场时推送/WS 判定与旧实现逐字等价有专项测试,M1 语义零变更 diff 直证);窗口标题=BrowserWindow 状态归主进程,renderer 无标题动词。
- 可选 hook 注入纪律(壳→workbench 单向):壳生命周期 hook(recallProjectWindows/markDetachedWindowsArchived)走可选 deps 注入——services 装配在窗口面缺席(早期测试/装配变体)时动词不受阻;client 桥孪生新字段一律可选(stored?:boolean),presence check 只验成员可调不检返回形状(跨宿 additive)。
- boot 路由纪律:hostless(无 dshForge)main() 同步执行=boot 契约逐字保持(3.3/4.4 spec 断言面);真壳代价=恰一次 getRole 往返(WeakMap 按 face 记忆化);dispose 后到达的角色不装配(无僵尸 seat);detached 世界零 seat 双注册由构造保证(apply 路由只装单视图,左树/导航/rail/rightbar/split/relays 不进 detached 窗)。
- C9 几何边界纪律:公共 ISidebarRight 无 resize 动词、库存无 pane 结构→forge 分隔条=C9 比例态权威控件+seam 暴露,原生 divider 保留原生拖拽与钳制;pane 增删全走原生公共动词(openTab/openResource preferNewPane,原生 per-pane 页唯一性天然幂等去重),收栏回活跃区=原生 settle 规则经库存 reconcile 观察而非重实现;如需上游 resize seam 走 vendored 升级显式适配。
- 竞态防御纪律:动词前落标(markRemoved/forgetLayout 前置于删除流程动词)而非事件后判存(规避 500ms 批推晚于 detached-closed 的竞态);迟到写复活防护=引擎 disarm+内核 ERR_PROJECT_NOT_FOUND 拒绝双保险;恢复回声抑制=sameTreeLayout 内容比对(读侧 boot 重试与写侧回声同款);boot 服务竞态有界重试(500ms×12 幂等重入,2.9 教训);呈现再断言梯子模式=上游异步去选择者面前的有界幂等重发(detached 窗构造上无导航面才可用)。
- 结构孪生纪律延续(插件不可依赖 app,3.3/4.1 先例):TabKind canonical=内核 layout-schema.ts、client 保留 2.2 表、ipc-types type-only import 零第三份声明,lockstep=drift 断言;WindowRole/OpenDetachedInput/SessionTarget 孪生镜像 windows/ 域+严格形状守卫(isDetachedRole),漂移载荷降级 main 渲染层永不崩;spec 以本地孪生实现内核白名单语义逐产物 round-trip 断言(真内核 drift 锁仍在 desktop 侧)。
- e2e 多窗口纪律:主窗定位经 renderer 标签排除法(getAllWindows()[0] 序非稳定,误关 detached 触发 recall 恢复链污染断言);窗口计数=主进程 BrowserWindow.getAllWindows() 权威面(隐藏≠关闭);waitForDetachedBoard 按内容标记轮询(开窗可早于订阅);每腿收尾 quitShellAssertZeroWindows(窗口计数归零+主 pid 退出+Playwright 句柄面归零,错误路径 finally 亦兜);会话 chrome 前提=预种 turnStart 语料(hideChrome 门,加法默认关)。
