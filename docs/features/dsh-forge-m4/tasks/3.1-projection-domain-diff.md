## Acceptance Criteria

- [ ] 期望 repo:注册即占位(1.3 registerProject hook 接线就绪);最近成功投影回写(workspace_id/title/order_idx/pushed_at);degraded 原因落 last_error;dsh 侧删除重建后按 path 复连(ensure 定位)。
- [ ] diff 纯函数矩阵:四操作派生(注册 ensure/改名 rename/删除 delete/重排 reorder)+ 三类偏差分类(renamed/deleted/reordered);幂等全量重推 = 同输入同 plan。
- [ ] 执行序:plan ops = ensure(forge sort_order 升序)→ rename → reorder(insertBefore 链)→ delete;reorder 仅 forge 所属子集相对序。
- [ ] 状态机纯函数:pending → healthy/degraded/deviation 迁移规则(含恢复 healthy 重试路径);偏差明细不落表(对账重算物化)。
- [ ] 归档语义:archived=1 → 期望不变(workspace 保留),diff 不产生归档相关 op(必答⑤)。
- [ ] vitest ≥80%:diff 矩阵/幂等/状态机/v3 回填交互(pending 存量收数)。
