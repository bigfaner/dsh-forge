## Acceptance Criteria

- [ ] 投影状态行(右栏概览):healthy 成功色「与 dsh 侧一致」/ degraded 警示 + [重试投影](成功 toast / 保留降级态)/ deviation 警示 + [偏差明细 N] 折叠(逐行类型 Pill 改名/删除/乱序 + 条目名 + 处理建议只读文字;均无反向写入口)。
- [ ] 左栏项目行 ⋯ 菜单:重命名(行内编辑)/ 归档(确认 Dialog:「workspace 保留,会话仍按项目分组」)/ 恢复 / 删除(确认 Dialog:「投影移除,会话退未分组(历史不删除)」;删除当前项目 → 工作台落其余项目或空态)。
- [ ] 生命周期 × 投影联动:改名同步投影;失败降级不阻断本地生效(动词本地落库即业务成功,投影异步呈现)。
- [ ] C2 归档横幅只读态:工作台头下方全宽(警示色底 6%);左栏树降透明;会话列表抑制;可用动作仅 恢复/删除。
- [ ] 事件驱动刷新:projection_updated → 状态行即时更新(BIZ-005 失效-重建)。
- [ ] vitest + jsdom:状态行三态/偏差折叠/生命周期菜单四动作/归档横幅。

## User Stories
