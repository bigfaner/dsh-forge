# 2.5: lineage 推导服务(client):上游快照 ⊕ session_links 只读 join + 执行中判定 + ≤100ms 超时降级(不落库)

## Description

血缘推断 = client 半身只读推导服务(T2 裁决):输入 = 上游 `ctx.sessions` 快照(SessionListState.byId + subagentsByParent)+ 内核 session_links(经 get-task-detail 既有动词);产出 `TaskBinding`(links 新→旧 / executingSubagents 递归后代 / sessionTaskBadges 反向徽标 / degraded 位);执行中判定 = `status=in_progress` ∧ active 挂接(BIZ-workbench-008);计算 ≤100ms 超时或快照缺席 → 降级仅顶层,恢复自动回完整;纯只读、不落库、可随时重算。

## Acceptance Criteria

- [ ] TaskBinding 推导:links(active/ended,新→旧)+ executingSubagents(active 挂接顶层会话血缘树内 origin='subagent' 递归后代,SubagentHit 含 address 三元组 parentSessionId/childSessionId/mode)+ sessionTaskBadges 反向徽标。
- [ ] 执行中判定矩阵:in_progress × active 挂接 → 执行中;in_progress 无 active → 常规 + 未挂接标注位;非 in_progress → 常规。
- [ ] join 矩阵全绿:命中/未命中/多后代/递归深度/超上限 20(尾部「查看全部」)/ended 会话 disposed → byId 缺席 → 行可展开血缘位「不可用」。
- [ ] ≤100ms 预算:超时 → degraded=true 仅顶层;上游快照缺席同降级;恢复后自动回完整模式;降级静默 + 结构化 log(不弹错)。
- [ ] 不落库纪律:服务无任何写路径;输入只读消费上游快照与既有动词,可随时重算。
- [ ] vitest ≥80%:join 矩阵 + 判定矩阵 + 超时降级(fake timers)。

## User Stories

## Hard Rules

- 血缘不落库(PRD 必答⑥明令);粒度局限标注:同一顶层会话连续执行多任务 → 会话级「该会话执行中」(M5 备注备查)。
- 内核只见 session_links,不得为 lineage 扩表(零迁移)。
