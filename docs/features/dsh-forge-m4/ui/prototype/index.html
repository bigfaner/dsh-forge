评审说明

  • 数据层:data.js 单一模拟数据源(项目/feature/任务/会话树+消息),变更即广播重渲染并落 sessionStorage(同标签页跨页/刷新保留);新标签页还原种子数据;未发送的新会话不持久化(单例:项目内同时仅一个,已存在时点「新会话」无效,刷新即还原);左栏「＋ 添加项目」= 原位确认卡(文档位置预览行 + 证据门控预选,场景演示在原型工具「注册场景」组,与 projects.html 向导同构共享绑定器)。
  • 右下角「原型工具」:切换亮/暗主题与评审专用状态(loading/error/降级/空态按状态作用域标注);核心流程为真实交互,不经工具切换。
  • 可键盘操作:Tab 遍历,Esc 关浮层/退搜索/回上级;左栏收起(品牌行行尾开关)→ 56px rail(◂/⊕/🔍/＋/⚙);右栏默认收起(轨道归零;strip 尾端 ◂ 收起,会话头右角面板钮 toggle 展开 —— 仅已发送会话可见,新会话右上角无图标,⛶ 全屏覆盖会话列);右栏宽度拖拽 300–70% 视口(中央保底 400,不足自动归零);内容列两侧 10px 拖柄调宽 640–920(持久化)。
  • 会话交互:输入卡 Enter 发送(Shift+Enter 换行)→ 500ms 工具行(呼吸点)→ 1.9s 回复落定;运行中主钮变停止、有稿 = 排队发送;工具行「查看」跳轨迹 tab 定位;左栏会话行点击 = 打开,hover ⋯ = 重命名/分叉/归档(归档无确认,行消失,恢复走设置页)。
  • 设计规格权威:视觉断言(截断省略、focus 环、钳制、对比度)以 ../ui-design.md 文字为准,本原型供目验。
