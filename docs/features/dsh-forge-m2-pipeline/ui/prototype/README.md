## 任务详情抽屉——两分块（v11 · 任务内容 / 时间线）

```
├── 左缘拖拽手柄(宽 320–760px;双击复位 420;←→ 键盘微调 ±32;宽度跨任务保持)
├── 通用区:头部(状态点+任务键+状态 tag 左,关闭 ✕ 右端) + 标签行 = chip 组件(`类别 : coding.feature`[着色] `优先级 : P0` `预估耗时 : 4h` `实际耗时 : 2h31m`[仅 completed] `复杂度 : 高` `影响 : ⚠breaking`)
├── 块一 任务内容(底色条标题,可折叠;目标/结果 = 标签在上、内容在下):
│    coding.*:参考文档(可点击 → dock 开 tab) → 改动范围 → 验收标准 → 单元测试覆盖率 → 备注(最末,⚠ 警示置底)
│      改动范围双列:预期(N,✓/未涉及)↔ 实际(M,commit 优先查找/记录回退,计划外徽标,差异摘要);文件路径完整展示(换行)
│    fix=症状/步骤/验证 · doc=大纲/交付物/读者 · gate=走查步骤/检查项 · test=命令/指标/基线 · eval=评分表/结论
│    单元测试覆盖率:实际 N% / 预期 ≥M% + 进度条 + 阈值刻度线 + 判定(✓达标/未达标/未执行)
├── 块二 时间线(可折叠;头部计数 N 条):
│    现状条:⚠阻塞 · 前置(键+状态) · 挂接 pill · Surface · 质量门 · 得分
│    事件流:创建(前置声明/Fix链)→ 领取(⟞pill)→ 提交(commit 摘要+⟞pill)→ auto-block/restore/人工转移/评估
└── 「转移状态…」按钮(from≠to + reason 必填)

折叠 = 就地 DOM 更新(grid 0fr/1fr 高度过渡 + caret 旋转;不重建抽屉、不重放滑入动画)
层级阶梯 = 块头(13px/600 主色·底色条) → 子标题 tc-k(12px/600) → 组标签(10.5px/600 三级色) → 内容行;界面零说明文字(UI 逻辑见 ui-design.md)
```
