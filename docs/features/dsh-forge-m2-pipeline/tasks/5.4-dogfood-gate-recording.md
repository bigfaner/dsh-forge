# 5.4: SC-M2 门：真实模型派发链 dogfood（含 fix 链 + 中断恢复）+ 录制夹具产出

## Description

SC-M2 验收门：真实模型跑通派发链一条不间断（run-tasks dispatcher → claimTask → executor → submitTask success），含 fix 链（blocked → block-source → fix → auto-restore）与中断恢复（外环再 claim → reclaimed + digest 新值）；全程录制 JSONL 夹具供 5.2 回放。S8 环境备忘：绕 node shim（真实 node 路径）。

## Acceptance Criteria

- [ ] 派发链一条不间断端到端：run-tasks → claimTask（dispatchPrompt 合成 + digest）→ 匿名 executor → submitTask success（gate/files/commit）
- [ ] fix 链路径：blocked（reason）→ addTask block-source（单事务建链）→ fix 完成 → 恢复钩子 auto-restore（边不删）
- [ ] 中断恢复路径：会话中断 → 外环再 claim → reclaimed=true + 简报重合成 digest 新值
- [ ] 录制夹具落盘（JSONL——5.1 格式；含 dispatchPrompt 全文与事件流），供 5.2 回放消费
- [ ] dogfood 证据归档（运行记录 + 环境备忘：真实 node 路径绕 shim）
