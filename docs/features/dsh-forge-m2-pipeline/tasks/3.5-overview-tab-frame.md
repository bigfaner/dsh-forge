## Acceptance Criteria

- [ ] ov-head：默认折叠（项目名 + 状态摘要一行）；▾ 展开 4 行（工作区/文档/知识/任务清单@hash8）；▴ 收起
- [ ] sticky 区：三子 tab（提案|feature|任务——用户定向顺序）+ 搜索行（IME 安全：仅更新内容区不重建搜索行；清除按钮）+ 排序 pill（⇅ 活跃优先 ↔ 最新创建）
- [ ] 子 tab 切换：清空搜索 + 清空 chips + 收起全部展开态
- [ ] 提案/feature 子 tab：父行 ▸ 展开元数据（slug/摘要/作者/裁决/谱系 或 摘要/来源提案/任务七态/文档统计；多开并存）+ 文档行（名称 + 状态标签紧贴 + › 行尾；feature 不含提案文档）；文档行点击回调（dock 开 tab——4.1 接线）
- [ ] chips 七态过滤 toggle + 0 计数 disabled（过滤接口三视图统一，3.6 消费）
- [ ] 组件单测（vitest renderToStaticMarkup）：结构/折叠/切换清空/IME 安全/搜索传参（search 关键词经 rpc mock 断言服务端过滤调用）

## User Stories

- Story 1: 任务浏览与人工决策（概览入口）
- Story 5: 文档浏览（文档行 → dock 开 tab 的入口）

## Hard Rules

- 搜索过滤服务端承载（listTasks search 入参）——前端禁全量拉取本地过滤。
- 三签不动：左栏不加行、中区不加面板、conversation.view 不加签。
