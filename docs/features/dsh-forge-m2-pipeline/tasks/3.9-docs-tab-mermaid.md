## Acceptance Criteria

- [ ] mermaid 产品依赖引入（精确 pin + lockfile）；懒加载：仅文档 tab 含 mermaid 块时动态 import——零块零加载
- [ ] securityLevel='strict'（库默认 sanitize，禁 click 回调交互）
- [ ] erDiagram 渲染成功（SVG 在场 = 验收锚）；全图型同库（flowchart/sequence 等同路径）；渲染失败/非法源 → 回退占位卡（源码 + 回退注记，异常不外溢）
- [ ] tab 内容：头部 + 路径栏（canonical 路径 + 📁 编辑器 + ↻ 重读）+ Markdown 渲染（md 段/mermaid 段分段）
- [ ] 悬空文档 → 只读占位面（路径栏保留，不崩溃不写入不删行）
- [ ] 单测：mermaid 分段解析/懒加载触发（动态 import mock）/回退占位/悬空态

- mermaid 懒加载 + securityLevel='strict' 为安全边界——禁同步 import、禁放宽 securityLevel。
- 渲染失败回退纯文本占位——异常不外溢（Mitigations ⑦）。
