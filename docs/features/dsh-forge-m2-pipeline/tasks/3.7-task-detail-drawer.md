## Acceptance Criteria

- [ ] 两分块结构：通用区（✕ 右端 + 标题 + chip kv 标签行 `{key} : {value}`：类别[只显类型，着色]/优先级/预估耗时/实际耗时[仅 completed]/复杂度/影响）+ 块一任务内容 + 块二时间线；块标题底色条 + 主色加粗，子标题与键标签全加粗（层次阶梯）
- [ ] 顺滑折叠：块头点击**就地更新**（grid 0fr/1fr 高度过渡 + caret 旋转；不重建抽屉、不重放滑入——仅切换任务时播放）；aria-expanded 同步；Enter/Space 可用；会话级保持
- [ ] 类型模板六族路由（coding/fix/doc/gate/test/eval × 20 类型；eval 类空态注记——M2 无技能写入）+ 参考文档 chip 可点击 → dock 开 tab 回调（refDocs docRel 去重，抽屉保持）
- [ ] 块一：目标/结果上下展示 + 改动范围双列（预期声明 ↔ 实际 commit 查找[无提交回退记录语] + 差异摘要）+ 文件路径完整展示 + 单元测试覆盖率组件（实际 N%/预期 ≥M% + 进度条填充=实际 + 阈值刻度线位置=预期 + 判定徽标 ✓达标/未达标/未执行）
- [ ] 块二：现状条（六型条件：阻塞原因/前置依赖[键+状态]/挂接 pill 分型/Surface/质量门 M/N/得分+严重度）+ 事件流（创建[fix 链来源织入]/领取[digest+派发⟞pill]/提交[gate+commit 徽标/摘要/文件数+执行⟞pill]/auto-block/auto-restore/人工转移[from→to+reason]/评估）
- [ ] 调宽：左缘手柄拖拽 320–760px 钳制 + 双击复位 420 + ←→ 键盘 ±32 + 会话级保持；关闭 Esc/✕/点击另一任务切换内容；单测（渲染/折叠纯函数/宽度钳制/模板路由）
