# 2.6: 任务域读面：list/stats/graph/detail/sessionLinks + 水化 + git 只读

## Description

`forge/tasks/` 读面五法：listTasks（搜索/排序/副行水化）、taskStats、taskGraph（DAG 数据）、taskDetail（全量水化 + allowedTransitions + git 实际改动查找）、sessionLinks（双源分型）。TaskCard/TaskDetail 承重字段按 Interface 1 表逐项。

## Reference Files

- docs/features/dsh-forge-m2-pipeline/design/tech-design.md — Interface 1 读面五法签名与 TaskCard/TaskDetail 承重字段表 (ref: Interface 1: `ctx.forgeTasks`（任务域）)
- docs/features/dsh-forge-m2-pipeline/design/tech-design.md — Cross-Layer 字段映射（allowedTransitions/actualDuration/派生目录） (ref: Cross-Layer Data Map)
- docs/features/dsh-forge-m2-pipeline/design/tech-design.md — Mitigations ③（git 白名单）与 ①（路径守卫） (ref: Mitigations)

## Acceptance Criteria

- [ ] listTasks：search 服务端中英双语过滤（标签常量匹配）+ sort（active|created）+ TaskCard 副行水化（实际耗时[completed，core 水化首 claim→末 submit 时差]/前置摘要[自然键+状态]/挂接计数/fix 源标）
- [ ] taskStats（total + byStatus 七态分布）+ taskGraph（tasks + edges{taskId, prerequisiteId, origin}）
- [ ] taskDetail 全量：records 时间线（verb/from→to/reason/summary/gate/commit/digest）/prerequisites/waitingOnMe/sessions 双源分型/actualFiles（files_json→commit 查找）/allowedTransitions/refs 水化（vars·description 锚点 → feature_documents ∪ proposals docRel 匹配；命中链接态、未命中置灰）
- [ ] 实际改动范围 git 只读：execFile('git') 恒数组参 + 白名单子命令 ['show','diff-tree'] + timeout 2s + ENOENT/失败回退记录语
- [ ] sessionLinks：links ∪ records.session_id 双源分型（卡片含 taskId——SC6③ 数据源）
- [ ] EQP 三查询命中索引（EXPLAIN QUERY PLAN 断言）+ @500 任务直读核心侧基准（SC2 数据面）

## User Stories

- Story 1: 任务浏览与人工决策（列表/详情数据源）
- Story 6: 挂接双侧（sessionLinks 双源）

## Hard Rules

- git 白名单子命令封闭 ['show','diff-tree']；禁 shell 字符串拼接；ENOENT 与失败同路回退记录语。
- 读面直读返回——禁 watch/回流/快照同步（即时判据 = 单次重取见新值）。

## Implementation Notes

- 新建 `packages/core/src/forge/tasks/{list.ts, detail.ts, session-links.ts, git-lookup.ts}` + `.test.ts`（EQP 断言 + 500 行夹具基准）。
- 搜索 IME 安全 = 前端职责（3.5）；服务端只做匹配。
- git-lookup 单独文件便于审计（SC-NFR 单一写入路径：git 仅只读两子命令）。
