## Acceptance Criteria

- [ ] addTask 单事务全成全败：tasks 行（id uuid 生成 + localId 混合分配[常规数值顺延 + fix-N/disc-N 动态前缀] + slug 归属校验[featureSlug 命中 feature 且 ≡ slug 列]）→ edges 行 → records 行
- [ ] 增量环校验：新节点无 dependsOn → O(1)；组合 → 可达性 DFS 回报完整环路径（ERR_CYCLE_DETECTED data 带环路径）
- [ ] 两级去重：任务级 fix 复用（reused=true）+ 边级 PK 幂等；UNIQUE(slug, local_id) 冲突 → ERR_TASK_EXISTS
- [ ] block-source：源任务同事务置 blocked + `auto-block` record + fix 链深 ≤6（ERR_CHAIN_DEPTH_EXCEEDED）+ 相位重算
- [ ] queryTask include 选项（prerequisites/waitingOnMe/records/sessions）+ 身份解析（TaskRef → taskId；未命中 ERR_TASK_NOT_FOUND）
- [ ] 单测：全路径 + B.5 锚（环构造双 flag / 两级去重 / 边持久不删）
