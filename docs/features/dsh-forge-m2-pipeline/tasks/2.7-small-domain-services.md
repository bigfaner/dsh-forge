## Acceptance Criteria

- [ ] registerFeature（slug UNIQUE → ERR_FEATURE_EXISTS；解析未命中 ERR_FEATURE_NOT_FOUND）+ transitionFeature（from≠to 复用 ERR_INVALID_TRANSITION；非法转移同源校验）
- [ ] upsertFeatureDoc 登记即推进：单事务内聚相位推进（单调只进；slug→id 服务内解析）
- [ ] listFeatures（七态分布/文档统计/谱系）+ createProposal/transitionProposal（裁决写 decided_at）+ listProposals（search/sort）
- [ ] forgeDocs.read：路径守卫 resolve + startsWith(canonical(forge_dir))（越界 ERR_DOC_PATH_INVALID）+ 悬空态（dangling 只读返回，不崩溃不删行）
- [ ] provide ×4 装配：ctx.forgeTasks/forgeFeatures/forgeProposals/forgeDocs 注入（service-assembly 扩测）
- [ ] features/proposals 写动词 emitTasksChanged 接线（四域一切写动词闭包尾部覆盖面收口——proposals 为 tool 写，无事件则提案子 tab 永不刷新）
