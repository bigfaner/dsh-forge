## Acceptance Criteria

- [ ] 目标态仅列 allowedTransitions（from≠to 机械排除；用户点不到非法目标）
- [ ] reason 必带：空因确认拒绝留场（不清空已选、不关闭对话框、错误提示在场）
- [ ] 确认 → transitionTask 回调（taskId + toStatus + reason）；终态提示可能触发 autoRestore
- [ ] 关闭：Esc / 取消；单测（选项集来源/空因拒绝/提交载荷）

## Hard Rules
