## Acceptance Criteria

- [ ] transitionTask：提前校验 toStatus ∈ transitionTargets(current,'human')（否则 ERR_INVALID_TRANSITION）+ reason 必带（ERR_REASON_REQUIRED）+ record（from→to）
- [ ] → completed/skipped 同挂恢复钩子（C3：与 submitTask 钩子同族）
- [ ] validateFeatureTasks 单 feature 子图五类检查：该 feature 全部 tasks/edges/records/links + 相位派生不变量（含 slug 列 ≡ feature slug、同 feature 边约束服务不变量）
- [ ] ValidateReport = { violations: Violation[]; checked: { featureSlug; tasks } }（违规含定位信息）
- [ ] 发现面吸收送校接线：1.3 post-ingestion 挂点 → 对新入库 feature 逐个送校（增量集语义归流程层）

## User Stories

- Story 1: 任务浏览与人工决策（转移 reason 必带 + 目标集校验）

## Hard Rules

- 一次只校验一个 feature（动词面恒单 feature；「批量」语义归调用方流程层）。
- transitionTask 仅 RPC 人类通道可达（tool 面不注册——3.2 审计锚）。
