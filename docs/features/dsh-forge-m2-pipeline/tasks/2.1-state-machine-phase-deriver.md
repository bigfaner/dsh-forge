# 2.1: 任务状态机 transitionTargets + 相位推导机（纯函数核心）

## Description

`forge/tasks/` 纯函数核心：`transitionTargets(current, face)`（human = 七态 − 当前态；agent = claim/submit 拥有的转移矩阵）+ 相位推导机（任务状态分布 → feature 相位快照，单调只进）。UI 菜单（taskDetail.allowedTransitions）与服务端校验同一纯函数，零漂移（所见即所得）。

## Acceptance Criteria

- [ ] transitionTargets 纯函数两 face 落地：human = 七态 − 当前（from≠to 任意通道）；agent = claim/submit 转移矩阵
- [ ] 单测覆盖 SC7 锚：from 不匹配 / 目标 ∉ transitionTargets / agent 面矩阵非法格 → ERR_INVALID_TRANSITION 形状

- [ ] 相位不变量断言（写事务内增量——受影响 feature 漂移防护）
- [ ] 七态/六态/五态与 contracts 标签常量 exhaustive 对齐（编译期穷尽 + 测试）
