## Acceptance Criteria

- [ ] 列表：主行（ID[slug/localId] + 标题 + 中文状态 tag + ⋯）+ 副行 11px（类型/优先级/实际耗时[completed]/前置/挂接/fix 源标）；行点击 → 抽屉回调
- [ ] DAG：SVG 贝塞尔连线 + 箭头 marker（完成边绿）+ 节点（状态点 + 键 + 标题 + ⏱实际耗时[completed]）；布局纯函数（分层独立可测）；节点点击 → 抽屉回调
- [ ] 泳道：七态横向列（0 计数列折叠为窄头）+ 卡片（foot 含 ⏱实际耗时[completed]）；卡片点击 → 抽屉回调
- [ ] chips 过滤三视图统一 + 排序作用三视图；0 计数 chip disabled
- [ ] 三视图 seg 切换保持过滤/排序态；feature pill 切换（taskGraph 按 featureSlug 拉取）
- [ ] 单测：DAG 布局纯函数（分层/回边）/三视图渲染/过滤联动
