# 5.3: SC2 性能 + 审计四锚（无 watch / SC8 零迁移 / SC3 零写入 / web 无编排 + 旧技能零残留）

## Description

性能与代码审计验收：SC2（@500 任务 ≤2s + EQP）；审计四锚——SC8 零迁移（无迁移工具 + 旧仓文件未动）、SC3 文件系统级零写入监控（任务域无 watch/回流/快照同步）、web 无编排逻辑、旧技能悬空引用零残留。审计锚以可重复的自动化检查（grep/构建图断言）落 test 面。

## Acceptance Criteria

- [ ] SC2：@500 任务列表/图/详情 ≤2s（e2e 计时，回放夹具造数）+ EQP 三查询命中索引（与 2.6 单测呼应的 e2e 侧）
- [ ] 任务域无 watch/回流/快照同步模块代码审计（grep 断言：core forge 域禁 chokidar/fs.watch/轮询守护）
- [ ] SC8 零迁移审计：无迁移工具调用 + 旧仓文件未动（存量目录断言）+ 发现面单向吸收白名单在场
- [ ] SC3 文件系统级零写入监控：forge_dir 只读面断言（发现面扫描零写入——与 1.3 Hard Rule 呼应）
- [ ] web 无编排逻辑 + 旧技能悬空引用零残留（构建图/引用扫描自动化断言）
