### 4. Conventions Established

- **夹具三来源一格式**: 手工构造（createFixtureBuilder）/落盘载入（writeFixture/loadFixture）/dogfood 首录落账共用 JSONL v1 格式——回放只执行 verb 行；版本字段逐行预留，不兼容版本 fail-loud（ReplayFormatError）。录制夹具 verb 载荷绑定录制期 projectId，跨库重放恒走 hand 夹具同机构造。
- **env 门控测试钩子纪律**: 钩子不在产品面——零 IPC 通道/零 preload 暴露，allowlist 双道守卫不知晓；发布构建 env 缺席零注册为断言面（G1 pin 相容口径）。钩子接线内聚 registerM2Channels 末段，main.ts pin 行数不动。
- **refetchOnce 单发判据本体**: e2e 断言「单次重取见新值」经 refetchOnce 直取（禁轮询兜底）；计时/等待面向主侧事件记账快照而非产品读面，超窗即红。
- **审计锚双落点 + 负样例自证**: 源码面锚同时落 vitest 常驻门与 Playwright G2 池；引擎自证沿 lint-selftest 形制（临时目录种植→拦截→清理）。
- **豁免清单纪律**: M3_DEFERRED_SKILL_REFS 显式豁免逐条附裁决出处——新增豁免须附出处，禁静默扩池。
- **运行面零写入监控形制**: 前后文件树快照（size/mtimeMs/sha256）逐字节对照；新文件豁免根 = .forge/.knowledge 产品状态根，其余工作区面恒零新文件。
- **core DTO 键缺席纪律**: 缺省字段恒「键缺席」而非「undefined 值在场」——agent tool 面（snapshotJsonValue/lossless 校验）后者致命；新增 DTO builder 须同口径（proposals 小域残留待收口）。
- **electronApp.evaluate 两坑形制**: 业务 arg 居第 2 参（第 1 参 = electron 模块本体）；返回值经序列化不保函数——取回桥面对象再调用的 husk 面 call 缺席，恒取 globalThis 挂点面求值。
- **共享 worktree 夹具卫生**: 失败重跑会覆写仓内录制夹具——重跑前 mtime 对照源码，跑后 git checkout 复原已交付版本（建议后续给 writeFixture 加审计后置位）。
- **e2e 环境备忘（fixtures/m2/README.md）**: 真实 node 绕 node.cmd shim（shim 注入 ELECTRON_RUN_AS_NODE=1）、DSH_FORGE_E2E_SKIP_WEB_BUILD=1 逃生口、host 侧改动先 tsc -b 再跑 e2e（playwright 启动 apps/host/dist）、vite global-setup 0xC0000409 偶发重跑即绿、隔离 DSH_FORGE_USER_DATA（用户 DSH Desktop 实例在场不冲突）。

### 5. Deviations from Design

- **[5.1] 钩子传输面显式化**(载体级裁决): tech-design 录制-回放节言「main 侧测试钩子（env 门控，经 host.services 桥代理直调动词）或 forge.db 直插」两径并列——实落双径并存且传输面显式化为 globalThis.__DSH_FORGE_TEST_BRIDGE__ 挂点 + Playwright electronApp.evaluate 注入（零 IPC/零 preload）；语义与设计一致（最贴近真实 tool 路径），仅传输机制具体化。
- **[5.2] 写入径夹具源替换**(前提级裁决): tech-design 言「按录制序列重放写入」——dogfood 首录夹具 verb 载荷绑定录制期 projectId 不可跨库重放（每 e2e run 独立 USER_DATA 新库），5.2 经 createFixtureBuilder 同机构造 hand 夹具（格式同源、动词序列手工编排）；「回放主径零在场模型」设计意图不受影响。
- **[5.2] 事件 ≤500ms 计时口径细化**: 设计只言「事件推送 ≤500ms」——实落主侧收讫时戳距写发起时刻的保守超集（含动词执行时间），观测面向主侧记账快照；口径比设计字面更严且不违禁轮询 Hard Rule。
- **[5.3] FRONTMATTER_KEYS 增补导出**(additive): 设计未列 discovery.ts 导出面变更——为承载吸收白名单「运行期 import 常量封闭集」断言（非字符串散扫）增补导出；吸收行为零变化。
- **[5.4] 受控初态直种 + 三处运行期缺陷修复**: 设计交互一言派发链/fix 链/中断恢复路径——实现在其上增 db 直种相位号初态（seedDogfoodTaskRow，addTask 数值顺延不可达设计初态）；执行中修复 boot overlay skill-filesystem 行（3.4 缝运行期兑现）/core DTO 键缺席（lossless 根因）/justfile powershell+firstWindow 预算——均为缺陷修复非设计偏离，逐条记账于 5.4 record。
- **[5.2] onRegistered 协作者缝（Interface 5）在场未接线**: 建库归 ensureOpen 惰性首开单径自洽（派生行「实际建库位置」断言经首次 forge 域触达后成立）；接线与否归后续裁决——留痕非偏离，后续任务消费本缝前必读本条。
- **契约面零偏离总结**: 阶段 5 未改 contracts 词汇/签名/错误码池；tech-design Testing Strategy e2e 行全判据落地（SC7/SC4/SC6③/SC2/SC-branch/疑似移动/B.5 六锚/审计四锚）+ dogfood 门全 AC 通过；「P1 口径升级：M2 预建 replay 层」逐字兑现（录制-回放三件套 + 真实模型仅 dogfood 门与录制源）；全部偏离均为载体级/口径细化/前提级裁决且逐条记账（各 record keyDecisions）。
