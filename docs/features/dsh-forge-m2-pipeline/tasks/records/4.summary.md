### 4. Conventions Established

- **两段注册纪律（官方口径）**: adding a type is a registration, never an edit——新 tab 类型恒走 sidebarRightTabs.register 定义段 + sidebar.right.pane.tab keyed body 段；useTabInfo 由 seat 声明 inject 恒递达占用者。
- **槽位 order 约定**: 产品注册恒排官方带之前（overview guide order 0 < 官方 10/20/30；header.actions -100 < 官方 -30/-20/-10/20）——产品入口不与官方动作争序。
- **单库解析纪律**: 恒复用 projectAnchorOf（会话锚定优先 retainedBy → workspace → 唯一项目兜底）——禁全库扫描 Hard Rule 由恒单 projectId 入查询机械承载；sessionId/useWorkspaces 等 session 作用域标准货币自动递达，占用者数据自持。
- **nonce 对照消费形制**: 桥快照持久 last-focus + 消费侧 nonce 对照（无 consume 清除往返；重复点击 nonce 恒新恒生效）；挂载初始态 useState 初始化器+效应双径承接（SSR 零 effect 可静态断言）。
- **受控覆盖释放形制**: 受控 featureSlug 覆盖经 onFeatureUserSwitch 上抛释放（受控优先语义与可切换 UX 兼得）——受控面恒带释放径，不留死锁态。
- **RPC 依赖注入面形制**: DeriveSource 注入面 + rpc 真身 + 纯异步相位映射（dir-source 同形制）——装载壳预检 effect 复用可测面，相位映射纯函数直测。
- **拒绝零副作用+闭包复检恒权威**: UI 预检只禁用确认（issues ∨ suspected-move 禁用；loading/error 不阻断），注册闭包复检为最终权威——预检在途/兜底错误永不阻断主流程。
- **形状守卫纪律**: 外部 RPC data 载荷恒形状守卫（ERR_SUSPECTED_MOVE 三串守卫——guidance 单源 core，畸形回落通用兜底零捏造）。
- **字面量同源 pin**: 跨文件常量（dsh-resource:// 地址形制等）经 plugin.test 字面量断言钉同源——classic script 与装配体两侧零漂移。
- **撤销面对称性**: 注册面撤销恒双径（apply catch + overlay 洞 dispose）——半途失败步步可撤，官方注册表 kind 不残留（fix-33 ⑥）。
- **effect 编排面归 e2e 口径**: renderToStaticMarkup 零 effect——装载重拉/事件订阅/桥订阅驱动/聚焦应用恒归 5.2 e2e 断言（写后单次重取见新值+全链路），单测只锚纯函数与静态呈现。
- **共享 worktree 卫生**: 选择性暂存（仅暂存本任务触达文件，他人未提交改动不掺入提交）——多会话共用 worktree 的提交纪律。

### 5. Deviations from Design

- **[4.1] 概览上下文载体=桥快照缝**(载体级裁决): tech-design Integration #5 言 ShellHost 锚定复用（会话优先 retainedBy.mainView/唯一项目兜底）未列载体——实落桥扩 setOverviewContext 缝（{drawerEntryId, overview} 双缝独立，桥=shell.overlay 树与 rightbar 会话树既有唯一通道复用）；锚定语义与设计逐字一致，仅载体显式化。
- **[4.2] featureSlug 富化径收紧**(单库纪律加强): tech-design Integration #2 数据源言 sessionId/workspace 解析自账本+事件订阅——featureSlug 取 card.slug 字段映射（身份双轨不变量 slug ≡ feature slug），比 3.10 注记预期的 feature 账本 enrich 更严（零额外 RPC）。
- **[4.3] DerivedTaskStorePhase 增第四态 error**(3.11 判别联合扩容): 3.11 落地三态（loading/ready/suspected-move），4.3 依 tech-design Propagation「未映射码 → 通用错误条」增 error 兜底态——preload 缺席/服务未注册/畸形载荷永无裸 code 泄漏、不卡死骨架。
- **[4.3] 复检触发面补强**: tech-design Integration #1 言「值改 RPC 下发+ERR_SUSPECTED_MOVE 错误条」——实现在 workspaceDir 值变更外增改选 nonce 触发（同路径重选也复检），覆盖手工指引「处置孤儿目录后重试」径；设计未显式列出，为拒绝路径闭环补强。
- **[4.1→4.2] G1-16 槽面拆分执行**: header.actions 槽面声明由 4.1 pin-09 先锚（上游公开面），注册本体归 4.2——按任务边界拆分执行，非语义偏离。
- **契约面零偏离总结**: 阶段 4 未改 contracts 词汇/签名/错误码池；五处 Integration（#1-#5）全部落地且 Insertion Point 逐字对齐（RegisterForm L219-223 整行替换/plugin.ts 槽注册/sidebarRightTabs 两段注册/ShellHost 锚定复用）；三签不动 Hard Rule 全程遵守（零左栏/中区/conversation.view 改动——纯右栏+会话头带+表单派生行官方缝内新增）；全部偏离均为载体级/补强级裁决且逐条记账（各 record keyDecisions）。
