### 4. Conventions Established

- **通道族三处一体纪律**: contracts → web/rpc client → host ipc/preload 四层同步增改（allowlist+satisfies+AssertNever 完备性）；新服务法先落 contracts 再镜像，注册面不留私扩通道。
- **写动词 RPC 禁令机械锚**: SC7 落点=ipc 注册面注入类型 Pick 收窄（add/claim/submit/createProposal/transitionProposal 不上 RPC），桥面与 RPC 面分层；G1-11 pin 六 tool 在场两缺席。
- **UI 组件三层分工形制**: 纯模型（纯函数直测）+ Body 纯渲染（renderToStaticMarkup 直测、零 hook）+ 装载壳（effect 胶水归 4.x 装配+e2e 面）——overview/drawer/transition-dialog/session pills/derived-store-row 全族同形制。
- **搜索/过滤/排序服务端承载**: 全为 RPC 查询参零本地过滤行；测试经通道捕获断言负载（Hard Rule）；三视图统一 vis 集单源（tasks.list 查询参）。
- **SPEC CONTRADICTION 裁决模式**: 数据形状权威（tech-design Interface）>ui-design 结构字面；更具体指令（§注记/原型/已建组件）>结构图；接口位留待契约扩法（FeatureTab.docs 形制——补 API 后直接接线零改动）。
- **令牌唯一硬规则+dsw-raw 豁免注记制**: 无上游令牌时最近似映射+CSS 头部注释/记录注记（排版 13px 档收敛、几何刻度布局常量单源）；官方组件原子面缺口（Pill 静态分支不透传锚）双载体自绘。
- **组件零自算/props 驱动**: 数据与错误载荷恒外部注入（判别联合单 prop 形制 DerivedTaskStorePhase）；同级业务互禁 import——本域副本+口径互指注记（SESSION_PILL_STATUS_DOT 先例）。
