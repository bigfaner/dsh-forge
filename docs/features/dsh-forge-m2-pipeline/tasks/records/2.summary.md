### 4. Conventions Established

- **写动词固定形制**: typed 校验先行（拒绝零副作用）→ 单事务全成全败（写前 assertPhaseInvariant 漂移断言 → 写 → derivePhase 重算）→ 事务提交后 emitTasksChanged(projectId) 闭包尾部单发（同通道同载荷 {projectId}；拒绝面零发射）。
- **四域互禁 import 彼此**(tasks / features·proposals·docs / workspace 协作者面): 共享逻辑经装配层 deps 注入（state-machine/phase-deriver）或域内单份（matchesSearch/排序助手），零第二实现零 import 边违规。
- **exhaustive Record 编译期穷尽 + 键集测试锚定 contracts 词汇**: AGENT_TRANSITION_MATRIX/DOC_KIND_PHASE/FEATURE_STATUS_ORDER/templates 路由表先例——加 TaskStatus/DocKind/FeatureStatus/TaskType 值即编译红。
- **actor 通道推断恒定**: tool 专属动词 'plugin-tool'、系统内聚效果(auto-block/auto-restore)'core'、人工转移 'ui'——append-only 记录为审计单源（reason 不落列，重入写无状态效应记录）。
