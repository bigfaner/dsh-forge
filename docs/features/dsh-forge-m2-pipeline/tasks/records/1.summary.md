### 4. Conventions Established

- **三处一体纪律(通道/DTO 变更)**: contracts → web/rpc → host ipc 必须同改;web 侧 Record<ErrorCode> 全码穷举为故意设计——contracts 增码不携映射 = web 编译红 + 测试红(防腐层)。
- **通道面规则**: allowlist 数据单源 = Object.values(FORGE_CHANNELS);events 通道不入 invoke 面;写动词(add/claim/submit/createProposal/transitionProposal)不上 RPC(agent tool 专属);平铺键跨族重名加族前缀。
- **契约 pin 测试形制(G1)**: 词汇精确表 + 标签键集等价 + 封闭集断言 + 错误码行序 + 身份双轨恒含 + 负载映射键 ↔ 族常量键 Exclude<…,never> 双向 + 信封 channel 常量本尊。
- **工作区存储纪律**: FORGE_DB_SCHEMA_VERSION 独立版本线(与中央 SCHEMA_VERSION 解耦);迁移单事务/版本;中央 state.db schema 零改动;结构健全性检查恒轻量(版本+foreign_key_check+表在场)。
- **fail-soft / fail-fast 分界**: 协作者(扫描/建库/onFirstCreate)失败 = fail-soft 记账不抛不断链;开库/迁移失败 = fail-fast 隔离(同一 error 实例复抛,单事件单条记账);动词校验失败 = typed error 先于写、单事务全成全败。
- **拒绝零副作用**: 注册类拒绝必须在中央行落库之前抛出,并以断言实证无行/无 create/无盘面变更/无记账。
- **铁律③**: forge/workspace 禁 import knowledge——解析器/工具薄自实现,不引第三方(gray-matter 等)。
- **测试环境免疫**: vitest coverage forks 池 process.send 在场——IPC 缺席断言须显式桩 process.send=undefined;pin 测试触发器体内分号需感知切分续接。
- **跨任务缝标注形制**: 源码注释以任务号锚定来源与承接方(如「1.4 缝——3.4 装配」「2.5 接线面」),装配缺省 = P1 行为零变化。
