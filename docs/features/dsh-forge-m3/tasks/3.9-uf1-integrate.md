# 3.9: UF1 集成:TaskBoardPage 编排接入(工具栏/三视图/详情侧板)

## Description

UF1 existing-page 集成(Integration Spec #1):`views/TaskBoardPage.tsx` 工具栏接入派发/审批按钮;三视图(TaskDag/Group/List)接入选择模式(整面勾选 + ⤢ 详情 icon + 行首内嵌)与编排态角标;`tasks/detail/TaskDetailPanel.tsx` 接入编排分区与「派发执行」主按钮;审批 dock 与详情侧板同层互斥呈现(打开一时另一关闭,往返恢复对侧状态);任务数据消费 dispatch/approvals 动词与事件(编排态回流 ≤5s,属性级变更不打断焦点/滚动)。

## Acceptance Criteria

- [ ] 工具栏:M2 既有控件(视图/筛选/排序)不动,右侧追加「派发」与「审批 N」;M2 全部只读浏览交互在选择模式下保持可用。
- [ ] 三视图接线:选择模式覆盖 DAG/分组/列表三视图;角标谱呈现在卡片/行上;详情入口按选择模式命中区域规则(整面 = 勾选,⤢ = 详情)。
- [ ] 侧板编排:TaskDetailPanel 编排分区置于执行记录之上;审批 dock 与详情侧板互斥 + 往返恢复状态。
- [ ] 事件回流:dispatch_updated/approval_received 驱动角标与计数 ≤5s 更新,免手动刷新;不打断焦点/滚动。
- [ ] e2e 可见性:选择模式进入 → 勾选 → 派发确认链 → 角标呈现,在 `workbench/tasks` 页可观察(为 6.5 SC3 腿铺垫;本任务以组件级 e2e/交互测试断言)。
- [ ] M2 任务看板既有功能回归(三视图/详情/挂接历史不破坏)。

## User Stories

- Story 2: 看板派发与并行执行闭环(编排面完整呈现)

## Hard Rules

- 仅修改以下文件:`packages/plugins/forge-workbench/src/client/views/TaskBoardPage.tsx`、`views/tasks/detail/TaskDetailPanel.tsx` 及其引用 3.6-3.8 组件的接线文件;不改 M2 三视图组件内部逻辑(角标以包装/props 传入)。

### Test Impact
- Affected test suite(s): `client/views/`(M2 TaskBoardPage/TaskDetailPanel 既有用例)、M2 e2e 任务看板腿
- Expected fixture changes: 工具栏 DOM 断言追加新按钮;侧板结构断言新增分区;M2 e2e 腿断言若含「发起会话」按钮文案需演进为「派发执行」
- Risk level: medium
