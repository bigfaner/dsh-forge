# 1.5: 外部写自动重摄入与偏离标记:index.json 复现/变更 watcher + deviated 置位

## Description

T3 裁决(自动重摄入 + 偏离标记):已迁移项目(data_authority='sqlite')上 watcher 检出 `tasks/index.json` 复现或变更 → 幂等重摄入(复用 1.4 摄入+对拍)→ `projects.deviated=1` + `deviation_detected` 事件 + `migration_event(reingest)` 留档;不阻断外部会话(双形态纪律)。重摄入失败 → 偏离标记保持 + 日志,不弹 UI(M2 sync_state 模式延续)。

## Acceptance Criteria

- [ ] 已迁移项目复现 index.json(外部 CLI 写)→ 自动重摄入成功 → SQLite 与文件一致 + projects.deviated=1 + deviation_detected 事件 + migration_event(reingest/ok)。
- [ ] 幂等:同一外部写多次触发不产生重复 task 行或半摄入;重摄入走同一对拍校验。
- [ ] 重摄入失败(如格式损坏)→ 偏离标记保持、事件照发、migration_event(reingest/fail)留档,不弹 UI、不阻断外部会话。
- [ ] 未迁移项目(files)不受影响:index.json 变更仍走 M2 感知路径,零行为变化。
- [ ] vitest 覆盖:复现/变更/损坏语料矩阵 + 双形态互斥路径。

## User Stories

- Story 8: 过渡双形态不破坏(已注册项目外部写被回收,双方数据互不破坏)

## Hard Rules

- 不阻断外部会话(零宿主侵入约束);回收失败仅可观察(标记 + 日志),禁止弹窗阻断。
