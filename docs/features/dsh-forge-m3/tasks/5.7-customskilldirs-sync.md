# 5.7: customSkillDirs 配置写入与漂移校验:boot 同步 + 路径前缀校验 + 清单 hash

## Description

D2 承载的机制面:应用 boot / 插件激活时写用户层 dsh 配置 `customSkillDirs` += 技能根(5.6 的 resources/skills 安装目录;去重);漂移校验(路径存在 + 15 项技能清单 hash)失败即重写;路径前缀必须 ∈ 插件安装目录(防任意目录注入技能面,T3);修复失败 → ERR_SKILL_DIR_SYNC 日志 + 设置面告警(不静默);版本升级时路径同步维护(路径漂移 = 应用责任)。

## Acceptance Criteria

- [ ] boot/激活:customSkillDirs 追加技能根(去重,不破坏用户既有其他目录项);写入后 dsh 会话可扁平名寻址 15 项技能。
- [ ] 漂移校验:路径缺失/清单 hash 不符(技能被增删改)→ 自动重写恢复;重写失败 → ERR_SKILL_DIR_SYNC 日志 + 设置面告警条目。
- [ ] 前缀校验:仅接受插件安装目录前缀路径;任意目录注入尝试被拒(T3)。
- [ ] 升级路径:应用升级致安装目录漂移 → 重新写入新路径并清理旧项(路径同步 = 应用责任)。
- [ ] vitest:首写/去重/漂移重写/前缀拒绝/告警矩阵。

## Hard Rules

- customSkillDirs 仅应用写入;配置写入必须含路径完整性校验(防任意目录注入技能面)。
- 失败显式告警不静默(boot 日志 + 设置面)。
