# 1.7: UF3 集成:ProjectCard 迁移入口 + 注册向导条件迁移步骤 + 文档根默认仓外翻转

## Description

UF3 集成面:①概览页 ProjectCard 操作行接入「迁移」sm ghost + 可迁移 Pill(检出 index.json 的已注册项目);②注册向导检出 index.json 时插入条件「迁移确认」步骤(StepExternal 与 StepSummary 之间,四步形态;开关默认开,关闭 = 只读兼容态注册);③向导第④步确认后步骤内容区原地演进为迁移进度呈现(复用 1.6 进度组件,不嵌套对话框;失败可「以未迁移态完成注册」);④注册向导文档位置默认值翻转:仓外文档根默认(应用管理路径),仓内为可选项(G7/SC9)。

## Acceptance Criteria

- [ ] 概览页:检出 index.json 的已注册项目呈现「可迁移」Pill + 「迁移」按钮;点击进入 1.6 确认链;迁移完成后 Pill 与按钮消失(e2e 可见性:workbench/overview 项目卡区位)。
- [ ] 注册向导:检出 index.json → 步骤点三圆变四圆,迁移确认步骤插入 ②与③ 之间;开关默认开;关闭则注册为兼容态,卡片持续「可迁移」。
- [ ] 向导内迁移:第④步确认后步骤区原地演进为进度呈现,向导整体锁定(Esc/✕/mask 无效);完成 = 对拍结论 + 进入工作台;失败 = 回滚说明 + 重试 + 「以未迁移态完成注册」。
- [ ] 文档根默认值翻转:注册向导文档位置步骤默认 = 仓外应用管理路径,仓内可选;既有仓内项目读写兼容不破坏。
- [ ] vitest + jsdom:向导条件步骤插入/跳过两路径 + ProjectCard 迁移入口呈现判定。

## User Stories
