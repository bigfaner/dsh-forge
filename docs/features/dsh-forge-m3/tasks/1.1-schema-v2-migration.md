# 1.1: schema v2 迁移段:store MIGRATIONS {version:2}(2 组 ALTER + 7 表 + 5 索引)+ 漂移对账

## Description

## Acceptance Criteria

- [ ] v2 段在自有事务内顺序执行:2 组 ALTER + 7 张 CREATE TABLE 一次成功,所有 FK 引用可解析,5 个索引全部建立。
- [ ] 漂移对账测试:`design/schema.sql` v2 段 ↔ `schema-v2.ts` 内联常量逐语句对账全绿(v1 先例延续)。
- [ ] 版本纪律:schema_version 单行只进不退;v1 库升级到 v2 幂等重跑 no-op;库版本 > 已知迁移即拒开(ERR_WORKBENCH_DB)。
- [ ] CHECK 生效验证:task.status 7 态、dispatch.state 5 态、approval_request.state 3 态、prefs.scope、stage_asset.stage、proposal_snapshot.status、migration_event.phase/result 违规写入均被拒。
- [ ] M2 v1 表与既有数据零破坏(升级路径:v1 库迁移后 v1 表内容原样)。
- [ ] vitest 覆盖:全新建库(v1+v2)、v1→v2 升级、幂等重跑、CHECK 拒写、拒新库。
