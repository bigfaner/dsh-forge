# 1.6: UF3 组件:迁移 Pill + 确认/进度(close-guard)/失败回滚对话框族

## Description

UF3 显式迁移的组件层(可 mock 动词独立构建):MigrationPill(可迁移 warn/已迁移 success)+ 迁移确认对话框(r24,宽 min(520px,100vw-48px),含备份路径 mono 与步骤说明)+ 进度/结果对话框(校验/迁移/对拍步骤行,执行中 Esc/✕/mask 全部无效的 close-guard,成功态对拍结论、失败态回滚说明 + 重试)+ 在跑编排守卫态(disabled + tooltip + ≤5s 自动恢复)。订阅 migration_progress 事件驱动步骤推进。

## Acceptance Criteria

- [ ] 组件态机覆盖 ui-design States 六态(migratable/confirming/migrating/done/failed-rolled-back/向导路径态由 1.7 复用),mock 动词驱动转换正确。
- [ ] 进度对话框 close-guard:执行中 Esc/✕/mask 点击全部无效(Esc 不注册关闭);done/failed 态可关。
- [ ] 步骤行枚举 = 校验/迁移/对拍(备份并入校验步行内呈现路径);成功态呈现对拍结论,失败态呈现回滚说明 + [重试]。
- [ ] 守卫态:在跑编排 → 迁移入口 disabled + tooltip;守卫解除随事件 ≤5s 自动恢复。
- [ ] vitest + jsdom 视图主路径:确认→进度→完成、确认→进度→失败→重试两条链。

## User Stories

- Story 1: 显式迁移到数据内核(确认 + 自动备份说明 + 原子进度 + 对拍结果 + 回滚重试)

## Hard Rules

- 迁移必须显式确认,无自动/静默迁移路径;执行中不可放弃(原子性口径)。
- 双语经上游 locale 机制;全部组件双主题语义别名。
