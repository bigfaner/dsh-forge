# 3.4: 预合成引擎:三要素组装(协议/目标摘要/生效偏好)+ prompt_hash + 模板移植

## Description

Interface 3 预合成(内核,确定性):dispatch 服务组装三要素——①任务类型协议(spike④ 移植面清单:任务类型 → 协议文本映射,模板权威源 = forge-cli `pkg/prompt/templates` + `pkg/task/templates`);②feature 目标/摘要(stage_asset 最近资产);③生效偏好(prefs 三级解析)→ 完整注入内容字符串(契约形态随 spike③ 裁决);`prompt_hash` = sha256(注入内容,口径随 spike③)落 dispatch 行(SC3 断言锚点)。内核视为不透明传输(仅保证字符串完整交付);模板常量组装,不 eval、不拼接指令语义(T2 缓解)。

## Acceptance Criteria

- [ ] 三要素注入内容断言:给定任务(带 task_type)+ feature(含 stage_asset)+ 三级偏好,组装产物逐段包含协议文本、目标摘要、生效偏好(单测逐字符断言)。
- [ ] prompt_hash 落库且 = sha256(注入内容,spike③ 口径);hash oracle 复用 M2 e2e channel stub journal 逐字符比对形态(接口预留)。
- [ ] 模板映射:spike④ 清单全覆盖(任务类型协议逐类型);模板为内核常量,禁 eval/动态拼接指令语义。
- [ ] 动态性:feature 摘要更新或偏好变更后再派发,产物反映最新值(Story 3 AC3);无 stage_asset 时的行为按 spike③/④ 结论显式定义并有断言。
- [ ] vitest 行覆盖 ≥80%(三要素组合矩阵 + hash 口径)。

## User Stories

- Story 3: 派发即得预合成专业化上下文(三要素一次性合成,断言锚点)

## Hard Rules

- 预合成为确定性内核代码:三要素均为文档数据,经模板常量组装;禁模型调用、禁 eval、禁拼接指令语义(T2)。
- 注入内容对内核不透明:仅保证字符串完整交付,不解释内容。

## Implementation Notes

- 文件清单:`apps/desktop/src/main/workbench/dispatch/presynth/`(templates.ts 移植常量 + assemble.ts + hash.ts)+ spec。
- 取代 forge prompt:本引擎落地后任务派发不再有任何 `forge prompt` 自跑路径(断言用例)。
