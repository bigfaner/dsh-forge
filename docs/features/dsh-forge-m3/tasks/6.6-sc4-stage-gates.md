# 6.6: SC4 e2e:阶段硬门(警告不阻断/门拒绝/资产渲染/新阶段注入/偏离标识)

## Description

SC4 验收腿:当前阶段产物不齐全 → 派发呈警告 + 缺失清单,确认后可继续(不阻断,确定性代码断言无模型调用);阶段总结未生成 → 推进被拒 + 可观察引导;总结生成(经 forge.stage.summarize stub/直写)→ 推进成功 → 文档根存在阶段资产文件 + 工作台面板只读渲染 + 新阶段会话系统提示词含目标 + 摘要(注入断言);外部会话跨阶段操作 → 看板偏离标识,不硬阻断。

## Acceptance Criteria

- [ ] 警告不阻断:产物缺失语料 → 派发呈现警告 + 缺失清单 → 确认后派发成功(检查路径零模型调用,e2e 侧以 stub journal 断言无模型通道流量)。
- [ ] 门拒绝/放行:总结未生成 → advanceStage 拒绝 + 引导(看板可观察);生成后 → 推进成功。
- [ ] 资产:推进后文档根存在 `stages/<stage>.md`;Feature 详情「阶段资产」tab 只读渲染其内容(内容一致断言)。
- [ ] 新阶段注入:推进后新派发/新会话注入内容含最新目标 + 摘要(journal 断言)。
- [ ] 偏离:外部直改 manifest status(测试内模拟)→ 看板偏离徽标呈现;外部操作不被阻断。
