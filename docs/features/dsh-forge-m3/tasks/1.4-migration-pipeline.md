# 1.4: 一次性显式迁移管线:守卫/备份/摄入/对拍/切读/归档 + migration_event 审计

## Description

Interface 4 迁移管线 8 步中的 1-6 步(内核侧):①守卫(dispatch.ended_at IS NULL 计数 >0 → ERR_MIGRATION_GUARD);②备份(`<userData>/workbench/backups/<projectId>-<ts>/` 库文件 + 文档树 tasks/ 拷贝);③摄入(单事务全量 index.json → task 行:字段映射 + 限定地址合成 + task_type/desc_path 推断);④对拍(task 表 vs task_snapshot 派生投影,限定地址/状态/依赖/标题零差异;差异 → 回滚 + ERR_MIGRATION_VERIFY);⑤切读(data_authority='sqlite' 同事务置位);⑥归档(index.json → index.json.migrated-<ts>;失败 → 整体回滚备份,零半迁移)。动词 getMigrationStatus/startMigration + migration_progress 事件 + migration_event 7 相审计。

## Acceptance Criteria

- [ ] 全链(tmp 树 fixture):守卫 → 备份 → 摄入 → 对拍 → 切读 → 归档顺序执行,完成后 data_authority='sqlite'、index.json 变为 .migrated-<ts>、任务全集对拍零差异。
- [ ] 原子性:注入失败(摄入中/对拍差/归档失败)→ 整体回滚至备份,库与文档树回到迁移前态,零半迁移;重试幂等可成功。
- [ ] 守卫:在跑编排存在时 startMigration 拒绝(ERR_MIGRATION_GUARD);迁移中重复发起 → ERR_MIGRATION_IN_PROGRESS。
- [ ] md 纪律:`tasks/*.md` 与 `tasks/records/*.md` 全程不迁移不改动(fixture 断言 mtime/内容不变)。
- [ ] migration_event 逐相留档(backup/ingest/verify/switch/archive/rollback,result + detail_json 含对拍报告),migration_progress 事件按 phase 推送。
- [ ] vitest 行覆盖 ≥80%(全链 + 各相注错回滚矩阵)。

## User Stories

- Story 1: 显式迁移到数据内核(确认/备份/原子/对拍/淘汰;失败回滚可重试)

## Hard Rules

- 迁移原子性:data_authority 置位与 task 全量摄入同事务;归档文件操作失败 → 整体回滚备份,禁止任何半迁移中间态对用户可见。
- 备份落 userData 默认权限路径;库文件不含凭据(T6)。
