# 3.1: prefs 内核域:单表 scope 化仓储 + 键注册表 + 三级解析 + 动词/事件 + forge.pref.get

## Description

偏好三级内核域(预合成与编辑面的共同前置):prefs 单表 scope 化仓储(scope,scope_id,key PK;global scope_id=''/project=项目id/feature=`<projectId>/<featureSlug>` 限定地址);键注册表(键集 = auto.\*/worktree.\*/eval.\* 全量,surfaces 除外;含类型元数据 toggle/数值/文本,暴露给 UI 不硬编码);三级生效解析 feature > 项目 > 全局;动词 getPrefs(含生效值+来源)/setPrefs(事务原子 + 键集/类型校验)/clearPrefOverride + prefs_updated 事件;forge.pref.get tool 注册(读生效值)。ERR_PREF_KEY_UNKNOWN/ERR_PREF_VALUE_INVALID。

## Hard Rules

- 键集封闭:仅注册表内键可写;surface 类键禁入继承链(D3)。
- 键 → 控件类型映射权威 = forge config 键定义(forge-cli pkg/forgeconfig),应用侧消费不复制语义。
