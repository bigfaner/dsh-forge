# 4.3: UF2 组件:stepper 门态 + 偏离徽标 + StageAssetsTab 分组卡

## Description

UF2 阶段化组件层(mock 动词可独立构建):StatusStepper 强化(当前阶段节点门未满足 = warn 描边 + 下方 12/18 提示行「总结未生成——推进需先生成阶段总结」,hover 引导生成路径)+ GateHint(可推进/拒绝态与缺失清单引导)+ 偏离徽标(warn Pill「偏离」,hover tooltip,零点击动作)+ AdvanceStageButton(推进动作,门拒绝 → ERR_STAGE_GATE_UNSATISFIED 引导呈现)+ StageAssetsTab(按阶段分组卡:r14 · bg-layer-2 · pad 14;头部阶段 Pill + 生成时间;目标/摘要两段只读 markdown 渲染经 MarkdownView 白名单;空态「尚无阶段资产」+ 说明)+ feature 卡偏离徽标追加。

## Acceptance Criteria

- [ ] stepper 门态:normal/gate-pending 两态(门未满足 = 当前节点 warn 描边 + 提示行);completed 前 5 阶段遍历呈现正确。
- [ ] 偏离徽标:deviated=true 呈现(卡 + 详情);hover tooltip;零点击动作。
- [ ] StageAssetsTab:分组卡自旧到新;目标/摘要只读渲染(MarkdownView 白名单,渲染区无交互元素);空态;新资产 0.2s 淡入。
- [ ] 推进动作:门拒绝 → 引导文案 + 缺失清单;成功 → stage_advanced 事件回流(≤5s)。
- [ ] vitest + jsdom:门态/资产渲染/推进链主路径(mock 动词)。

## User Stories

- Story 4: 阶段门与上下文跨阶段传递(门态呈现 + 资产只读查看面)

## Hard Rules

- 阶段资产面板严格只读(无编辑入口);渲染经 MarkdownView 白名单(防注入,渲染区无交互元素)。
- 偏离标识仅为呈现,不产生阻断交互。
