# 4.1: stages 写侧与推进门:forge.stage.summarize + advanceStage 门内化 + stage_advanced

## Description

阶段化写侧(T4 单一规范文件):①forge.stage.summarize tool(agent 会话写阶段资产 `features/<slug>/stages/<stage>.md`,frontmatter {stage,generated,goal} + 正文摘要,文档根直写);②advanceStage 动词:门校验(阶段总结已生成 = stage_asset 存在)不满足 → ERR_STAGE_GATE_UNSATISFIED 拒绝 + 引导;满足 → 内核写 manifest status(阶段推进内化,归宿表 feature set/complete)→ stage_advanced 事件;③新阶段会话强制注入目标 + 摘要(预合成链消费 stage_asset,3.4 已建消费位点,本任务接通推进后链路)。
