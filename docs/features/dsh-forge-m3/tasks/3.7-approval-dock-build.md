# 3.7: UF1 组件·审批 dock 与编排角标:ApprovalPanel + 角标谱 + tab 计数徽标

## Description

UF1 审批面组件层:ApprovalPanel(右侧 dock 宽 min(440px,45vw),与任务详情侧板同构互斥;条目 = ID mono + 标题次文字 + 请求正文 14/22 ≤3 行截断 + 展开;拒绝 ghost 左/批准主右;「详情 ↗」切详情侧板 + 「◂ 返回审批(N)」恢复剩余条目与滚动位置)+ 编排态角标谱(待启动中性描边/执行中品牌蓝+呼吸点/待审批 warn 可点打开 dock 并定位/失败 error/已提交 success 一闪 0.3s 回落)+ 工具栏「审批 N」warn Pill 按钮(N=0 隐藏)+ 任务 tab 标签右上 warn 计数徽标(工作台级指示,aria-label)。批准 → 回执行中;拒绝 → 转 failed + 原因「审批请求被拒绝」。

## Acceptance Criteria

- [ ] 角标谱五态与 dispatch.state 一一对应(枚举映射表 + 未知值兜底 = 数据原值透出中性 Pill);「待审批」可点 = 打开 dock 并滚动定位对应条目。
- [ ] 审批操作:批准/拒绝仅显式点击(无默认自动批准);批准 → 条目滑出 + 任务回「执行中」角标;拒绝 → 「失败」角标 + 原因呈现;N-1 同步(工具栏按钮 + tab 徽标)。
- [ ] 「详情 ↗」/「◂ 返回审批(N)」往返:恢复剩余条目与滚动位置,上下文不断路。
- [ ] approval_received 事件到达 → dock/角标/计数 ≤5s 更新(订阅驱动,免手动刷新);aria-live 播报节流口径(2s 窗口终态 + 批量聚合计数)。
- [ ] 失效/已决条目操作 → 刷新 + toast(ERR_APPROVAL_DECIDED/NOT_FOUND 路径)。
- [ ] vitest + jsdom:审批往返/互斥/角标迁移/事件驱动主路径(mock)。

- Story 2: 看板派发与并行执行闭环(审批可见可操作面)

## Hard Rules

- 审批纪律:仅显式点击,无默认自动批准;审批到达仅呈现提示,不弹模态。
- 「审批 N」Pill 按钮契约按 Button(Tab 可达/Enter/Space 触发/focus ring),不另设组件类目。
