# 3.6: UF1 组件·选择模式与派发链:工具栏入口 + 多选 + 浮动条 + warning/confirm 对话框

## Description

UF1 派发链组件层(mock 动词可独立构建):「派发」工具栏按钮(md 主,无可派发 disabled + tooltip)+ 选择模式(checkbox 28×28 r14 原语,卡片左上覆盖/列表行首内嵌;整面点击 = 切换勾选;⤢ 详情 icon;依赖未满足/终态 disabled + tooltip)+ 浮动操作条(z200,已选计数 + 取消 + 派发所选)+ warning 对话框(产物缺失清单 mono 逐行 + 继续派发/取消,不阻断)+ confirming 对话框(所选列表 + 三要素说明)+ dispatching spinner 态与超时错误。键盘契约:Tab/方向键遍历、Space = 勾选、Enter = 详情、Esc 分层(对话框开 = 关对话框留选择模式;否则退出并清空)。

## Acceptance Criteria

- [ ] 选择模式:进入后 checkbox 显现;整面点击切换勾选;依赖冲突/终态项 disabled + tooltip;已选计数实时更新。
- [ ] 键盘契约:Tab/方向键遍历卡片;Space = 切换焦点卡片勾选(覆写 M2 Enter/Space 语义仅在选择模式内);Enter = 打开焦点卡片详情;浮动条入场后 Tab 可达。
- [ ] Esc 分层:warning/confirming 对话框开 → Esc 关对话框、留在选择模式、已勾选保留;无对话框 → Esc 退出选择模式并清空已选。
- [ ] warning 对话框呈现缺失清单(mono 逐行),「继续派发」= acknowledgeMissing 进 confirming;「取消」回到选择模式;产物齐全直接进 confirming。
- [ ] dispatching 态:按钮 spinner;超时 → error 对话框 + 重试入口;全程不打断看板其余交互。
- [ ] vitest + jsdom:选择/键盘/对话框链主路径(mock 动词)。
