# 0.1: spike① dsh tool 注册契约:renderer 桥时延与启动竞态实测(T2 可用性确认)

## Description

验证 T2 裁决(renderer 桥接:host cordis rpc → client 半身 tool 桥 → 既有 `dshForge.workbench.*` IPC 白名单)的可用性。以 vendored `plugin-manager/tools.ts` 先例为起点,回答:①dsh model-facing tool 注册的契约(名称/schema/handler 形态);②host 半身注册的 tool 能否经 cordis rpc 到达 client 半身并转发 IPC;③桥的时延量级与启动竞态窗口(UI 未装载/插件激活顺序);④失败兜底(重试一次后 `ERR_TOOL_BRIDGE_UNAVAILABLE`)是否成立。产出结论与兜底建议,门控 2.1。
