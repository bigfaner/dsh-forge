# 3.8: UF1 组件·详情侧板编排分区:派发执行主按钮 + 编排态/重派发/预合成要素行

## Description

M2 UF3 任务详情侧板的 M3 演进组件:头部「▶ 派发执行」md 主按钮(整宽;M2「发起会话」同位同形演进,无执行条件 disabled + tooltip;等价单任务派发捷径)+ 新增「编排」分区(置于执行记录之上):当前编排态 + 派发时间 + [进入会话](sm ghost,切会话视图 session-focus)+ 失败原因 + [重派发](sm ghost,二次确认 RedispatchDialog:标题 + 原因回显 + 重走检查/预合成说明)+ 预合成要素行(「协议 ✓ · 目标摘要 ✓ · 偏好 ✓」12/18,tooltip 三要素来源)+ 待审批时 [去审批](sm 主,切审批面板)。

## Acceptance Criteria

- [ ] 「派发执行」主按钮:依赖/终态不满足 disabled + tooltip;可执行时发起单任务派发(等价选中 1 项,走检查→确认链)。
- [ ] 编排分区:当前态 + 派发时间 + 会话链接(进入会话 = 切会话视图 + session-focus 定位)+ 预合成要素行(三要素 ✓ 与 prompt_hash 元数据);失败时原因 + 重派发可用。
- [ ] 重派发:二次确认对话框(原因回显);确认后重走检查 + 预合成;拒绝路径回侧板。
- [ ] 待审批态:[去审批] 切换到审批面板(侧板互斥编排由 3.9 接线)。
- [ ] vitest + jsdom:按钮态/分区内容/重派发链主路径(mock)。
