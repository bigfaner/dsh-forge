# 4.2: 偏离检测:外部跨阶段操作 watcher + feature_snapshot.deviated + 事件呈现

## Description

feature 级偏离检测:watcher 检出非内核发起的 manifest status 变更(外部会话跨阶段操作,如终端 CLI / 冻结 CC 插件)→ `feature_snapshot.deviated=1` + `last_external_at` + `deviation_detected` 事件(featureSlug);仅呈现不阻断(外部会话不硬阻断,看板偏离标识);项目级偏离(1.5 index.json 复现)事件复用同通道。偏离后内核状态同步策略:外部推进 = 读侧跟随(manifest 仍为 feature 阶段事实源之一),deviation 标记持续至人工确认清除策略(最小实现:呈现 + 事件,清除 = 下次内核合法推进)。

## Acceptance Criteria

- [ ] 外部 manifest status 变更(非 advanceStage 路径)→ feature_snapshot.deviated=1 + last_external_at + deviation_detected 事件(featureSlug)。
- [ ] 内核合法推进(advanceStage)不触发偏离;偏离标记在下次内核合法推进时按定义清除(行为有测试)。
- [ ] 不阻断:外部操作全程无拒绝/弹窗;检测失败仅日志(感知面纪律)。
- [ ] 事件推送 ≤5s;项目级(1.5)与 feature 级偏离事件同通道不同载荷。
- [ ] vitest:外部变更/内核推进/清除矩阵。
