### Key Decisions
- Detection invariant = live manifest status ≠ pre-scan feature_snapshot.status: advanceStage writes manifest + snapshot as consecutive sync statements (single-threaded event loop, no scan can interleave), so divergence is exactly the non-kernel change set — no kernel write-ledger needed
- Hook runs before the scan (services seam) so the pre-scan snapshot is observable; the scan then follows the manifest, making repeat scans silent (same external change reports once; a new change reports again with a refreshed last_external_at)
- Clear semantics per task definition: next kernel-legal advanceStage flips deviated to 0 and preserves last_external_at as audit; gate rejection and terminal completed no-op are not legal advances and do not clear
- Kernel-unknown features (no snapshot row) stay on the M2 structural-new path — not deviation; unreadable/out-of-vocab manifests emit no signal (scan failures carry that face)
- No deviated-flag event dedup: the follow invariant is the dedup; batcher coalesce key extended to deviation_detected|projectId|featureSlug so project-level (1.5) and per-feature events never swallow each other in one 500ms window
