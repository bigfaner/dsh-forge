## Conventions Established
- 工具命名纪律：一律下划线扁平名 forge_<族>_<动词|action>（provider 字符集拒绝点号）；一族一工具 + action enum（plugin_manager 先例），桥/IPC 动词面保持封闭小集。
- 新工具族一律经 2.1 基座三段式追加注册（defineTool 挂 base ToolRuntime root context 全局工具 → 封闭桥动词 → 白名单 IPC 通道），host 侧零 fs 直访、零新端口/零新监听面。
- 结果语义分流契约：业务拒绝以 canonical JSON 值返回（{ok:false,code,message,detail}），仅 transport 降级（重试一次已尽）throw ERR_TOOL_BRIDGE_UNAVAILABLE 上抛会话 — Story 9 禁静默。
- 双闸防御：工具面做形态校验（taskKey 白名单/路径段校验），语义不变式与 resolved 包含复验归内核 — renderer 被攻破不构成越权通路（T4）。
- actor 纪律：exec.agent.session.id ?? exec.agent.id 推导 session:<id>，缺失 fail-closed throw，绝不误记 'external'；审计/事件失败留痕优先（1.summary 延续）。
- forge CLI 数据面对等：知识系文件布局/条目形态/排序词表以 Go 源为准移植（fact-table.json、frontmatter 方言、created-desc/mtime）；与设计差异显式记录为偏差。
- 路径安全：traversal/绝对路径/控制字符在工具面拒绝 + 内核 resolved 包含复验（ERR_KNOWLEDGE_PATH_*）。
- 测试落位延续 1.summary：desktop 侧 apps/desktop/tests/workbench-*.spec.ts，插件侧 packages/plugins/*/tests/；机器无关性经可注入 deps（forensicHomeDir 先例）；装饰器壳经 tsc 产物测试（工作区测试 transform 不降级标准装饰器）。
