## Conventions Established
- IPC 动词接线五件套:ipc/types → channel-allowlist(主/preload 双侧同源 drift 锁)→ handlers 形状校验 → services 装配 → preload 暴露;事件一律入 WorkbenchEvent v2 联合 + 批推合并键 + 动词完成单批直发。
- 域错误码 ERR_* 惯例:设计错误表无行时按地址空间既有码扩展 + 注释钉定(ERR_DISPATCH_NOT_FOUND/STATE_INVALID、ERR_PREF_SCOPE_INVALID、ERR_TASK_TYPE_NOT_DISPATCHABLE);IPC reject 原码透传。
- 内核 seam 装配纪律:services.ts 显式注入 + 缺省行为注释钉定接缝(checkArtifacts/composePrompt/launchPort);依赖未接线时 = 显式拒绝(ERR_SYSTEM_PROMPT_CONTRACT)或留态(starting),禁静默。
- forge-cli 权威对拍:键注册表/模板库/期望矩阵/预合成路由逐符号对齐 Go 源(pkg/forgeconfig、pkg/prompt、pkg/task);与 PRD/design 差异显式记录为偏差(SPEC CONTRADICTION 记录于执行过程)。
- 可派发语义唯一权威 = 内核(3.3):UI 面逐字镜像(pending|blocked + 依赖 completed/skipped + 悬空 vacuously satisfied),禁 UI 自创判定规则。
- client 动词缝签名逐字镜像 preload(输入形状、dispatched|blocked 联合、actor 串);组件 BUILD 层 mock 动词可独立构建,集成层接真 IPC,测试经 face 注入禁静默回退 mock。
- M2 视图零侵入扩展:交互契约经选择器 union(捕获相键盘拦截严格限选择模式相位),装饰经 additive render props(5.11 activeLinks 先例);选择模式下点击语义收窄在页面网关实现,不改视图 onClick。
- 三机常挂 hooks(选择控制器/审批 dock/详情链),无动词时入口 disabled 而非卸载;dock 互斥由 controller 单点编排。
- 新增控件原语走 ui-design 例外溢声明程序(checkbox 28×28 r14 先例);locale zh/en 双语键全量同步。
- 测试落位:desktop = apps/desktop/tests/workbench-*.spec.ts(真 node:sqlite),插件 = packages/plugins/forge-workbench/tests/(jsdom);decorator rpc 壳经 tsc 产物执行;覆盖率口径 = v8 lines 于本任务模块目录 ≥80%;lint 以 pnpm lint(oxlint)代跑,存量 e2e 错误未触碰不计;提交前按 worktree 门引导跑 prepare-host-runtime + pnpm build:plugins(陈旧 lib 会掩蔽测试债务)。
