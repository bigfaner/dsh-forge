### Key Decisions
- 可派发判定按内核(3.3 权威)而非原型:DISPATCHABLE_STATUSES={pending,blocked},依赖满足={completed,skipped}(rejected 不满足),悬空依赖 vacuously satisfied —— 原型的 pending-only 与 kernel 不一致,SPEC 优先
- ui-design「多选含互相依赖→后续者 disabled」被标准依赖规则蕴含(批内 blocker 仍 pending = 未满足依赖),无需独立规则;tooltip 统一「存在未完成依赖」
- 键盘契约在 SelectionLayer 捕获相拦截(preventDefault+stopPropagation)实现 M2 Enter/Space 语义覆写,且严格限 selecting 相位 —— 3.9 集成时三视图卡片仅需携带 data-dsh-forge-select-card 属性,零卡片内部改动
- 动词缝(checkStageArtifacts/dispatchTasks)逐字镜像 preload 3.3 签名(input 形状、dispatched|blocked 联合、actor 串);client 桥面接线归 3.9;多 feature 批每 distinct feature 一次 check 后合并缺失清单(kernel dispatchTasks 同型循环)
- dispatchTasks blocked 竞态返回 → 重开 warning 对话框(新清单),acknowledge 保留语境重走;超时(3s 预算)与 verb 拒绝共用 DispatchErrorDialog 双面(timeout=预算文案,failed=envelope message),重试保持 acknowledge 语境
- 文件清单在 Implementation Notes 基础上追加 DispatchErrorDialog.tsx(超时错误对话框,Description 明列)与 DispatchToolbarButton.tsx(工具栏入口,任务标题明列),均属 Description 组件枚举范围
- 取消/Esc(对话框)回选择模式保留已勾选;派发成功才退出并清空(ui-design Interactions 口径);对话框关闭后焦点回落浮动条派发按钮
