## Conventions Established
- Go 权威对拍：凡移植 forge-cli 行为，差异一律以 Go 源为准（基准 commit 644321da），行为基准 baseline.json 作为 fixture 提交；Go 无指定序的输出（map 迭代）做同秩去序归一后再比较。
- 权威 DDL 优先：design/schema.sql 为 schema 最终权威，内联 TS 常量承载同一 DDL 并以逐语句漂移对账测试强制同步；任务文案与 DDL 冲突按 DDL 落地并注释记录。
- 唯一写入口 + 单事务：task 表全部写路径（CRUD 动词/迁移摄入/重摄入）必经 task-repo；多步写包单事务失败整体回滚零半态；对拍 oracle（verifyMigrationParity）复用为重摄入事务内校验。
- IPC append-only 纪律：通道白名单主/预载双侧共享同源常量，新动词只追加，append-only 锁测试钉定既有段原样；异步动词经 handlers then 链异步拒绝同码封装。
- 测试落位：desktop 侧 specs 落 apps/desktop/tests/workbench-*.spec.ts（root vitest include 不含 src 旁路径）；插件侧落 packages/plugins/*/tests/。
- actor 审计：每笔写动词记 updated_by/updated_at；审计/事件行按需置于业务事务之外以保证失败留痕。
- 前端纪律：文案仅经上游 locale seat（zh/en 双语）；样式 inline 于 --dsh-alias-* 语义变量带回退（双主题）；迁移显式确认唯一路径、执行中不可放弃（close-guard）；Face 对象为 DI 开关（hostless 构建期缺席保持旧版面）且必须 useMemo 稳定。
- 文档树纪律：tasks/*.md 与 records/*.md 全程不迁移不改动；index.json 归档改名（.migrated-<ts>）而非删除，双形态非破坏。
