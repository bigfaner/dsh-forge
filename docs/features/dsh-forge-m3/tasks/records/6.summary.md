## Conventions Established
- env-seam 家族 stub 开关纪律(session-channel-stub 先例): DSH_FORGE_SESSION_STUB_DIR / DSH_FORGE_APPROVAL_STUB_DIR / DSH_FORGE_MIGRATION_FAULTS — unset/malformed = 生产行为零触碰;控制文件按 run 重读(绝不 boot 快照);注入驱动真核心,绝不旁路路由。
- Typert 单包单挂纪律: 远端描述符必须并入 FORGE_TOOL_BRIDGE_REMOTE_CONTRIBUTION 共享贡献(同包二次 $mount 即 already-registered 拒绝);配套模块槽 + 命名空间轮询安装器形态;动作成功后 fire-and-forget 投递、失败不上抛(host settle 晚到/重复幂等)。
- SC 腿补件先例: SC 全链验收暴露的接线缺口随任务补件并配单测(6.3 relay / 6.5 approval-answer / 6.6 detail 透传 / 6.7 reflux + 扫描分型);不可达面与覆盖边界在 spec 头注逐条登记,不静默。
- e2e 实例锁纪律: 跑前三形态检测(repo main.cjs/打包 exe/host-child 命令形),冲突 fail-fast 不越守卫;腿强制隔离 userData + 净化 PATH;Playwright project forge-m3-e2e 与既有 lane 共享 workers:1 单实例串行;vitest 排除 tests/e2e/specs(Playwright spec 永不进单测门,快 lane self-check 留 vitest)。
- 零 CLI 断言口径: 进程级限定 app 进程树(pid 祖先链 — 机器级扫描误报 dev 机合法无关进程);日志级活性锚点 = WORKBENCH_WATCH(attach 竞态下 boot 期行已被消费);零标记集按腿扩展(SC7 加 claude-code|cc-plugin)。
- prompt_hash oracle 四件套: sha256(journal.text)===prompt_hash / 测试侧内核引擎重算逐字节前缀 / 单追加行 / requestId 确定性;presynthContent 重算 = 派发后库/文档树现场(同只读句柄、同 featuresRoot、真 loadPresynthContext)。
- e2e 语料经真内核链产出(writeForgeProject→register→scan→migrate),绝不手搓 SQLite;锚点值取非平凡异于默认(偏好 65/55/75 vs 80/60);语料规模以观察窗秒级为度(300 任务/6 feature 使 close-guard 观察非竞态)。
- 产物重建纪律: 主进程 src 改动后必 pnpm build:desktop(dist gitignored);插件 client 改动后必 pnpm build:plugins(tarball 重打包);fresh worktree 跑真链 e2e 前先 bootstrap vendored 闭包(tests/e2e/README.md 跑法节)。
- doc 面板 reflux last-good 模式: 读键分型(如 (slug,tab)),同键回流/失败保留 last-good 渲染、新键走骨架 — 真实浏览器滚动位置不被钳制(jsdom 测不出,须真链腿断言)。

## Deviations from Design
- [6.1] 外围命令归宿: quality-gate/cleanup/worktree/verify-task-done 四行 tool 化未入 I2 封闭动词面 → 显式延后 M4 随 GUI 逐项归宿(PRD 归宿分解决议 + 主提案 M4 段 + todo.md 条目登记,6.gate 承接 gate 决策),不静默吞;claude/completion/upgrade + justfile 行淘汰。

- [6.4] Implementation Notes 的 MigrationFaults 为静态对象形态;实现扩展 per-run resolver union(同 boot 内注错→回滚→清错→重试旅程需要),静态形态向后兼容保留 — 任务注记许可的 seam 族扩展。
- [6.5] 「拒绝→会话失败→dispatch failed」执行器侧半链 M3 不可达(running→failed 边存在但 notifyDispatchEnded 无生产者/无 IPC 动词,spike-1 §5 会话无终局信号)— AC3 拒绝面以审批库审计 + outcome=rejected 覆盖,失败+重派发面经 launch 注错腿(starting→failed,PRD Story 2 AC4 同一可观察面);缺口留 spec 头注待后续任务。
- [6.6] tech-design §Error Handling(L216)要求 ERR_STAGE_GATE_UNSATISFIED→推进拒绝 + 缺失清单引导;实现修正 toWorkbenchIpcError 使域错误 string detail 随封装透传(envelope 此前只留 code+message,引导被截断)— spec 权威的接线补件而非行为变更。
- [6.7] scanForgeFiles 对 sqlite 权威项目过滤「index missing」形态: 设计未明说已迁移稳态(index.json 淘汰归档)的扫描分型;实现按 data_authority 分型,消除健康已迁移项目假「仓外路径失效」(概览引导卡 + 提案板阻断);files 权威语义不变。
- [6.8] 无设计偏离(SC7/SC9 面由 1.7/4.x/5.x 齐备,零生产代码改动一次通过)。
