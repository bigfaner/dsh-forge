# 2.1: dsh tool 桥与 forge.task 工具面:renderer 桥接(T2)+ 写集/读工具注册

## Description

agent 原生工具面基座:①renderer 桥(host 半身 tool handler → cordis rpc → client 半身 tool 桥 → I1 IPC 白名单动词),零新增监听面;②forge.task.add/claim/transition/submit/reopen(写集)与 forge.task.get/query/list(读)注册,契约按 spike① 结论;③权限界:写集仅 data_authority='sqlite' 项目,files 项目返回明确提示走 CLI(ERR_TASK_NOT_AUTHORITATIVE,业务提示非错误噪音);④taskKey 限定地址校验 + actor 自动携带(session:<id>);⑤桥降级:不可用重试一次后 ERR_TOOL_BRIDGE_UNAVAILABLE 明确提示(禁静默)。

## Acceptance Criteria

- [ ] 桥链路:tool 调用(host)经 rpc → client 桥 → IPC 动词达内核,写操作落 actor 审计;stub 单测验证往返与 payload 保真。
- [ ] 写集五动词 + 读三工具注册成功(扁平名),输入 schema 严格类型;taskKey 限定地址校验拒绝非法形态。
- [ ] 权限界:files 项目写集调用返回明确「走 CLI」提示;sqlite 项目正常;未注册项目不在工具操作集。
- [ ] 桥不可用(UI 未装载/启动竞态)→ 重试一次 → ERR_TOOL_BRIDGE_UNAVAILABLE 上抛会话(明确降级提示,禁静默)。
- [ ] vitest + stub:注册契约、桥往返、降级链、权限界四组主路径全绿。

## User Stories

- Story 9: 会话内原生操作与技能寻址(agent 经 dsh tool claim/submit,actor 标识审计可查;tool 不可用明确降级)

## Hard Rules

- 桥仅转发封闭动词集(无通配/无反射);渲染进程被攻破面最大能力 = 既定动词集(T4)。
- 零新增监听面:禁 named-pipe/UDS/HTTP 等任何新本地端点(T2 裁决)。
