# UI Design: dsh-forge M2 需求与会话工作台

> 设计对象 = 壳级视图切换 + 工作台页面族(自有 UI,UF1-UF6);主窗口会话界面 100% 继承上游 GUI,不在本文设计范围(TECH-ui-reuse-001),仅作为 UF5 的跳转目标。两级插件模型(2026-09-21)约束 UF6 设计:必备插件不可禁用。

## Design System

**上游 dsh 设计语言**,完整提取见项目根 [DESIGN.md](../../../DESIGN.md)(源:上游 `packages/client/ui-theme/src/styles/`)。要点:

- **色彩**:一律使用语义别名(`--dsw-alias-*`),亮暗双主题经 `body[data-ds-dark-theme]` 自动切换,新 UI 必须双主题适配;品牌动作色 `--dsw-alias-link`(亮 rgb(65,118,230));状态色 error/success/warn 别名
- **字体**:系统栈;字号阶 12/18(辅助)、14/22(正文)、16/24(标题,字重 500);代码/ID 用代码栈(mono)
- **动效**:`cubic-bezier(0.4,0,0.2,1)`,0.1/0.2/0.3s;侧板/对话框入场 0.2s;回流高亮 0.3s
- **几何**:r14(卡片/小面板)/ r20(菜单)/ r24(对话框);按钮胶囊 md h36 r18 / sm h28 r14;对话框 mask-1 + blur(2px)
- **组件先例**(上游 ui-primitives,自研前已核对):Button / Modal / Menu / Toast / StateDot / Pill——任务状态点用 StateDot、状态/徽标用 Pill、下拉菜单用 Menu 卡(r20,pad 4,min-w 218)

## Navigation(视图与页面结构)

### 顶层双视图切换(壳级)

主窗口存在两个互斥顶层视图,同一时刻只呈现一个:

```
┌──┬──────────────────────────────────────────┐
│导│                                          │
│航│        主内容区(二选一)                  │
│区│  · 会话视图 = 上游 GUI(100% 继承)       │
│  │  · 工作台视图 = 本设计 UF1-UF6           │
└──┴──────────────────────────────────────────┘
```

- **呈现位置(首选形态)**:上游侧边栏导航区新增顶级导航项「工作台」(icon keyword: kanban),与「会话」入口并列——复用上游导航组件、tokens 与交互;当前视图项高亮
- **降级形态(渲染载体由 tech-design 裁决)**:壳级 slim rail(宽 48px,主窗口左缘,垂直两枚 icon 按钮:chat 上 / kanban 下)——仅当上游导航扩展经源码侦察不可行时采用。rail 完整契约:两枚按钮均带 tooltip + `aria-label`(「会话」/「工作台」);当前视图按钮 = `interactive-bg-hover` 填充 + 左缘 2px `--dsw-alias-link` 指示条,非当前为 ghost;click / Enter / Space 触发切换(0.2s fade);Tab 序 = chat → kanban。两形态在切换行为、当前项高亮语义与键盘激活上契约一致,本文以下设计对二者等价
- 切换 = 主内容区容器切换(0.2s fade),**上游 GUI 不重载、不重排、不丢会话状态**;工作台视图状态(当前 tab/筛选/滚动位置)在切出后保留于会话期内存
- UF5「进入会话」= 切至会话视图 + session-focus 定位(复用 M1 已建立的会话聚焦契约)

### 工作台内部结构

```
┌──────────────────────────────────────────────┐
│ 项目切换器 [当前项目 ▾]  [＋ 添加项目]        │  顶栏 h48 · sticky
│ ──────────────────────────────────────────── │
│ [概览]  [任务]  [feature]                     │  tab 条(PRD Secondary Pages)
├──────────────────────────────────────────────┤
│                                              │
│              tab 内容区                       │
│                                              │
└──────────────────────────────────────────────┘
```

- tab 条:概览 / 任务 / feature 三项,文本 tab(pad 8 14,r14,选中态 `interactive-bg-hover` 填充 + label-primary,未选中 label-secondary);对应 PRD 三个工作台页面,tab 切换不改项目上下文
- 项目切换器 = Menu 卡下拉(r20,pad 4,min-w 218):项目列表(显示名 + 激活 ✓)+ 底部「添加项目」项;「＋ 添加项目」顶栏常驻按钮为 sm ghost

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 项目概览(工作台默认 tab)
- **Position**: 顶栏与 tab 条之下的 tab 内容区,全宽

### Layout Structure

```
┌ tab 内容区 ──────────────────────────────────┐
│ 项目元信息行:显示名(16/24)· 代码根目录/     │
│ 文档位置(12/18 mono 次文字)                 │
│                                              │
│ ┌─ 项目卡片 grid(min 280,auto-fill,gap 12)─┐ │
│ │ ┌────────────┐ ┌────────────┐            │ │
│ │ │ ● 激活      │ │            │            │ │
│ │ │ 项目显示名  │ │  …         │            │ │
│ │ │ 路径/文档位 │ │            │            │ │
│ │ │ [重命名][切换][移除]│ │            │            │ │
│ │ └────────────┘ └────────────┘            │ │
│ └───────────────────────────────────────────┘ │
│                                              │
│ ┌─ 插件管理区(UF6,见下)──────────────────┐ │
└──────────────────────────────────────────────┘
```

- 项目卡:r14 · bg-layer-2 · pad 14 · border-l1;激活卡边框 `--dsw-alias-link`(1.5px)+ 左上角 Pill「当前」;操作按钮 sm ghost(重命名 / 切换 / 移除)
- 元信息行仅当前激活项目的路径信息(12/18,mono 代码栈,路径超长中段省略 `…`,保尾段)

### States

| State | Visual | Behavior |
|-------|--------|----------|
| empty(无项目) | 空态卡:居中「还没有注册项目」+ 主按钮「注册项目」 | 注册向导自动进入(见 UF1 向导组件) |
| loading(扫描) | 骨架占位(卡片灰块 + shimmer,0.3s 循环) | 注册/切换时的项目数据扫描 |
| error(未检出/路径不可访问) | 表单内错误文案(error 色 12/18)+ 修正引导 | 见注册向导;概览页激活项目路径失效时:错误卡 + 「重新指向 / 移除」动作(重新指向 = 注册向导 · 编辑模式,见向导组件) |
| populated | 项目卡片 grid + 插件管理区 | 正常 |

### Interactions

| Trigger | Action | Feedback |
|---------|--------|----------|
| 点击非激活卡「切换」 | 激活该项目 | 卡片高亮迁移;任务/feature tab 数据整体切换(loading 骨架) |
| 点击「重命名」 | 卡内 inline 编辑显示名(14/22 输入框替换显示名) | Enter 保存 · Esc 取消;空提交回退原名;仅更新注册表显示名,不动磁盘目录名 |
| 点击「移除」 | 二次确认对话框(「仅删除工作台注册信息,不动项目文件」) | 确认后卡片消失;移除的是激活项目且仍有剩余 → 按注册顺序自动激活剩余首项 + toast「已激活 {显示名}」;唯一项目移除 → 回 empty 空态(单激活恒有明确归属) |
| 顶栏「添加项目」/ 空态「注册项目」 | 打开注册向导 | 对话框(见下) |
| 点击项目切换器项 | 同「切换」 | Menu 卡关闭 |

### Data Binding

| UI Element | Data Field | Source |
|------------|-----------|--------|
| 项目卡(显示名/路径/文档位置) | 项目注册表 | 工作台自有状态(DF005) |
| 激活标记 | 激活项目标识(单激活) | 工作台自有状态(DF005) |
| 文案 | `workbench.overview.*` | 上游 locale 机制(zh/en) |

## Component: 项目注册向导(UF1)

### Placement

- **Mode**: existing-page(浮层对话框,挂载于工作台视图)
- **Target Page**: 工作台 · 项目概览之上
- **Position**: 全屏 mask(`--dsw-alias-bg-mask-1` + blur(2px))+ 居中对话框;宽 `min(520px, 100vw-48px)`,高自适应(max 70vh 内容区内滚动)

### Layout Structure

上游 Dialog 几何(r24 · bg-layer-2 · elevation-prominent · 标题行 pad `22 14 12 24` · pb24 · 关闭钮 28×28 r8)。**宽度偏离声明**:对话框宽取 `min(520px, 100vw-48px)`,刻意宽于上游先例 `min(380px, 100%)`——容纳三步点行 + 步骤②双选布局 + 右对齐双按钮行(380px 下将换行挤压);其余几何沿用上游:

```
┌─ 注册项目 ──────────────────────────── ✕ ─┐
│  ●──●──○  步骤 2/3                        │  步骤点(12/18 次文字)
│                                            │
│  [步骤内容区]                              │
│  ① 选择代码根目录   [浏览…] 路径输入       │
│  ② 文档位置  (·) 仓内(默认)              │
│              ( ) 仓外本地路径 [浏览…]      │
│     ⚠ 仓外路径:须 ≠ 代码根目录 + 授权     │
│  ③ 确认:三分信息摘要(只读)              │
│                                            │
│                 [← 上一步(ghost)] [下一步(主)] │
└────────────────────────────────────────────┘
```

- 步骤点:三圆点连线,当前步 `--dsw-alias-link`,未达步 border-l3,已过步 success
- 底部按钮行右对齐:上一步(sm ghost,步骤①隐藏)/ 下一步或「完成」(md 主按钮,校验未过 disabled + tooltip 原因)
- 编辑模式(重新指向):入口 = UF1/UF4 错误卡「重新指向」——复用同一向导组件,标题改「重新指向项目」,步骤①/②预填当前代码根目录与文档位置;「完成」= 仅更新该项目的路径信息并重扫 forge 数据;项目显示名与挂接索引(DF005)原样保留

### States

| State | Visual | Behavior |
|-------|--------|----------|
| 步骤① 校验中 | 路径输入后 spinner(12×12) | 检出 forge 数据(`.forge`/`docs/features`) |
| 步骤① 未检出 | 输入下错误文案(error 色 12/18)+ 引导(修正路径或先初始化项目) | 停在步骤①,「下一步」disabled |
| 步骤② 仓外选中 | 授权说明块(warn 色 12/18,r14 卡) | 需显式确认授权才可下一步 |
| 步骤② 仓外路径 = 代码根目录 | 输入下错误文案(error 色 12/18)「文档路径须与代码根目录不同」 | 「下一步」disabled,直至另选不同路径 |
| 注册中 | 「完成」按钮 spinner | 写入注册表 + 扫描 |
| 注册成功 | 对话框关闭 | 激活项目,进入概览 populated |

### Interactions

| Trigger | Action | Feedback |
|---------|--------|----------|
| Esc / 点 mask / 点 ✕ | 关闭向导 | 步骤②之后(已有输入)先确认「放弃注册?」;无输入直接关 |
| 「下一步」 | 校验通过则前进 | 步骤点推进,0.2s 内容切换 |
| 错误卡「重新指向」(UF1 概览 / UF4) | 打开向导 · 编辑模式 | 预填现路径;完成重扫后错误卡消除,回 populated |
| 「完成」 | 写入并激活 | 见注册成功态 |

### Data Binding

| UI Element | Data Field | Source |
|------------|-----------|--------|
| 路径/文档位置 | 代码根目录 / 文档位置(enum + path) | 用户选择 → 工作台自有状态(DF005) |
| forge 数据检出结果 | 扫描结果 | 应用扫描(DF003 前置) |
| 文案 | `workbench.wizard.*` | 上游 locale 机制(zh/en) |

## Component: 任务看板(UF2)

### Placement

- **Mode**: new-page
- **Target Page**: 工作台 · 任务看板(任务 tab)
- **Position**: tab 内容区,全宽;工具栏 sticky 于 tab 条下

### Layout Structure

```
┌ 工具栏 h48 sticky ──────────────────────────┐
│ [依赖树|状态分组|列表](segmented)           │
│ 筛选:feature ▾  状态 ▾  worktree(toggle)   │
│ 排序 ▾                    任务计数 N        │
├─────────────────────────────────────────────┤
│ 视图主区(见下三视图)                        │
└─────────────────────────────────────────────┘
```

**视图 A · 依赖树(默认)**:自上而下分层 DAG(blocker 在上,被阻塞在下);容器可横纵滚动,初始 fit-view(整图适配视口,tech-design 定渲染引擎):

```
┌─────────────────────────────────────────────┐
│   ┌─T1.2────┐      ┌─T1.3────┐             │
│   │● 任务标题 │─────→│● 任务标题 │             │  节点卡 w240 · r14 ·
│   │  1.2 ⌥w │      │  1.3 ⌥s │             │  bg-layer-2 · pad 10 12
│   └─────────┘      └────┬────┘             │  边 = blocker → blocked
│        └────────────────┘   ↓               │  (1.5px border-l2,箭头指
│                      ┌─T2.1────┐            │  向被阻塞方)
│                      │○ 任务标题 │            │
│                      └─────────┘            │
└─────────────────────────────────────────────┘
```

- 节点卡:StateDot(状态色,携带 `aria-label` 状态全称)+ 标题(14/22 单行截断 `…`)+ 第二行:任务 ID(12/18 mono 次文字)+ 状态短名(12/18 次文字,StateDot 的非仅颜色冗余)+ 角标(worktree ⌥w / 来源 [会话]/[终端] Pill / 挂接 Pill——与 UF5 同一形态:active = 品牌蓝「会话中」+ 呼吸点(StateDot),历史 = 「N 次会话」计数,无挂接不显示)
- 焦点任务(从 UF3 返回/挂接回流定位):节点边框 `--dsw-alias-link` 1.5px

**视图 B · 状态分组**:7 态横向看板列(列宽 min 280,横向滚动):列头 = StateDot + 状态名 + 计数 Pill;列内节点卡堆叠(同视图 A 卡片)

**视图 C · 列表**:表格行 —— ID(mono)| 标题 | 状态 Pill | feature | 分支(mono)| worktree | 来源 | 更新时间;行 hover `interactive-bg-hover`,点击开 UF3

- 只读约束(PRD):视图内不出现任何任务状态变更按钮/入口——全部交互限于导航(打开 UF3、UF5 发起会话)与视图控制(视图切换/筛选/排序),回流仅呈现、不提供写回

### States

| State | Visual | Behavior |
|-------|--------|----------|
| loading | 骨架(树视图:灰节点网;列表:灰行) | 首次加载/切换项目 |
| empty | 空态卡「无任务」+ 引导(指向 forge 初始化文档) | 项目无任务数据 |
| error | 错误卡 + 「重试」 | forge 数据读取异常 |
| populated | 三视图正常 | — |
| updating(回流·属性级) | 变更节点/行 0.3s 高亮(背景 `interactive-bg-hover` 渐出)+ 角标来源刷新;不打断焦点/滚动 | 外部变更到达(≤5s 时效,免手动刷新) |
| updating(回流·结构性) | 任务/依赖边增删:节点 0.2s 淡入/淡出 + 增量重排,保留当前 pan/zoom(不自动 re-fit,fit-view 仅首载);列表视图 = 行插入/移除,不重置滚动;焦点任务被删且侧板开启 → 侧板转错误态 | 同上 |

### Interactions

| Trigger | Action | Feedback |
|---------|--------|----------|
| 切换三视图 | 视图切换 | 0.2s 切换;视图偏好记忆于会话期 |
| 筛选/排序变更 | 即时过滤 | 无结果 → 明确空态(非错误) |
| 点击节点/行 | 打开任务详情侧板(UF3) | 侧板 slide-in |
| Tab / 方向键(依赖树视图) | 焦点依布局序(自上而下、同行左→右)在节点卡间遍历 | 焦点节点边框 `--dsw-alias-link`;Enter / Space = 打开 UF3;节点聚焦时(:focus-within)UF5 发起按钮显现,可 Tab 到达 |
| 挂接回流事件 | 定位 + 高亮该任务 | 见 updating 态 |

### Data Binding

| UI Element | Data Field | Source |
|------------|-----------|--------|
| 节点/行字段 | 任务 ID/标题/状态(7 态)/依赖(blocker 边)/feature/分支(任务执行 git 分支名,列表视图列)/worktree/更新时间(最近变更时间戳,列表视图列) | forge 任务数据(DF001/DF003) |
| 来源角标 | 变更来源标识 enum[会话/终端] | 变更事件(DF003) |
| 任务计数 | 任务规模 count | forge 任务数据(DF001/DF003;规模预算 ≤500、首屏 ≤2s) |

## 全局规则(工作台视图)

**层叠与共存**:沿用 M1 层序——注册向导/移除与禁用确认对话框 z1200(mask + blur);toast z1100;任务详情侧板 z100(不 mask 主区,焦点锁定);回流高亮不抬升 z。

**主题与双语**:全部组件双主题适配(语义别名);文案一律经上游 locale 机制(zh/en),不自建文案通道。

**键盘与可访问性**:侧板/向导为焦点陷阱(Esc 关闭,Tab/Shift+Tab 循环);回流高亮提示 `aria-live="polite"`;stepper/状态 Pill/StateDot 一律携带 `aria-label`(状态全称);仅图标的按钮(UF5 发起、slim rail)必须有可访问名称;动效遵循 `prefers-reduced-motion: reduce` 降级(位移禁用,保留淡入)。

**markdown 只读渲染(防注入)**:任务描述/执行记录/五类文档一律只读渲染——禁 raw HTML、禁脚本、禁外链跳转离开应用(PRD 安全约束);渲染区不含交互元素。

**数据时效**:外部变更(会话/终端)回流 = 免手动刷新,≤5s;属性级变更(状态/标题/角标)仅高亮与角标更新,不打断当前焦点/滚动;结构性变更(任务/依赖边增删)按 UF2「回流·结构性」口径执行——增量重排,但保留 pan/zoom 与列表滚动位置。

**性能预算**:任务看板首屏 ≤2s(500 任务);会话发起到会话界面可交互 ≤3s;骨架先行,禁止白屏等待。
