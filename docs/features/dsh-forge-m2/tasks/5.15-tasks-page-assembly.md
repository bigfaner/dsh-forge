# 5.15: Page Assembly：任务页组装(三视图 + 侧板 + 发起入口 + 事件回流)

## Description

new-page 装配任务:任务页完成态——工具栏 + 三视图 A/B/C(5.5/5.6)+ 详情侧板 dock(5.8)+ 发起入口(5.11)+ 事件回流编排:onEvents 推送 → 快照增量 → 视图级行级更新 + updating 指示 + aria-live 播报;首屏 getTaskBoard 单次拉取;视图切换/筛选状态与回流共存不冲突。

## Acceptance Criteria

- [ ] 任务页全要素组装:工具栏/A/B/C/侧板/发起入口,view-key 与 tab 状态机对齐(5.1 挂载点填充)。
- [ ] 真数据:mock 全撤;首屏 getTaskBoard 单次;500 任务首屏可交互 ≤2s(SC1 预算在页面级核算)。
- [ ] 事件回流:任务变更推送 → 行/节点级更新 + updating 指示,整页不闪不重置;终端变更场景端到端 ≤5s(SC3 页面侧)。
- [ ] 视图切换保持筛选/滚动/选中态(三视图契约一致);侧板联动三来源正确。
- [ ] aria-live 播报状态变化文案(双语);焦点管理无丢失。
- [ ] e2e 冒烟:三视图切换 + 侧板联动 + 一次回流呈现(详细腿归 6.2/6.3)。

## User Stories

- Story1 任务可视化浏览:三 AC 页面级闭环(树一致/worktree 标识/详情可读)。
- Story3 状态回流与来源:页面侧 ≤5s 与来源徽标。
- Story4 双形态一致:呈现面。

## Hard Rules

- 回流更新不得整页重建(行级 diff 是硬要求,闪烁/重置即缺陷)。
- 500 任务预算不达标时优先优化渲染路径,不得放宽 SC1 阈值。

## Implementation Notes

- 文件清单:`packages/plugins/forge-workbench/src/client/views/tasks/TasksView.tsx`(完成态)、`client/store/task-board.ts`(快照缓存 + 事件合并)。
- 复杂度 high 依据:回流编排与性能预算交叉,AC=6。
