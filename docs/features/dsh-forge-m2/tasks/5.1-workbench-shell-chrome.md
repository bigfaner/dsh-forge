# 5.1: WorkbenchShell 页面 chrome：顶栏/项目切换器/三 tab 条/视图键状态门

## Description

实现工作台视图容器的页面 chrome(新页面 Build 任务,UF 族共享底座):顶栏(应用标识/全局状态)、项目切换器(激活项目下拉 + 快速切换)、三 tab 条(概览/任务/feature,对应 view-key `workbench/overview|tasks|features`)、视图键状态门(无路由:以状态机切换视图,子视图与浮层按 page-map 键寻址)。数据可 mock(UI 依赖层规则:仅依赖 Interface 1 DTO 类型)。

## Reference Files

- docs/features/dsh-forge-m2/design/tech-design.md — §Integration Specs(工作台容器与 UF 挂载点)、§Interfaces Interface 1(WorkbenchState/Project DTO)
- docs/features/dsh-forge-m2/ui/ui-design.md — 全局规则(层序/双主题/focus)与「壳级双视图切换 + 工作台三 tab」节
- docs/features/dsh-forge-m2/design/page-map.md — 视图键寻址与状态门(替代路由守卫)

## Acceptance Criteria

- [ ] 三 tab 切换正确驱动 view-key 状态机(含 `workbench/features/:slug` 子视图返回栈)。
- [ ] 项目切换器:显示激活项目、下拉列出全部、切换即激活(经 IPC,mock 阶段本地桩);无项目时空态引导至注册。
- [ ] 状态门:未注册项目时任务/feature tab 呈引导态而非报错(对齐 page-map 状态门语义)。
- [ ] 双主题(上游明暗)跟随、焦点环与键盘可达性(tab/arrow 导航)达 ui-design 全局规则。
- [ ] 视图挂载点就绪:三个 tab 内容区为受控挂载点,5.14-5.16 assembly 直接填充。
- [ ] 组件单测(vitest + Testing Library):tab 状态机、切换器交互、空态/状态门。

## User Stories

- Story5 多项目管理:项目切换入口(chrome 层)。
- Story1-Story7 全部故事的页面骨架。

## Hard Rules

- 不得引入路由库(M1 spike-3 裁决:视图键状态门)。
- 样式作用域限定插件容器,禁止污染上游全局样式。

## Implementation Notes

- 文件清单:`packages/plugins/forge-workbench/src/client/views/WorkbenchShell.tsx`、`client/components/chrome/{TopBar,ProjectSwitcher,TabBar}.tsx`、`client/store/view-key.ts`(消费 3.3 状态机)。
- UI 依赖层:本任务及 5.x build 任务只 import `ipc/types.ts` DTO + mock 桩,不直接依赖 IPC 运行时(装配任务才接真数据)。
