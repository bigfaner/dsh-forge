# 5.2: 只读 markdown 渲染组件(防内容注入白名单)

## Description

实现工作台共享的 markdown 只读渲染组件(任务描述/feature 文档共用):支持受限语法子集(标题/列表/表格/代码块/引用/链接白名单),输出前 sanitize——禁 raw HTML/script/style/事件属性/非白名单协议链接(javascript:/data:),代码块纯文本高亮不执行。

- docs/features/dsh-forge-m2/design/tech-design.md — ### Mitigations(markdown 渲染防内容注入 T 面)、§Interfaces Interface 1(readFeatureDoc/getTaskDetail 的 *Markdown 字段)
- docs/features/dsh-forge-m2/ui/ui-design.md — 全局规则「markdown 防注入」与文档 tab 视觉规范
- docs/features/dsh-forge-m2/prd/prd-spec.md — 安全约束(markdown 渲染防内容注入)

## Acceptance Criteria

- [ ] 受限子集正确渲染:标题/有序无序列表/表格/围栏代码块/引用/白名单协议链接。
- [ ] 注入面关闭:raw HTML、script/style 标签、on* 事件属性、javascript:/data: 链接全部被剥离或转义为纯文本(测试用例含典型 XSS 载荷)。
- [ ] 渲染严格只读:无任何可交互元素被执行(链接仅文本或受限打开)。
- [ ] 长文性能:万行级 markdown 渲染不冻结主线程(分块或虚拟化,量化阈值记录在测试)。
- [ ] 双主题下代码块/表格样式适配。
- [ ] vitest:子集渲染矩阵 + 注入载荷矩阵(≥10 用例)。

## User Stories

- Story1 任务可视化浏览:详情描述可读。
- Story6 feature 文档与仓外:五类文档可读。

## Hard Rules

- sanitize 白名单制(默认拒绝),不得黑名单制。
- 组件不得依赖任何执行型插件(如代码块运行时)。
