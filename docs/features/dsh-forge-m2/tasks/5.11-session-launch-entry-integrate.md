## Acceptance Criteria

- [ ] 双挂位入口可用:节点卡 hover 与侧板主按钮均发起同一流,真服务(非 mock)全链打通。
- [ ] 发起成功自动切换到会话视图且目标会话可见;返回工作台后徽标状态正确。
- [ ] 运行中徽标:active session_link 的任务在 A/B/C 三视图与侧板一致显示;结束事件 ≤5s 内撤下。
- [ ] 发起后看板选中态与滚动位置保持(返回无缝)。
- [ ] e2e 级冒烟(stub 通道):发起→跳转→徽标→结束撤除全链(详细腿归 6.3)。
