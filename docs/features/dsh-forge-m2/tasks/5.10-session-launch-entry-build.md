# 5.10: UF5 会话发起入口 Build：节点卡 hover 按钮 + 侧板主按钮 + confirm 态

## Description

Build 任务(集成归 5.11):发起入口组件——视图 A 节点卡 hover「发起会话」按钮 + 详情侧板主按钮(同一组件两种挂位);点击进入 confirm 态:prompt 预览(只读,可展开全量)、目标会话说明、确认/取消;发起走 4.1/4.2 服务链,错误与降级(通道不可用 → 剪贴板 + toast)显式反馈;≤1 点击可达发起(确认态默认聚焦确认钮,Story2 AC1)。

## Acceptance Criteria

- [ ] 双挂位组件一致:节点卡 hover 钮与侧板主按钮触发同一 confirm 流(行为逐项一致)。
- [ ] confirm 态:prompt 预览默认折叠可展开全量(逐字符可核对)、确认默认焦点,一键确认即可发起。
- [ ] 发起链状态机:取 prompt 中→创建中→成功跳转/失败显错/降级 toast(三终态齐备,无静默)。
- [ ] 降级呈现:剪贴板已复制说明 + 手动指引 toast(文案按 ui-design)。
- [ ] 任务无 prompt(ERR_NO_PROMPT)/CLI 不可用(ERR_FORGE_CLI_UNAVAILABLE)错误内联可读。
- [ ] 组件单测:状态机全路径 + 双挂位一致性 + 错误映射。

## User Stories

- Story2 一键发起:≤1 点击、首条消息完整 prompt 呈现、失败可见。

## Hard Rules

- prompt 预览严格只读(5.2 同纪律),不得渲染为可执行内容。
