# 1.1: SC8 spike：dsh 插件机制承载 forge 管线语义等价性 + DF004/导航槽位/FORGE_ACTOR 侦察

## Description

PRD In Scope 首个任务(SC8 硬前置)。以源码侦察 + 最小可运行验证回答四个悬空问题，产出 spike 报告并回填 tech-design Open Questions：

1. **语义等价性**：forge 管线要素(skill 指令流、hook、subagent/task-executor、manifest/任务文件)能否全部在 dsh 插件形态(上游 desktop-host 的 cordis 双半身)内承载；逐要素给出等价/降级/不可行结论。
2. **DF004 会话发起通道**：Interface 5 候选序(host cordis service → client cordis service → 冻结 fallback 剪贴板+toast)逐一侦察可用性，定形 M2 采用的通道。
3. **上游导航槽位**：上游 SPA 是否存在可注入的导航槽位(名称/id/order)，决定 D3 渲染载体首选路径 vs 插件内 rail 降级。
4. **FORGE_ACTOR 透传**：forge 仓最小配合(Related Changes #2)在当前上游版本是否可行；不可行则确认推断兜底为 M2 唯一来源判定路径。
