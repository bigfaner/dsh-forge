### 4. Conventions Established

- Host-half services return reasonCode unions (discriminated availability), not IPC envelopes — the reasonCode IS the routing contract; every failure class maps to exactly one code with disambiguating detail; bad input answers the bad-request class, never fake success.
- Two-code failure discipline for the bridge: resolution-class failures (resolve/spawn-start) → ERR_FORGE_CLI_UNAVAILABLE; post-resolution no-prompt failures → ERR_NO_PROMPT with detail.
- Safe-spawn invariants: argument arrays only (never a shell string — T2), registered-path allowlist fail-closed, bounded output (stdout/stderr caps), timeout with child termination, complete untrimmed output as data (SC3: never parse/execute prompt content, no cross-task caching).
- PATH admits only directly-spawnable binary forms; script shims rejected with shim diagnostics (win32 .exe/.com; posix bare executables).
- Path comparison folds both sides through the repos-layer normalization convention (resolve → forward slashes → no trailing slash) + win32 case folding — the plugin mirrors the app's normalization because it cannot import the app.
- Decorator-free pure core + decorator-bearing rpc class split per file: vite 8.3 test transform doesn't lower standard decorators while tsc --build does; class/apply tests load the tsc-lowered build output (suite gates on built lib/ artifacts).
- Env-seam pattern for host-process configuration: env vars read lazily per call, fail closed on absent/invalid; the app-side table stays the single source of truth and a shell wiring task feeds the seam (DSH_FORGE_PRIMARY_RUNTIME precedent).
- Per-call structural service resolution (duck-typed channel lookup at call time) over load-order-fragile constructor DI when the plugin host half reaches an in-process host service.
- Replay-safety via deterministic requestId (sha256 over (sessionId, message)) + upstream hasPromptRequest short-circuit — replays never double-post the first user message.
- Launcher-side convergence for lifecycle states the platform cannot signal (no session terminal signal exists): supersede on re-launch + explicit endSessionLink; no agent-status heuristics; no end-on-quit.
- Test patterns: stub external binaries as inline temp-dir scripts executed through the REAL spawner via the spawnFn seam, with hermetic pinned resolution env (empty PATH); bad-input legs assert the bad-request class; coverage reported as the minimum new-file figure.

### 5. Deviations from Design

- [4.1] Version probe subcommand: design Interface 2 declares resolveCli(): {path, version} without naming the probe and body text frames 版本兼容探测; implementation uses the `forge version` subcommand because the live CLI rejects --version (verified: unknown flag, exit 1) — live-CLI contract supersedes design body text.
- [4.1] PATH script-shim rejection added beyond design's 解析序 (显式路径 → PATH → ERR_FORGE_CLI_UNAVAILABLE): design is silent on shim forms; implementation rejects .cmd/.bat/.ps1 with shim diagnostics because executing them requires cmd.exe — a shell (T2 Hard Rule).
- [4.1] Allowlist delivery via the DSH_FORGE_PROJECT_ROOTS / DSH_FORGE_CLI_PATH env seam: design states 仅对已注册项目路径执行 (PRD boundary) without specifying how the plugin host half learns the registered roots; implementation adds the env seam with shell-side feeding deferred to a wiring task — an open feed point that must land before 6.3.
- [4.1] rpc class file split (forge-bridge-rpc.ts) beyond design's single-service framing — build-tooling-driven (vite 8.3 vs tsc decorator lowering); the Interface 2 wire contract is unchanged.
- [4.2] Launch input shape: Interface 2 declares launch(input: {promptText; title}) — implementation resolves promptText host-side and extends the input with cwd + optional caller-minted sessionId (the spike-fixed channel creates with create({cwd}); Interface 2 body text predates the spike fix); ok:true returns the caller-minted sessionId.
- [4.2] FORGE_ACTOR value = session:<sessionId> instead of the design's session:<linkId> (Interface 3/6): the link row is minted only after launch succeeds, so linkId cannot exist at compose time; 2.5's judgment resolves either form through session_links — the 来源判定 contract holds.
- [4.2] Carrier = ONE appended instruction line in the first persisted message instead of an environment variable: spike-1 §4.2 proved dsh has no per-session env injection, so Interface 6's env transport is unreachable dsh-side; the append-line form preserves 原文不改写 and the no-second-source-of-truth principle.
- [4.2] Ended convergence is launcher-side supersede (supersedeActiveSessionLinks at the recordSessionLink verb) instead of any session-terminal-signal listener: spike-1 §5 proved no terminal signal exists (AgentStatus idle|running; dispose = host unload) — design's 会话结束→endSessionLink framing realizes as supersede-on-re-launch + explicit endSessionLink, with no end-on-quit (Story2 AC3).
- [4.2] Interface 5's full success chain (launch → recordSessionLink → 切会话视图 + 会话定位) landed host-half only: tier-2/tier-3 degradation legs, openSession 定位, and the orchestration are renderer-side and owned by 5.10/5.11 — a phase-boundary split, not a contract divergence.
