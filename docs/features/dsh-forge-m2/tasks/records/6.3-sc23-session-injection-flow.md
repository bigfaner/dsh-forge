### Key Decisions
- DSH_FORGE_PROJECT_ROOTS is set explicitly in the launch env (both specs): the ForgeBridge spawn-allowlist is a host-spawn env fact fed from the projects table (host-env-feed.ts), so a mid-boot registration never reaches the live host child — the explicit-env override is the documented test channel (5.11 leg-B precedent).
- SC2-2's ground truth is a control.json prompt-text override with hostile bytes (CRLF, unicode, trailing spaces) — a test-process stub spawn anchors control→stdout before the app boots, so the in-app assertion isolates stdout→renderer→channel fidelity; hashes AND full-string equality asserted with a divergence-index diff sample.
- ≤5s measurement window: t0 = the test process's last semantic writeFileSync (the status flip; the actor record is written BEFORE it so the one scan that fires sees both), t1 = in-page waitForFunction (polling 50ms) first seeing the target source badge + the new status short label on the task's view-A node card; retry-once per leg over a fresh-subject pool, distribution always logged, threshold fixed at 5000ms.
- Focus arbitration fix (TaskDetailPanel): the dock's [open] focus-in skips when a [data-dsh-forge-dialog] frame exists in the same commit — a modal dialog owns focus over the non-modal dock; the return-focus capture is unchanged.
- DAG keydown fix (DepTreeView): the delegated canvas keydown ignores events originating from interactive descendants (button/input/textarea/select/a/contenteditable/dialog) — node-card-mounted controls keep their native Enter/Space activation.
- onLaunched hardening (launch-rpc): the uiWorkspace.openSession locate leg is best-effort try/catch — a session id the workspace store does not know (the stub channel, or a store-sync race) degrades to located-when-synced instead of an unhandled rejection.
- helpers/restart-app.ts carries the SC1-verbatim single-instance guard + close-and-await-exit + a reboot-stable session factory (same config root/userData/env seams per boot = exactly SC2-3's same-userData restart); SC1's landed spec stays untouched.
