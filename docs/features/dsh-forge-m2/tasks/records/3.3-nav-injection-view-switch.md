### Key Decisions
- Form-identity is structural (Hard Rule): both the slot path and the rail call the SAME ViewSwitchController methods over the SAME view-key machine and the SAME persistence projection, and the workbench content is the SAME WorkbenchShell component receiving the SAME view face (registration inject hooks compartment in the slot path; hand-bound twin in the rail) — divergence is impossible by construction rather than asserted.
- Fallback-rail trigger = grace timer over slot declarations (RAIL_GRACE_MS=5s, ctx.slots.spec on both nav slots): healthy boots declare during roster assembly (base-bundle tier) and onPathLive clears the timer; expiry without declarations mounts the rail — overlay mode when the plugin owns the surface, chrome-only when the main registration is live but sidebar.panellist is missing (mixed drift); late declarations stand the rail down, and a mid-boot main arrival rebuilds an engaged overlay rail as chrome (no zombie surface).
- ctx.layout is consumed OPTIONALLY (ctx.get, never the plugin inject array): a hard service dependency would gate this plugin's whole load on ui-layout and kill the fallback rail it exists to guarantee.
- Restart restore = carrier attach-time projection: the slot carrier's first present() re-selects the persisted panel when the registration commits — no separate restore path. A one-shot restore hold (armRestoreHold) re-presents once against the upstream boot session auto-restore (home-scoped session hydration ends in selectPanel(null) seconds after ui-ready, which would otherwise defeat AC4 on every real restart); the hold is consumed by the first dismissal so genuine user intent afterwards adopts normally.
- External selection sync rides the keyed main slot's mount/unmount lifecycle (shell mount = presented, unmount = dismissed → adoptExternalView persists without re-presenting, no loop); the rail instead keeps its shell mounted and faded (session-memory retention by construction, the ui-design 切出后保留 clause).
- SPEC CONTRADICTION resolved per task AC over the pre-spike tech-design line (视图切换状态不持久化): AC4's 重启回到上次视图 wins — the persisted projection is {view, workbenchTab} under localStorage key dsh.forge.workbench.view (the upstream dsh.* snapshot-store precedent); the feature-detail slug stays session-scoped per page-map.
- Rail is a plugin-owned React root under a body-appended display:contents host with inline styles only — zero stylesheet injection, zero upstream DOM mutation (Hard Rule 防污染); scoped-styles assertion is machine-checked in rail.spec.
- Live rail boot cannot be forced without removing the upstream bundles (which kills the SPA the rail switches back into), so the rail's automated leg is a real-DOM jsdom mount (installRailNav + createRoot) driving the identical machine; the slot path gets the live e2e legs (click + Enter keyboard switch, aria, two-boot restart).
