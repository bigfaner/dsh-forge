### Key Decisions
- TaskRecord dialect adaptation (spike-1-findings 4.1): forge execution records are one write-once .md per task under tasks/records/ with status/started/completed/time_spent frontmatter only - at = completed (degraded to started, verbatim local string), kind = task type from index.json (record file carries no kind), source = optional actor frontmatter line (FORGE_ACTOR slot, session:<linkId>/terminal) else null with no historical inference, summary = ## Summary section verbatim; no fields invented beyond what forge writes
- task_key stored as qualified address <featureSlug>/<localId>: schema PK (project_id, task_key) is two columns while the live dialect collides local IDs across features (this repo M1 vs M2 overlaps 33 keys; SC1's 50-feature fixture forces collisions too) - bare IDs would silently overwrite; blockers stay verbatim local IDs resolved within the row's feature namespace
- No gate/summary/T-* exclusion: forge task list lists them all (SC1 board=list consistency) and business tasks depend on phase gates like '5.gate' - excluding would fabricate dangling blockers; snapshot is the full faithful index.json task graph
- blockers = index.json dependencies verbatim (upstream blocker keys); branch stays null and worktree stays false because the dialect never writes them (Hard Rule: missing means empty, never inferred); dangling blocker refs preserved verbatim and explicitly flagged in scan stats
- updatedAt derived only from forge artifact mtimes (index.json / task .md / record .md max) - the snapshot layer never fabricates timestamps; unchanged rows are never rewritten so updated_at cannot drift without a content change
- Degraded-scan semantics: parse failures still commit the parseable data (AC4 continue) but the round ends in sync_state error with the cursor NOT advanced (er-diagram: last_scan_at = last clean scan); corrupt index.json preserves that feature's existing rows instead of structurally deleting them; missing features directory changes no data
- Source determination on rewrite only: unchanged rows keep their historical source/updatedAt; changed/new rows re-run the Interface 3 order - actor slot may be permanently empty in practice (optional forge-repo enhancement), active-link inference is the primary path
