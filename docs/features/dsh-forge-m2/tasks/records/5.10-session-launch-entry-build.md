- Degradation chain is a pure exported runner (runSessionLaunchChain): BOTH tier-1 reason codes route (ERR_HOST_NOT_READY and ERR_SESSION_CHANNEL_UNAVAILABLE chain into tier 2 then tier 3) — channel failure is routing, never error display; the tier-2 retry carries the tier-1 recovery sessionId for replay-safe adopt + re-prompt

- Error dialog is reserved for chain exceptions and a denied tier-3 clipboard (deliverability lost); a bare channel failure degrades to the guidance toast instead — 三终态 (launched/degraded/failed) all explicit

- recordSessionLink failures are swallowed after a successful launch (the session exists; persistence must not un-launch it) — link recorded BEFORE onLaunched per the success-chain order
