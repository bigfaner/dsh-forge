# 6.3: SC2/SC3 e2e 腿：一键发起注入链 + 状态回流来源 + 重启挂接

## Description

SC2/SC3 验收腿(stub 通道):①SC2——从任务发起(stub 会话通道),断言 ≤1 点击、注入首条消息 = 完整任务 prompt(逐字符)、发起后应用重启挂接仍在;②SC3——stub 会话侧改任务状态(actor 标识)→ ≤5s 看板标 [会话];终端侧(直接改 fixture 文件)→ ≤5s 标 [终端];历史挂接(ended 后)详情侧板可回溯。
