## Description

建 Playwright `_electron` e2e 的数据地基:合成 forge 项目 fixture(临时目录生成:.forge 任务文件族/docs/features 五类文档/manifest,结构对齐本仓形态);500 任务生成器(确定性种子,含 7 态分布/依赖链/多分支/worktree 混合,SC1 性能腿数据);SC 场景装置(仓外 doc_location 目录、第二项目、stub forge CLI/stub 会话通道脚本)。

- docs/features/dsh-forge-m2/design/tech-design.md — ### Per-Layer Test Plan(fixture 项目 + 500 任务生成器约定)、### Key Test Scenarios(SC1-SC7 数据前提)

## Acceptance Criteria

- [ ] fixture 生成器产出完整 forge 项目结构,indexer(2.5)可直接扫描入库无错误。
- [ ] 500 任务生成器确定性可复现(同种子同输出),任务状态/依赖/分支分布可配置。
- [ ] stub forge CLI:对 getTaskPrompt 类调用返回固定合法 prompt,退出码/超时行为可编排。
- [ ] stub 会话通道:可编排「创建成功/失败/结束事件」三态(供 4.2/6.3 消费)。
- [ ] 全部装置走临时目录 + 测试后清理,不依赖也不污染本仓 .forge。
- [ ] 装置自检用例:生成→扫描→清理一条冒烟。
