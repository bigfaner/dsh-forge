# 3.2: forge-workbench 插件包骨架：cordis 双半身 + 槽位注册壳 + locale + bundle 装配

## Description

经基座插件工程模板创建 `packages/plugins/forge-workbench`:client 半身(上游 SPA 进程)注册工作台槽位壳组件与 zh/en locale;host 半身(壳 host 进程)空载占位(apply(): void,4.x 填充 ForgeBridge/SessionLaunch);package.json `dsh.client` 声明;@xyflow/react 作为插件依赖经 bundle 引入(不进壳);装配入 plugin-bundles.json(mandatory: true)。

## Reference Files

- docs/features/dsh-forge-m2/design/tech-design.md — §Architecture Layer Placement(`packages/plugins/forge-workbench/src/client/` + `src/host/`)、### Dependencies(@xyflow/react 仅入插件 bundle、单 React 实例解析)
- packages/plugins/hello-world/src/client/index.ts — cordis 槽位注册样板(ctx.slots.inject/register、declare module SlotMap 扩展、locale 注册)
- packages/templates/plugin — 基座插件工程模板(经模板生成,不手抄结构)

## Acceptance Criteria

- [ ] 包可构建、可被 host-profile 装配加载;plugin-bundles.json 含 forge-workbench 条目且 mandatory: true。
- [ ] client 半身完成目标槽位注册(名称按 1.1 结论;spike 前可用占位名,3.3 定形)+ zh/en locale 注册(NS 级,缺译回退 en)。
- [ ] host 半身 apply() 空载返回,host 侧无未实现引用;双半身 rpc 通道可用性以最小 ping 验证。
- [ ] @xyflow/react 仅出现在插件依赖,bundle 构建产物包含之;壳与上游 SPA 不重复打包 React(单实例解析验证)。
- [ ] hello-world 插件回归不受影响(装配共存)。
- [ ] 冒烟:应用启动后插件加载日志/状态正常,mandatory 保护生效(3.1 守卫联动)。

## User Stories

- Story7 插件管理两级模型:forge 核心作为必备插件首次以产品清单形态装配。

## Hard Rules

- 插件内不得 import 壳内部模块(只能经公开面/slot/rpc);反向(壳 import 插件)同样禁止。
- 依赖解析必须经 host-profile 统一模块解析,防第二 React 实例。

## Implementation Notes

- 文件清单:`packages/plugins/forge-workbench/{package.json,tsconfig.json,src/client/index.ts,src/host/index.ts,src/client/locale/{zh,en}.ts}`,构建配置沿用模板。
- 本任务交付「壳」,UF 视图组件由 5.x 填;client 槽位先渲染占位容器(3.3 换导航形态)。
