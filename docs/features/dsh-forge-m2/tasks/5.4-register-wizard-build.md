# 5.4: UF1 注册向导组件 Build：三步流 + 编辑模式重指向 + 错误内联

## Description

new-page Build 任务:注册向导浮层(`workbench/dialog/register`,view-key 寻址)——步骤 1 路径输入与 forge 检出即时反馈(检出成功显示任务/feature 概览)、步骤 2 仓外 doc_location 可选配置(默认仓内)与显式授权确认、步骤 3 摘要确认提交;编辑模式复用同向导承载重指向(display_name/doc 路径);校验错误逐字段内联(映射 2.4 错误码)。

## Acceptance Criteria

- [ ] 三步流:路径→仓外配置(可跳过,默认仓内)→摘要;步骤间可回退修改,状态不丢。
- [ ] 检出即时反馈:输入路径后探测(桩)显示检出结果;失败给内联原因(对应 2.4 六类拒绝码文案)。
- [ ] 仓外路径选择必经授权确认交互;未授权不可进入下一步。
- [ ] 编辑模式:从项目卡进入,预填现值,提交走 updateProject 语义(重指向校验同链)。
- [ ] focus trap、Esc 关闭(脏态需确认)、aria 对话语义合规。
- [ ] 组件单测:三步状态机、错误映射、编辑预填、焦点陷阱。

## User Stories

- Story5 多项目管理:第 2 项目 ≤3 步注册。
- Story6 feature 文档与仓外:仓外注册路径与默认仓内呈现。

## Hard Rules

- 向导提交前不得写入任何持久状态(只有摘要确认步才调 IPC)。
