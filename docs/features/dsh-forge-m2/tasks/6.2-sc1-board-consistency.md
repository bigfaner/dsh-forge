# 6.2: SC1 e2e 腿：看板数据一致性 + 500 任务首屏 ≤2s

## Description

SC1 验收腿:以 6.1 fixture(500 任务)启动应用,断言 ①三视图数据与 forge 文件派生事实一致(依赖树逐边、状态、分支、worktree)②任务页首屏可交互 ≤2s(计量:getState/启动就绪到可交互)③详情侧板内容可读且与任务文件一致。

## Acceptance Criteria

- [ ] 一致性断言:视图 A 依赖边集合 = fixture blockers 关系全集(含悬空标记);B/C 行字段与任务文件逐项一致。
- [ ] 性能断言:500 任务首屏可交互 ≤2s,连续 3 次运行取中位,失败即红(不放宽阈值)。
- [ ] 详情侧板:随机抽 5 任务,描述/依赖链/records 与文件内容一致。
- [ ] 断言失败输出可诊断:附耗时分解(启动/数据/渲染)与差异样本。
- [ ] 腿纳入 `test:e2e` 套件并可单独运行(tag 过滤)。

## User Stories

- Story1 任务可视化浏览:三 AC 验收(依赖树一致/worktree 标识/详情可读)。

## Hard Rules

- 跑全量 e2e 前必须检查本机无活跃 dsh-forge 实例(ERR_SINGLE_INSTANCE 教训);腿内启动前加单实例探测守卫。
