# 5.3: UF1 项目概览页组件 Build：项目卡 grid/切换/重命名/移除/空错态

## Description

new-page Build 任务:概览页主体组件——项目卡 grid(每卡:display_name/code_root 路径缩略/branch 数/任务计数/快照时间)、点击切换激活、卡内菜单(重命名/移除,移除需确认且文案明示「不动仓内文件」)、空态(无项目引导注册)、错误态(项目目录失联徽标)。

## Acceptance Criteria

- [ ] 项目卡完整呈现 ui-design 字段集(名称/路径/branch 数/任务计数/快照时间/激活徽标)。
- [ ] 点击非激活卡 → 激活切换(IPC 桩);激活卡有明确视觉态。
- [ ] 重命名内联生效;移除走确认对话,文案含「不删除仓内任何文件」承诺语义。
- [ ] 空态/错误态视觉与引导(注册按钮/失联徽标)符合 ui-design 状态规格。
- [ ] 双主题/键盘可达/焦点环合规;卡片响应式换行。
- [ ] 组件单测:渲染矩阵 + 交互(切换/重命名/移除确认流)。

## User Stories

- Story5 多项目管理:切换完整、移除不动仓内文件(UI 侧呈现)。

## Hard Rules

- 移除动作 UI 必须双步确认;确认文案不得暗示会删除仓库内容。
