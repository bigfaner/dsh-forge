# 5.7: UF3 任务详情侧板 Build：描述/依赖链/进度点/records/挂接徽标

## Description

new-page Build 任务(集成归 5.8):右侧详情侧板——任务描述(5.2 只读 markdown)、依赖链(blocker 链路可视化,与视图 A 边同源)、状态点进度(英文标签,与任务进度点同词表,2026-09-22 原型修订统一)、records 时间线(逐笔来源 [会话/终端] + 时间)、挂接徽标与历史(active/ended 挂接列表,发起入口按钮位预留)。

## Acceptance Criteria

- [ ] 五区块齐备:描述(markdown 只读)/依赖链/状态点进度(英文标签,与任务进度点同词表)/records 时间线/挂接徽标与历史。
- [ ] 依赖链呈现与视图 A 图同源同序(blocker 路径一致);链上任务可点击跳转选中。
- [ ] records 逐笔来源徽标 [会话]/[终端] 与时间;挂接历史含 active/ended 状态区分。
- [ ] 侧板开合:Esc/关闭钮收起;打开时焦点入板,关闭还焦原节点(focus trap 合规)。
- [ ] 发起入口按钮位预留(禁用态占位,5.11 接真)。
- [ ] 组件单测:五区块渲染矩阵 + 焦点管理 + 空态(无描述/无 records/无挂接)。

## User Stories

- Story1 任务可视化浏览:详情可读。
- Story3 状态回流与来源:逐笔来源与挂接历史呈现。
