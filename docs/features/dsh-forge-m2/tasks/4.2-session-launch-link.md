# 4.2: SessionLaunch(host 半身)：DF004 通道 + FORGE_ACTOR + 挂接持久化 + 结束回流

## Description

实现会话发起链(Interface 5 定形后):以 4.1 取得的 prompt 经 DF004 通道在上游创建/复用会话并注入首条消息;spawn 环境注入 FORGE_ACTOR(标识本应用来源,2.5 来源判定消费);发起成功即经 IPC recordSessionLink 持久化挂接(project/task/session);通道不可用走冻结 fallback(prompt 复制剪贴板 + toast 指引,对齐 M1 session-focus 形态);会话结束事件 → endSessionLink。

## Acceptance Criteria

- [ ] launch(taskKey):取 prompt → 经定形通道创建/复用会话并注入首条消息,首条消息内容 = 完整任务 prompt(逐字符,无截断)。
- [ ] FORGE_ACTOR 注入发起链环境;2.5 来源判定端到端验证:该会话产生的任务变更标 [会话]。
- [ ] 发起成功立即 recordSessionLink(幂等);应用重启后挂接关系仍在(Story2 AC3)。
- [ ] 通道不可用降级:剪贴板含完整 prompt + toast 指引,用户手动路径可达,无静默失败。
- [ ] 会话结束(通道事件或状态探测)→ endSessionLink 置 ended;结束后同任务再发起走新挂接(历史保留)。
- [ ] vitest/e2e(stub 通道):发起/重发幂等/结束回流/降级路径四组用例。

## User Stories

- Story2 一键发起:≤1 点击、首条消息完整、重启挂接仍在(三 AC 的服务侧)。
- Story3 状态回流与来源:[会话] 标识与历史挂接回溯。

## Hard Rules

- prompt 在通道内始终为数据载荷;fallback 剪贴板写入同样只写数据不执行。
- 通道失败必须显式可见(toast/状态),禁止吞错后假装成功。
