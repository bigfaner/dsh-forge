# 5.12: UF6 插件管理区 Build：两级行(必备标识 / 第三方启停)

## Description

Build 任务(集成归 5.13):插件管理区组件——两级行模型:必备插件行(名称/版本/描述/「必备」标识,无任何禁用入口)、第三方插件行(名称/版本/描述/启停开关);列表数据经 listPlugins(PluginRow:mandatory 标志驱动行形态);启停调用 setPluginEnabled,错误(ERR_PLUGIN_MANDATORY/ERR_PLUGIN_RUNTIME_STATE)即使出现也有可读呈现(纵深防御的可见层)。

## Acceptance Criteria

- [ ] 必备行:名称/版本/描述 + 「必备」标识,无开关无禁用入口(逐项断言不存在写控件)。
- [ ] 第三方行:启停开关可用,切换即调 IPC(桩),状态徽标(运行/已停用)即时更新。
- [ ] 空态(仅必备插件)与加载/错误态齐备。
- [ ] 守卫错误可读呈现:ERR_PLUGIN_MANDATORY 文案解释不可禁用;ERR_PLUGIN_RUNTIME_STATE 提示已自动重建。
- [ ] 双主题/键盘可达(开关 role=switch)合规。
- [ ] 组件单测:两级行渲染矩阵 + 开关交互 + 错误呈现。

## User Stories

- Story7 插件管理两级模型:必备无禁用入口、禁用仅退出注入内容(UI 侧)、产品清单只读的呈现面。

## Hard Rules

- 必备行不得渲染任何可写控件(即使后端守卫失效,UI 侧也零入口)。
