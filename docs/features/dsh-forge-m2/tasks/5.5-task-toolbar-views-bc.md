# 5.5: UF2 任务看板 Build：工具栏 + 视图 B(状态分组)/视图 C(列表,含分支列)

## Description

## Acceptance Criteria

- [ ] 视图 B:按 7 态分组列,组内任务卡含标题/branch/worktree/来源徽标;组可折叠。
- [ ] 视图 C 列齐全:任务号/标题/状态/分支/worktree/来源/updatedAt;排序(状态/更新时间)与列宽适配。
- [ ] 工具栏:视图切换(A 位为 5.6 占位 tab)、状态筛选、搜索(标题/任务号)生效于 B/C 两视图。
- [ ] 只读纪律:无任何行内编辑/状态按钮/勾选写入入口(Story1 看板人侧只读)。
- [ ] updating 态:收到事件推送时行级轻量指示(不整页刷新),aria-live 播报状态变化。
- [ ] 组件单测:B/C 渲染矩阵(空/少/多)、筛选搜索、只读断言(无写入口)。

## User Stories

- Story1 任务可视化浏览:worktree 标识与列表可读。
- Story3 状态回流:updating 指示与来源徽标。

## Hard Rules

- 看板对人侧一律只读(BIZ-task-ops-001);任何写入口引入即缺陷。
- 视图 A/B/C 切换不重置筛选与滚动位置(行为契约一致性)。
