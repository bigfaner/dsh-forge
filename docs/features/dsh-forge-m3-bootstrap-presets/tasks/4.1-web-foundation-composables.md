## Acceptance Criteria

- [ ] rpc client 扩容：forge:settings/{get,set} + forge:proposals/{transition,setMode,listDocs} + forge:features/listDocs + 既有 forge:tasks/features 调用面容器参数（source）改造
- [ ] formatPrefill(container, docs) 纯函数：@path 第一行 → 名称/所属 → 摘要 → 状态|阶段 → 已生成文档真实路径清单（· 路径（状态）逐行）→「我的意图：」空位——不含模式
- [ ] formatDiagMessage(task/container, records) 纯函数：@path → 所属（背景）→ 摘要 → [阶段] → 主体（任务键/诊断项/失败记录）→ 请求——feature 子图/任务失败（feature 容器）/任务失败（突击容器）三态
- [ ] openSessionWithPreset({mode?, prefill, autosend?})：创建 blank 会话 → mode 在场则 agentPreset.select（__DSH_TRANSPORT__ 载体）→ composer 预填（draft 缝——OQ#1 实施期核实；兜底 = 聚焦 + 引导粘贴，届时裁决）→ autosend 例外成员（诊断两路 + 派发指令）
- [ ] 派发指令模板：`/run-tasks ` + 容器标识单行串接（v23 最小消息——零纯函数、模板断言）
- [ ] 组件测试：纯函数快照对齐 PRD 消息体示例 ×5（含派发单行）+ 组合子编排序（mock 平台 API：select/预填/autosend 三步）
