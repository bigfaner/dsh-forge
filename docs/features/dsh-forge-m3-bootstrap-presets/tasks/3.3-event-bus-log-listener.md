## Acceptance Criteria

- [ ] 进程内 emit/subscribe 总线：产品自建（零上游事件面 import）；信封 {ts, sessionId, slug, type, payload} 恒全
- [ ] 监听器 = 唯一写者：事件标准化 → JSONL 追加行落盘 logs/{slug}.jsonl（容器维度文件——同容器全程同文件）
- [ ] 归属三分支：事件带任务 → 任务容器 slug；无任务 → contextSlug；皆无 → logs/_pool.jsonl 兜底——四例单测（三分支 + 兜底）
- [ ] 工具执行零日志代码（本任务建总线 + 监听器 + 挂接缝；emit 点随 3.4/3.5 工具路径接入）
- [ ] 单测：事件 → 标准行 → 落盘往返 + 串联读法（taskKey 过滤 → claim/spawn/submit/worker-done 会话链重组；slug 过滤 = 容器全程）

## User Stories

- Story 8: 自举走查（容器全程可串联——审计与排障面）

## Hard Rules

- 日志不含凭据、不含 dispatchPrompt 全文（只记 digest——Security ③）。
- 分工边界：logs = agent 面执行运营日志；UI 面状态审计 = feature_records/task_records（两纪律不混）。
