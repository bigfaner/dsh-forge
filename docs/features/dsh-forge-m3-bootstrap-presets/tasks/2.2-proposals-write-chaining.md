# 2.2: proposals 域写径：成链分叉内聚（accepted·expedition → registerFeature 原子）+ setProposalMode + supersededBy 取代链

## Description

`forge/small-domains/proposals.ts` 写径三面：transitionProposal 成链分叉内聚（单事务：accepted ∧ mode='expedition' → 同事务 registerFeature + feature_records(register)——裁决⑤）、setProposalMode 新正门（律三唯一写径）、superseded 转移必带 supersededBy 目标在场校验。

- docs/features/dsh-forge-m3-bootstrap-presets/design/tech-design.md — transitionProposal/setProposalMode/createProposal 签名与内聚语义 (ref: Interface 1: core 动词扩展（contracts `dto/forge.ts` 单源）)
- docs/features/dsh-forge-m3-bootstrap-presets/design/tech-design.md — 成链分叉全分支（expedition 原子/blitz 无链/NULL 边界/幂等） (ref: 图 6 · 成链分叉（transitionProposal 服务内聚）)
- docs/features/dsh-forge-m3-bootstrap-presets/design/tech-design.md — 快照不回溯与升降级边界注记 (ref: 图 7 · mode 人工升降级与快照不回溯（律三）)

## Acceptance Criteria

- [ ] transitionProposal(toStatus='accepted' ∧ mode='expedition' ∧ 无同 proposal_id feature) 单事务原子成链：proposals 行 + features 行（同名 slug/title/summary 继承/proposal_id 谱系）+ feature_records(register)——全成全败断言；返回 chained
- [ ] 分叉边界：mode='blitz' → 不成链（直接任务阶段）；mode=NULL → 不成链（先 setProposalMode，补链 = 显式 registerFeature）；幂等（同 proposal_id 已有 feature 不重复建链）
- [ ] setProposalMode：单事务只写 proposals.mode（tasks.mode 永不触碰——快照不回溯断言）+ reason 必填
- [ ] toStatus='superseded' 必带 supersededBy：目标提案在场校验 → 写 proposals.superseded_by（缺席 → typed error）
- [ ] createProposal 增 mode 透传（可选——创建技能写入；扫描吸收旧行 = NULL 缺省占位）
- [ ] 单测：图 6/图 7 全分支表（expedition/blitz/NULL × accepted/superseded/打回）+ 拒绝路径 + 原子回滚锚

## User Stories

- Story 4: 提案评审流转与 mode 人工升降级（快照不回溯）
- Story 8: 自举走查（成链 = 走查第一步）

## Hard Rules

- 成链原子性 = 单事务三行全成全败（不变量 5）。
- setProposalMode = 模式唯一写径；agent tool 面无模式改写动词（SC6 契约断言对象——tool 注册面由 3.x 保证）。
