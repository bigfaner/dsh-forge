- **renderer 禁 import core（运行期边界）+ structure pin 禁 contracts 引入**: core 常量（终态集/模式双值）在 web 本地镜像字面量声明（terminal-state/ModeChip MODES 先例）——值漂移由 5.1 契约 pin 与 e2e 对账承接；components/ 共享位组件零 contracts 依赖（web-shell.test AC-3 机械面）。
- **词汇单源纪律（双 vocabulary 并存）**: PRD 短形（PHASE_PHRASES——消息体/chips 共用单源）与 contracts 长形（FEATURE_STATUS_LABELS——M2 概览行）各自单源不混；DiagToast 行集与消息体同词汇/读序/刻度经 message-format 增量导出单源。
- **判据输入纪律**: 可用态/执行中判定走容器全集单源（TaskStats.byStatus 未过滤/listTasks 全集内自取）——恒不消费 chips/搜索过滤集（过滤集低估可用态）。
- **autosend 分野（v13 裁决沿袭）**: 组合子 autosend=例外成员缺省恒关——预填渠道（打开新会话）恒不发送；诊断发送/派发指令=例外显式置真（同 facade submit() 径）。
- **令牌纪律三分支**: 官方有令牌直用；无对应令牌走最近语义映射+注记（superseded 紫/v24 深灰实底）；原型刻度复刻走 dsw-raw 豁免注记（chips 6px/24px/8px、对话框 64px 等 M2/4.2 同值刻度）；4.5 零豁免先例（原型小字号归档最近官方字阶令牌）。
