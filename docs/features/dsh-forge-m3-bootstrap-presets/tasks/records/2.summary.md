### 4. Conventions Established

- **四域互禁 import·装配层注边形制**：small-domains 各域互不 import，跨域同事务协作（成链）经装配层（index.ts）注入导出面，消费侧以结构投影类型承接——同事务调用非二次提交；后续跨域协作一律循此形制。
- **actor 通道动词级规范推断表**：registerFeature/upsertFeatureDoc=plugin-tool、transitionFeature=ui、成链内聚=core——后续新增动词按此表归类（服务面无通道信息、输入面不收）。
- **成链撞键判别口径**：feature 与 proposal 同 slug 共享 UNIQUE(slug,local_id) 键空间——写径命中他容器同键按未命中口径 typed error（非裸约束错）；读径 kind+source_id 双列判别。
- **claim 盲选 vs 读面解析分治**：claimTask 容器盲选=kind+slug 直筛（缺席容器恒空走 Z1 零 404）；读面容器解析=source_id 路径（EQP 索引前缀锚要求）——两口径各有约束并存，勿强行统一。
- **错误面双轨纪律**：契约码缺席的编程错误（supersededBy 入参缺席/路径守卫违规/set 入参防御）=普通 Error fail-loud 原样上抛不私扩 typed 面；用户可见失败=typed error+contracts 单源 data（错误信息人话+逐行清单，禁裸错误码）。
- **审计锚双形制扫描**：裸名引用（挂载名形制）仅挂载集可命中；forge: 前缀引用=挂载集 ∪ M3 豁免清单——新增技能引用按形制入相应集。
- **条件键省行+NULL 直出=键缺席形制（M2 延续扩展）**：prompt 组装可选语境（SOURCE 行）缺席即省行（既有快照零漂移）；DTO NULL 值（mode/superseded_by）键缺席非显式 undefined（lossless 纪律延续）。
- **服务装配独立降级形制**：新服务 config 缝缺席=该服务降级缺席，不影响既有服务形制——多缝各自独立降级。
- **submitTask 校验链门序**：gate 摘要门→AC 证据门→转移校验（图 8）——后续在校验链插门保持此序；双门仅挂 success（blocked 直通走 fix 链）。
- **同 scope 口径纪律**：taskStats byStatus 与 unmetPending 必须同 ContainerScope 口径（Interface 1）——池快照数字不可异源。

### 5. Deviations from Design

- **[2.2] 既有 M2 测试行为面收紧**（→superseded 必带 supersededBy——无目标从此拒绝）：tech-design Interface 1 明示该必带约束，M2 期测试无目标夹具按 spec 授权修订补目标夹具——设计语义零偏离，行为面变更记账防误读为回归。
- **[2.4] 审计锚④b 扫描面扩展超 drift #8 记账范围**：tech-design drift #8 只记「Skill(forge:run-tests) 前缀引用缝消灭」，实施伴随裸名形制纳入扫描面+负样例扩 bare 悬空拦截——前缀缝消灭的必要泛化，非设计偏离，记账。
- **[2.5] queryTask/taskDetail container 水化实现承载者前移**：tech-design Interface 1 列两动词「增 container 水化」——实现已由 1.2 垫片期落地两消费面，2.5 补字段级测试锚（任务分工偏离，终态语义与设计一致；同 1.summary「下游对齐承载者偏离」先例族）。
- **[2.6] 图 8 未明示 blocked submit 分支是否过双门**：裁决=仅挂 result=success（blocked 直通）——按 Go 权威源 validateRecordData 非 completed 早退同语义；严格读法会致 C4 死锁。设计隐含语义显式化，非偏离。
- **[2.7] 域错误不挂 contracts code**：tech-design Interface 6 +3 码闭合（24 码无设置域码）——SettingsPathInvalidError/InvalidSettingsInputError 为编程错误走 fail-loud 上抛、rpc-envelope 结构判型不入带内信封。设计既定口径（错误码面不私扩）的实施裁决，记账。
- **RPC/tool 接线未动（防误读为偏离）**：proposals/{transition,setMode,listDocs}+features/listDocs+settings/{get,set} 通道常量 1.1 已在场而 host 未注册（归 3.8）；plugin-forge 工具面 feature_slug shim 保留（移除归 3.5）；M2 e2e 涉 claimTask/dispatchPrompt spec drift 台账归 5.3。Phase 2 交付面 = core 服务语义（与任务分解一致）。
