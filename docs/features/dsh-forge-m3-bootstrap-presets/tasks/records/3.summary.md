### 4. Conventions Established

- **插件间零依赖**: deps 恒 contracts+path-key；同型面（session/args）按插件同型裁剪复制不 import；boundaries 跨插件 import 禁面断言钉住——后续新插件循此形制。
- **双友好返回面单源**: 全 tool formatOk（✓ 首行+键值行）/formatErr（✗ code+人话+违规清单逐行派生）经 format.ts；typed 错误→失败 DTO {ok:false,code,message,violations}，无 code 意外错误 fail-loud 重抛——RPC/桥信封双面分治不破。
- **容器参平铺形制**: 工具负载禁嵌套 object（官方 enforced subset）——ContainerRef=source_kind+source_slug 两标量；嵌套概念一律平铺+snake_case 系统映射。
- **事件双防线纪律**: emit 入口信封守卫 fail-loud（装配 bug 零静默）vs 监听器写径 fail-soft（日志缺席不拖垮工具闭包）；resolveContainerDir 未解析=丢行不落相对路径。
- **digest 双记同值**: dispatchDigest 在 task-claimed 事件与 task_records.claim 行双记同值；dispatchPrompt 全文仅入 SpawnWorkerRequest.prompt——渲染面/日志面/模型上下文零出现。
- **「worker 未产出=执行受阻」口径**: worker run 无终态结算（refusal/max-tokens/漏提交）与 spawn 基建故障同径 ERR_SPAWN_FAILED+防线计数；spawn 失败任务留 in_progress 走幂等重入径不走 submit-blocked。
- **halted 防线形态**: 会话作用域计数器×3 粘住（入口检查先于 claim）、成功清零、无重置参数（复位=新会话）、冷启动易失。
- **技能承载分离**: 机械面（计数/校验/前缀恢复/门）描述为 tool 承载，LLM 判断面（摘要组织/证据引用/池三判）留技能——技能不重复承载 tool 已实现机制；worker 面全局拒 delegation（评分器内联同源）。
- **物化零 !!js 死刑口径**: 底稿镜像保真（机械 diff 守卫）+物化时求值具体布尔——保真与死刑两 AC 并立；customSkillDirs 占位符双引号项行形制（YAML 惰性合法）。
- **行所有权分叉**: overlay 产品工件行（每启注行）vs 用户层行（首启预置一次性、增量补行 id 键控不覆盖）——两径不混。
- **非 TS 资产进 dist**: 拷贝脚本挂 pnpm build（tsc 不拷非 TS 资产）；packaged 靠 host-dist 递归拷贝随包。
- **退役文件剔 dist**: tsc -b 增量不清理删除源——tool/文件退役后手工剔 dist 防进打包闭包。
- **spike 缺陷处置纪律**: 实证发现缺陷走 drift 记账（tech-design Appendix）不就地改语义；修复归 fix 任务；复职轮独立复证（非转引验收轮证据）。
