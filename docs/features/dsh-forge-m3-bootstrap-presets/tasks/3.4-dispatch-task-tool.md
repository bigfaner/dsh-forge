## Acceptance Criteria

- [ ] 四分支返回：spawned（success/blocked + taskRef/title/type/mode/digest/summary?/commitHash?/followUp?/pool）/ no-task（pool——池态三分：收工/等待/疑似死锁可判）/ halted（reason）/ spawn 失败（ERR_SPAWN_FAILED + 人话指引：带 taskRef 重入/人工转移）——formatOk/formatErr 四态渲染
- [ ] 组装序落面：taskType → 收窄矩阵（contracts 常量）→ toolFilter；forgeSettings.get() → agentOptions（未配置 = 不携带回退父会话继承）；driver in-process spawn（阻塞）+ childCtx.tools.restrict + 组合继承
- [ ] 池快照 = taskStats 现读 {pending, inProgress, blocked, unmetPending} 附载每次返回（无状态——任意会话可接管）
- [ ] halted 机械防线：会话作用域计数器（易失·冷启动重置）连续 spawn 失败 ×3 粘住（无重置参数；复位 = 新会话）；成功即清零；spawn 失败任务留 in_progress 走幂等重入径（不走 submit-blocked——执行受阻语义）
- [ ] 事件发射：task-claimed/task-spawned/task-submitted/task-worker-done/no-ready-task/tool-error → 3.3 总线（含 dispatch_digest 双记——task_records.claim 行联动）
- [ ] 单测：全场景表（spawned·success/blocked、halted 粘住/清零/冷启动、no-task 三分、spawn error）+ agentOptions 携带/未配置两态 + boundaries 修订（driver 白名单）
