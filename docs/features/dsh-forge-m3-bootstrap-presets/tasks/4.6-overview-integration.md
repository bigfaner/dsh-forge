## Acceptance Criteria

- [ ] proposal-tab.tsx 完整形态：五态 chips（插入点 = ov-sticky 之下、列表之上）+ mode chip + 行头「打开新会话」（openSessionWithPreset·提案 mode/无溯源不切换 + formatPrefill 预填不发送）+ ⋯ 菜单（两对话框挂线）+ 展开元数据（两列网格 + 文档区 listProposalDocs）
- [ ] feature-tab.tsx 升级：阶段 chips + 两列元数据 + DocGroupList（forge:features/listDocs）+ 行头「打开新会话→固定远征」+ 预填
- [ ] task-tab/ 工具栏重构：容器 pill 双轨 + 视图下拉（pill 右侧）+ [诊断]+[派发] 固定最右端（同行不换行）+ 诊断两路挂线（validateFeatureTasks RPC + taskDetail 失败路 → DiagToast → 发送给 agent）+ 派发按钮挂线（终态判定 + 双路由）
- [ ] OverviewTab：默认 560px + 左缘拖拽手柄调宽（钳制 400–920 + 中区保底 ≥580；工具栏控件恒一行）
- [ ] 数据流：rpc 容器参数路由（source）+ 事件订阅刷新（写推送链 M2 既有）+ 三子 tab 同源直读；任务行/详情无「执行」动作（无单任务执行入口断言）
- [ ] 组件测试：三子 tab 接线快照（组件于正确位置可见——插入点断言）+ 宽度拖拽钳制 + chips 切换清空语义
