## Acceptance Criteria

- [ ] 三动词每次写入同事务伴随 feature_records 行：verb = register/transition/doc-upsert（TS 单源常量）、actor 通道推断、transition 必带 reason——全成全败
- [ ] feature_records UPDATE/DELETE → ABORT 触发器断言（单测直执 SQL 验证双触发器）
- [ ] validateFeatureTasks 检查项扩展：source_id 必命中 source_kind 对应表（容器表命中）+ task_edges 两端 source_id 相等（同容器边）——漂移可抓

- [ ] 单测：每动词一行审计表断言 + 五类校验回归（派生不变量/依赖无环/Liveness/记录链完整性/拓扑可分层）+ 扩展项构造漂移样本可抓
