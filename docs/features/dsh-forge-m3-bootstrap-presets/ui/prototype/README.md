# M3 UI 原型

静态原型：M3 四 UF（提案子 tab 完整形态 / Forge设置区块 / 任务子图诊断 + 派发入口 / feature 子 tab 升级）+ hero 预设座位形态参考（平台 `AgentPresetSeat`，非自建）。设计系统继承 M2（`--dsw-*` 语义令牌、亮/暗双主题、chip kv、对话框允许集 + reason 必填）。

## 运行

浏览器直接打开 `index.html`（或 `node smoke.cjs` 跑冒烟——浏览器候选链：playwright chromium → 系统 Chrome → Edge；**170 断言**）。

## 演示面

- **概览 tab**：默认 **560px 加宽**（容器 pill/视图下拉/诊断/派发控件一行），**左缘手柄左右拖拽调宽**（400–920 钳制）。
- **提案子 tab**：五态 chips 过滤 · mode chip（远征蓝/突击琥珀/未标记中性；点击 = 模式更改快捷入口）· 展开元数据（**摘要独行 + 两列网格[模式\|谱系 / 标识\|作者 / 创建\|裁决]**）· ⋯ 菜单（评审流转/更改模式/打开新会话）· 裁决对话框（允许集 = 五态机纯函数、reason 必填；**远征 accepted → 单步成链 / 突击 accepted → 直接任务阶段[无 feature]**）· 模式更改对话框（快照不回溯）· 搜索中英 + 排序（M2 机制）· **提案文档不固定**（spike 笔记等任意挂）。
- **feature 子 tab**：**阶段 chips 过滤**（进行中/需求/设计/任务/已完成/已归档）· 展开元数据（摘要独行 + 网格[模式\|谱系 / 标识\|阶段]）· **分层文档**（标题含篇数；类型分组 → 文档行整行可点）· feature 列表 = 远征内容（突击无 feature 阶段——只有提案与任务）。
- **打开新会话（行头状态 chip 右侧·提案与 feature 都有）**：提案渠道 → 切提案模式；feature 渠道 → **固定切远征**；**均注入现状上下文**（标识/状态·阶段/摘要/**文档相对路径**——预填输入框不自动发送，等待意图）。
- **任务子 tab（M2 全量复刻 + 诊断 + 派发）**：**容器 pill = features + 突击提案**（琥珀点标记·「无 feature 阶段」注记·无子图诊断按钮——任务直挂提案）· **视图下拉（v22：容器 pill 右侧·类模式下拉——当前视图直出 + ▾，选项 列表|DAG|泳道）**（两行列表 + 执行中分组 + 行内详情时间线/挂接/转移入口；DAG 分层贝塞尔箭头 + 节点点击回列表展开；泳道七态列 0 计数折叠）· 七态 chips 统一过滤 · 右簇固定最右端 = **[诊断] + [派发]**（仅 feature 容器有诊断；派发居最右——**可点击态与其它按钮同款式、置灰态 = 深灰实底·非透明淡出[v24]**）· **feature 诊断 toast（锚定诊断按钮左侧）**：成功「子图健康 ✓」1s 自消；失败五项 + ✗ 任务键 + 「发送给 agent」5s 自消——自动发送错误消息 · **任务失败诊断（v19–v21）**：blocked/rejected 任务详情内「诊断失败」→ 失败摘要 toast（状态/原因/最近记录/任务键·5s）+ 「发送给 agent」→ 新会话自动发送、**发往容器对应模式**（feature→远征 / 突击提案→突击）、**格式化分层 + 所属容器背景**（@path → 所属[标题+种类] → 摘要 → [阶段] → 任务键+标题 → 状态+原因 → 失败记录 → 请求）· **派发按钮（v22/v23）**：存在未终态任务（pending/in_progress/blocked/suspended——终态 = completed/skipped/rejected 与相位推导机同源）亮起、全部终态置灰（tooltip 说明）；**执行中任务在场 → 跳转对应派发会话**（最新派发挂接·不新建不重发）；否则**新开派发会话**（容器对应模式）+ **自动发送**派发指令——**「/run-tasks <容器标识>」单行最小消息**（v23：只给 dispatchTask 必要参数 contextSlug；背景/池快照/请求行废止——池快照由 dispatchTask 返回自附）；三态演示 = 跳转（M2 管线接管·2.4 执行中）/ 新开（突击容器 + M3 feature 容器）/ 置灰（P1 MVP 全 completed）· **无单任务直接执行入口**（不支持指定单个任务执行——按 DAG 顺序领取）。
- **Forge设置**（侧栏底 ⚙ 设置 → 通用设置下方分区）：**多小节结构**（worker 小节标题 + 明显视觉分隔，行式控件对齐通用设置）· 三项（Provider/Model/Reasoning 三段——Output 上限已按用户裁决去掉）· 未配置态 ⚠ 占位 + 保存禁用 · 保存失败演示按钮 · 未来注记文案锚点。
- **hero 座位**：折叠标签 = 当前模式 · 菜单双预设（blank 期可切换）·「模拟首回合」→ 锁定态（平台 blank 锁 UI 面）。

## 种子数据

**9 提案**（五态全覆盖 × 有/无 mode 溯源 × 不固定文档；含三个**同名成链提案**——M2 管线接管 / P1 MVP / M3 自举·模式预设，与 feature 同标识链：feature ⊂ 提案）+ 3 feature（阶段 × 分层文档，谱系 = 成链自同名提案）×16 任务（远征任务挂 feature=提案链；**突击提案直挂任务 2 条**——旧线 eval 退役，blocked 样本）+ M2 blocked 样本 2.5 + Forge设置 两态——概览三子 tab 同属一个项目（单工作区）。见 `data.js`。
