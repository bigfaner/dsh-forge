# dsh-forge 重构总纲 · 产品原型(HTML/JS/CSS)

依据 `docs/proposals/dsh-forge-redesign/proposal.md`(2026-10-02 总纲)编写的可交互原型,
演示新产品「以知识资产为核心的研发工作台」的产品形态与核心链路。纯静态实现:
直接双击 `index.html` 打开,或本地静态服务托管本目录(无构建、无依赖)。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 三区单工作台(原生首屏)骨架 |
| `styles.css` | 全部样式;严格引用 `--dsw-*` 令牌(总纲 §风格一致纪律),亮/暗双主题 |
| `data.js` | 模拟数据层:dsh 侧(workspaceRegistry + 会话账本)/ 应用数据库(项目/任务/提案状态)/ 知识文件(frontmatter)/ 状态层事件流(含 sessionId 关联);置信度引擎与召回引擎 |
| `app.js` | 三区渲染 + 全部交互(知识库统一页面 / 会话知识召回 tab / 审核工作台 / 会话演示 / 项目概览) |
| `smoke-data.cjs` | 数据层冒烟(41 断言):`node smoke-data.cjs`(Node 直接运行) |
| `smoke-ui.cjs` | 浏览器走查冒烟(196 断言):`node smoke-ui.cjs`(依赖仓库根 `node_modules` 的 Playwright) |
| `shots.cjs` | 关键状态截图生成:`node shots.cjs` → `shot-1..12.png` |

数据持久于 sessionStorage(同标签页刷新保留);右下角「原型工具 → 重置种子数据」可还原。
URL 参数 `?p=<projectId|项目名>` 定位项目。

## 场景走查(对应总纲 §Key Scenarios / SC 池)

1. **首用**:清库后首屏 = 工作台(hero 相位);左栏 ＋ → **先弹文件浏览器(模拟盘 Z:;单击选中、双击进入、面包屑跳转、已注册目录带标记)选定工作区目录** → 添加项目表单:工作区目录自动回填(只读 + 「重新选择」可重开浏览器,换选后未手改的字段随之重构);字段自上而下 = **文档位置 · forge 目录 → 知识库目录**(分别默认 `<工作区>\.forge`、`<工作区>\.knowledge`,可直接输入或点「浏览…」叠加文件浏览器改选;改选/手改后不再随工作区联动)→ **任务清单与记录(表单最下方只读** = `{dsh-forge-home}/{canonical-path 扁平化:/ 与 \ 替换为 -}`,自动派生无需填写);无「默认召回域」——默认加载内容由用户写入 AGENTS.md(扩展功能,见总纲 §知识库工程机制·延后锚点);「确认」toast 演示「先 dsh create(幂等)后自家外键」与任务清单落位。
2. **日常**:左栏切换项目/会话(原位换台,dock 页签集跟随所属项目切换,面板状态不打断);中区发消息 → 模拟 `knowledge.search` 工具行(命中卡片附置信度与命中理由,可采纳/忽略/读正文)。
3. **知识管理**(SC5):点左栏「知识库」菜单 → **整体切换为知识库一等公民视图**(左栏入口激活态;右栏隐藏 —— 已展开也隐藏,切回会话即恢复;点任意会话切回)→ 范围默认「全部知识」,经范围菜单下钻全局库 / 项目 / 会话;搜索栏输入即过滤(命中提示条 + 目录计数联动);域树点击 = 前缀过滤;状态 chips + 仅可召回阈值 + 工具栏「✎ 从会话抽取」chip;多列卡片网格热度与置信度徽章实时计算;**点卡片 → 右侧知识详情抽屉**(摘要块 + 两列元数据 + 动作),中区浏览上下文保持。
3b. **统计分析(时间过滤 + 逐级下钻 + 自由分析)**:时间 chips(近1/3/7/30/90天)或**自定义气泡选择器**(快捷跨度 + 起止;起止过远自动收窄,上限 90 天) → 召回分布按 **项目 → feature → 会话** 逐级下钻(面包屑回退)→ 知识召回 Top 点击开抽屉 → 次行 盲区/反馈质量/**召回动词分布**(读摘要/读正文转化率)→ **自由分析**任选维度 × 指标(多选 ≤3,**共享同一坐标系**:柱形同类别一组多柱、类别色相 × 指标深浅;折线每指标一线;图例标注);目的 = 持续迭代提升召回率。
3c. **知识 ↔ 会话 / 知识 → dock**:卡片 ⋯ 或抽屉统一双入口「当前会话引用 / 新会话引用」→ 当前会话直接预填,或进入 hero 草稿新会话并预填 `@知识文档`;卡片 ⋯ 与抽屉另有「**在 dock 打开**」→ **整体切回会话视图**并在右栏开出知识文档页签(只读 + canonical 路径栏 + 徽标行 + 摘要 + 正文,可 ⤢ 回抽屉编辑),**页签跟随所属项目** —— 左栏切项目后 dock 页签集随之切换(全局页签保留),切回原项目即恢复。
3d. **召回日志(事后分析)**:知识库第三个页签 —— **dsh-forge 内核于召回执行时记录的知识召回轨迹**(非 dsh 会话日志;发送消息、读正文、浏览域都在执行点即时入日志);行内看 时间 / trace_id / 所属项目 / 所属会话 / 命中与阈值滤除/预算截断 / 耗时 / token / 反馈;点行展开参数与命中列表(命中知识可跳详情);动词 chips + trace_id 检索;范围下钻(全部 → 项目 → 会话)同步收窄轨迹。
4. **会话知识**(SC10 使用监控最简形态):打开会话 → 「知识召回」tab 查看本会话召回的知识(动词明细 / 最近时间 / 反馈状态,可采纳/忽略、跳详情)与抽取沉淀;发送消息后再看 tab,事件即时累积。
5. **置信度生命周期**(SC9):抽取落库(pending,中等置信)→ 审核通过(置信 +0.18)→ 原型工具「模拟时间 +30/+90 天」观察闲置衰减;「仅可召回 ≥40%」chip 直观看到阈值过滤;点置信度徽章看四信号构成气泡。
6. **去重与晋升**(SC9/SC11):合并队列(seed:kn-118 ≈ kn-106)→ 保留一侧合并(正文并入 + 关键词并集);知识详情「晋升到全局库」→ 全局范围可见,项目侧留重定向幽灵卡;「移动(换域)」→ 稳定 ID 不变。
7. **对账**:项目概览 → 模拟目录整体移动 → 失配提示 → 按 canonical path 找回。
8. **任务状态层**(SC2/SC7):概览·任务子 tab = feature 绑定三视图(列表/DAG/泳道,feature 选择器切换,无全局汇总);⚡ tool 模拟 forge 插件半身提交 → 三视图状态与 feature 进度即时刷新;DAG/泳道节点点击看任务气泡(前置/挂接会话/动作)。
9. **外部修改**:原型工具「模拟外部改动知识目录」→ 知识面板对账横幅 → 重建索引。

## 已知简化(原型边界)

- dsh 会话引擎为罐头模拟(无真实 RPC);轨迹 tab 为简化台账(无时间线缩放)。
- 置信度公式为演示口径(基线 0.45;审核 ±;使用对数加权封顶 0.15;近期性 +0.06/+0.03;反馈 ±0.04/0.06 封顶;闲置 >14 天按日衰减),P2 设计期定参;「仅可召回 ≥40%」为 UI 示意阈值。
- token 估算 = 字符数 × 0.7(示意);OpenViking 2000 tok / 0.35 为外部参考值。
- 分组方式仅「按项目树」;多窗口、拆分面板未实装(M4 原型已有,本原型聚焦知识链路);DAG 为静态自上而下分层布局(非拖拽/缩放画布)。
- 设置页为占位(各项随 GUI 逐项归宿);已归档会话恢复入口未实装。
- 「全部知识」范围下的跨项目检索为关键词/域过滤;向量/语义检索为 P5 锚点(总纲 §延后锚点)。
