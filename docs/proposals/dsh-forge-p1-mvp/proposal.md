# Proposal: dsh-forge P1（MVP）—— 走线架 + 知识飞轮第一圈（M0+M1）

## Problem

核心问题：总纲已 Accepted 但产品尚不存在——宪法级设计停留在纸面，没有任何可运行、可演示的形态。P1 要解决的是：**把总纲设计变成可运行的最小产品，让知识资产飞轮转出第一圈**（真实 dsh 会话可用、项目可注册、知识可浏览、agent 可召回、使用被记录）。

### Evidence

- 总纲 Accepted（2026-10-02），Next Steps 明确「首个阶段提案立项：P1 = MVP」。
- UX 基线与断言资产就位：重构原型（`dsh-forge-redesign/prototype/`）+ smoke-data 41 / smoke-ui 116 断言（迁移即 e2e 种子）。
- 教训①（增强层嫁接感）：产品级 UI 需要自己的主场——原生首屏是 P1 必须首先立起的东西。
- 技术预研完成：薄宿主（S1）、boot manifest 掌舵（S2）、slot 替换（S3）、registry 幂等（S4）、创建补偿链（S7）均有 spike 方案与 fallback（tech-research.md spike 表）。

### Urgency

- 用户信任修复靠**可见增量**，不靠更多文档；MVP 门是后续全部里程碑的地基（M2 forge 接管、M3 自举都立在 P1 骨架上）。
- 零代码新分支越晚切开，设计与实现之间的空转期越长（旧线冻结可用，但新方向无产出即无反馈）。

## Proposed Solution

按总纲路表直切：**M0 走线架 + M1 知识飞轮第一圈**，两个里程碑、一个阶段提案。

**M0 · 走线架**（可演示增量 = 原生首屏立起 + 项目可注册 + 真实会话可用）：

- 零代码新分支与工程骨架；薄宿主（S1 spike 先行，失败 fallback vendor desktop-host——总纲既定裁决）；自有 vite 前端入口 + `dsh-client-web` 壳内核 + boot manifest 掌舵（官方 ui-\* 选型注入，S2）。
- 三区骨架：左栏导航 rail（品牌行 / 新会话 / 知识库入口 / 项目树 + 会话列表 / 设置，可收起）；中区会话面板（真实 dsh 会话）；右栏 dock（默认收起，轨道归零）。
- 视图互换机制（会话 ⇄ 知识库，知识模式右栏隐藏且状态保留——知识面板空态占位）+ dock 页签跟随最简版；首用 hero 空态。
- **项目创建流程（UI + 四步补偿链）**：hero 空态 → 添加项目向导 → 确认卡（唯一取消点）→ 反馈；ownership 预检 → dsh create → 应用库写入 → 失败/取消 `registry.delete` 补偿 + 启动对账（canonical path 失配找回）。
- 质量基建起步：G0–G2 门机制（lint / 类型 / 契约面 pin 测试 / e2e 池）；冒烟断言迁移起步（骨架组）；`--dsw-*` 令牌纪律自第一行 CSS。

**M1 · 知识飞轮第一圈**（可演示增量 = MVP 门）：

- 知识目录解析（项目级）+ frontmatter 最小契约 + 可重建索引（应用侧缓存，不落知识目录）。
- 知识库一等公民视图 · 浏览最小面：域目录树（≤3 层，目录即域）/ 卡片网格（frontmatter 驱动 + 热度徽章 = 使用事件计数）/ 详情抽屉（摘要块 + 两列元数据 + 正文 `MarkdownDoc` 统一渲染）。
- 召回能力面：`search` + `read-abstract`（域前缀过滤 + 关键词细分 + 置信度占位排序、摘要先行）+ **知识插件召回 tool**（agent 可调，随产品交付）。**定位 = agentic search 工具集**——与 grep / glob 同位的检索原语，供 agent 在既有 agentic search 流程中自主编排多步检索（search → read-abstract → …），产品不做应用侧编排的检索管线。
- **系统提示词最简知识段（随知识插件交付）**：说明知识库存在、知识召回流程（agentic search：遇项目问题先 `search` 相应域、以摘要先行、按需 `read-abstract`）与工具用法；组装归知识插件，产品出契约内容源。注入通道（dsh 插件向会话系统提示词贡献内容的机制）为设计期定缝项。
- 使用事件记录（召回执行点落状态层）+ 会话知识召回 tab（最简列表，数据源 = 使用事件）。
- **MVP 门**：飞轮端到端走查演示（注册 → 会话 → agent 经 tool 召回 → 事件落库 → 召回 tab 可见 → 卡片热度 +1）+ **单平台（Windows）安装包启动冒烟**（本提案 brainstorm 裁决，提前验证打包/CI 链路；三平台分发仍归 M8）。

### Innovation Highlights

诚实声明：**无新创新主张**。本提案是总纲既定方向的首阶段执行切分，方案内容全部继承总纲与架构基线。阶段级新增裁决五处：MVP 门含单平台安装包冒烟（提前暴露打包链路风险，避免积压至 M8）；SC6③ 显式顺延 M2（依赖任务域，记账防悬空）；**召回定位 = agentic search 工具集**（grep/glob 之外的检索原语，agent 自主编排，不做应用侧检索管线）；**系统提示词最简知识段 P1 即交付**（召回流程 + 工具说明）；**项目创建流程 UI 为 M0 一等交付**（新增 SC13 走查）。

## Requirements Analysis

### Key Scenarios

- **首用**：零项目 hero 空态引导 → ＋添加项目（代码区路径 + 文档位置预览 + 知识目录 + 默认召回域）→ 确认卡（唯一用户取消点）→ 注册成功，左栏出现项目与 dsh 会话列表（实时读账本，零副本）。
- **日常会话**：左栏切换项目/会话（dock 页签集跟随项目，面板状态不打断）→ 中区发消息完成真实往返；打开既有会话转录完整呈现。
- **知识浏览**：左栏知识库入口 → 中区整体切换为知识库视图（右栏隐藏、状态保留）→ 域树前缀过滤 / 卡片网格 / 详情抽屉（元数据 + Markdown 正文）。
- **召回飞轮（核心）**：会话系统提示词含最简知识段（召回流程与工具说明）→ agent 遇项目问题时依指引走 agentic search——经知识插件 tool `search`（域过滤 + 关键词）→ `read-abstract` 读摘要（与 grep/glob 同位的自主多步检索）→ 会话知识召回 tab 出现该知识行 + 使用事件落库 → 知识卡片热度 +1。
- **失败路径**：注册第 ③ 步失败或确认卡取消 → `registry.delete` 补偿 → dsh 侧无孤儿注册、目录与会话日志保留；同路径既有工作区（幂等命中）在任何失败路径下不被误删。
- **MVP 门走查**：上述全链在安装包形态下启动冒烟通过。

### Non-Functional Requirements

- **布局与风格基线**：布局以第一版重构原型（`prototype/`）为基准（三区结构 / rail 收起 / 视图互换）；视觉风格与 dsh 官方一致——`--dsw-*` 令牌体系 + ui-primitives 复用 + `MarkdownDoc` 单一包装，无平行设计体系。
- 应用自身离线自足：静态资源与运行时不依赖网络分发（无 CDN / 远程脚本 / 远程字体）；agent 模型调用属 dsh 会话域，不在此列。
- 只读纪律（SC3 回归起步）：应用全程对代码仓与文档位置零写入；P1 阶段知识目录亦只读（无写入面——写入 tool 与 UI 编辑分别属 M4 / M6）。
- 直读性能（SC2 运行验证，P1 对象 = 项目记录 / 知识索引 / 使用事件）：首屏数据全部来自数据库/缓存直读，无文件扫描型加载。
- 令牌纪律：自有 UI 样式只引用 `--dsw-*` 变量，禁裸色值/裸字号（L3 lint 起步）。

### Constraints & Dependencies

- **宪法级**：总纲（定位 / 边界 / 工件版图 / 路书）+ 架构基线（工件能力边界、依赖方向、单一写入路径、演进纪律）；SC 继承不弱化，溢出显式记账。
- **dsh 唯一 agent 运行时**：上游 0.2.0-rc.2 精确 pin + lockfile 入库；升级走窗口纪律（架构基线 §5），P1 期内默认锁死不开窗口。
- **契约面清单 = P1 设计产物**（架构基线 §6）：boot manifest 注入格式、slot 洞名、workspace registry API、`__DSH_TRANSPORT__` carrier、ui-\* props——逐项 pin 测试（G1 门内容）。
- **知识插件 ↔ 宿主能力面调用缝**：dsh 插件内调用产品能力 API 的机制为 P1 设计期第一优先必答题（未验证缝，见 Key Risks）；**系统提示词知识段的注入通道**（dsh 插件向会话系统提示词贡献内容的机制）同为定缝项。
- **forge 插件并行轨 = 外部独立工程**（skills 半身迁移 + eval-\* 裁剪，总纲 Out of Scope 定性）：本提案仅注记，P1 无依赖、零阻塞（对接点最早 M2）。
- 知识插件为产品交付物（非独立工程）：P1 交付最简召回 tool 面。

## Feasibility Assessment

### Technical Feasibility

中高。壳层 / 宿主 / 协议缝经旧线 M1–M4 验证；S1/S2/S3/S4/S7 spike 方案就绪且带 fallback。**唯一未验证缝 = 知识插件调用宿主能力面**（dsh 插件 → 产品 API 的通道）——设计期第一优先定缝；若走不通，M1 降级预案 = 召回能力面先以产品内部 API 直测承接（SC10 除「agent 真实调起」外全部可验），插件转正顺延并显式记账（与 SC7 同模式）。

### Resource & Timeline

单人；M0、M1 各 1–2 周（合计 2–4 周，含 Windows 安装包冒烟）。溢出纪律：显式记账顺延，不静默砍验收；安装包冒烟为可独立顺延项（优先保飞轮链）。

### Dependency Readiness

上游 dsh 源码与 npm 包齐备（0.2.0-rc.2，npm `next` 线）；原型与断言资产齐备；forge 并行轨无阻塞依赖；无外部 API 依赖。

## Scope

### In Scope

**M0 · 走线架**

- 零代码新分支 + 工程骨架（工件命名与目录布局设计期定，能力边界遵循架构基线工件版图）。
- 薄宿主：S1 spike（全 npm 依赖的 ~100 行入口：profile 加载 + 运行 + `{url, injections}` IPC）先行；失败 fallback vendor desktop-host（总纲既定）。
- 前端：自有 vite 入口 + `dsh-client-web` 壳内核 + boot manifest 掌舵（S2）；官方 ui-\* 选型注入；slot 路线 A 替换 `sidebar.workspaces` 占用者（S3）。
- 三区骨架：左栏导航 rail（品牌行 / 新会话 / 知识库入口 / 项目树 + 会话列表 / 设置，可收起 56px）；中区会话面板（真实 dsh 会话，ui-chat 复用）；右栏 dock 默认收起。**布局遵循第一版重构原型（prototype/）**；**视觉风格与 dsh 官方一致**（`--dsw-*` 令牌体系 + ui-primitives 复用）。
- 视图互换机制（知识模式右栏隐藏、状态保留，知识面板空态占位）+ dock 页签跟随最简版；首用 hero 空态。
- **项目创建流程（UI 全流程 + 四步补偿链）**：hero 空态引导 → ＋添加项目向导（代码区路径 / 文档位置预览 / 知识目录 / 默认召回域）→ 确认卡（唯一用户取消点）→ 成功/失败反馈；四步补偿链（S7：ownership 预检 / dsh create 幂等 / 应用库事务写入 / 失败与取消补偿）+ 启动对账（canonical path 失配按 path 找回）；应用数据库落地 `projects` 表（workspace 外键 + 文档位置 + 知识目录 + 默认召回域；引擎与 schema 细节设计期定）。
- 质量基建：G0–G2 门机制起步（lint / 类型 / 契约面 pin 测试 / e2e 池）；smoke 断言迁移起步（骨架组）；令牌 lint（L3 起步）。

**M1 · 知识飞轮第一圈**

- 知识目录解析（项目级）+ frontmatter 最小契约（字段集设计期定，为应用与技能共享契约的子集）+ 可重建索引（应用侧缓存，不落知识目录；启动/进面板静默重建，对账 UI 归 M6）。
- 浏览最小面：域目录树（≤3 层，目录即域，域由路径派生）/ 卡片网格（frontmatter 驱动 + 热度徽章 = 使用事件计数）/ 详情抽屉（摘要块 + 两列元数据 + 正文 `MarkdownDoc` 统一渲染，variant = body）。
- 召回能力面：`search` + `read-abstract`（域前缀过滤 + 关键词细分 + 置信度占位排序 + 摘要先行 + token 预算极简值设计期定）；知识插件召回 tool（agent 可调）——定位 = **agentic search 工具集**，与 grep/glob 同位的检索原语，供 agent 自主编排多步检索，不做应用侧检索管线。
- **系统提示词最简知识段**：说明知识库存在、知识召回流程（agentic search：遇项目问题先 `search` 相应域、摘要先行、按需 `read-abstract`）与工具用法；组装归知识插件（产品出契约内容源），注入通道设计期定缝；写作契约与抽取时机段 M4 续写。
- 使用事件记录（召回执行点落状态层）+ 会话知识召回 tab 最简列表。
- MVP 门：飞轮端到端走查演示 + Windows 安装包启动冒烟（打包/CI 链路继承旧线 M1 资产模式）。

### Out of Scope
