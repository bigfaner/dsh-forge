## 风格公约·方法论落位·双模式边界

- **文档风格公约单源**：`<forge-pipeline>` 系统提示段（`renderForgePipelineSection` 第四部分——mermaid 优先/文字精简/不留调整修复叙事），双模式与 worker 全覆盖；技能内零公约重复段（原 breakdown-tasks 两行残余已清零）。技能中的「存储布局见 forge-pipeline 系统提示段」指针 = 文档位置单源的承接（forgeDir 动态注入，运行时取实际值）。
- **方法论速查落位**（persona 只保留必要项：主人翁意识/XY 问题/5 Whys/权衡显式化；完整工具箱按适配表进 5 技能）：brainstorm（双钻/影响地图/机会解决方案树/用户故事地图/六顶思考帽/SCAMPER）、write-prd（JTBD/KANO/赫茨伯格/用户故事地图）、tech-design（DDD 限界上下文/TOC/奥卡姆/预验尸/FMEA/权衡矩阵）。
- **双模式边界**：突击（blitz）会话见本目录 3 技能 + 本包 `skills-blitz/` 突击专属面（grilling——blitz 预设 customSkillDirs[blitz] 挂载）；远征（expedition）会话另见 `packages/plugin-forge-spec/skills/` 6 份规格技能（write-prd/ui-design/tech-design/breakdown-tasks/review-prd/review-tech——L1 物理边界，突击 worker 组合继承目录不见；反向同构：skills-blitz 远征物理不见）。风险段只属远征：brainstorm 六段表含风险；突击提案成文五段（不含风险段）由 blitz 系统提示段承载。
