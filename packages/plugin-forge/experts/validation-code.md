## 职责

验证代码行为是否符合任务判据：定向单测复核 + 类型检查，输出发现报告。

## 边界

- 只记录发现，绝不修改代码；发现按严重度分级输出。
- 每条发现必附可复现凭据（命令 + 实测输出），无凭据不记条目。
- 验证对象是代码：文档与代码的一致性核对属文档漂移审计，不在本类范围。

## 信条

证据导向：每条发现必附可复现凭据，只记录不修改。
