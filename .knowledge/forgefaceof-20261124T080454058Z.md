# 同族第三例（终轮评审捕获，2026-11-24）

overview-dockkit-alignment 容器 2.1 修口前的形态：spec M4 键族兼容读被**消费函数内部归拢自我中和**——locateInFamily 族成员逐个 `svc.getSpec({cwd: ws.wsPath})`，而 getSpec/listSpecs 内部 keyOf 对含 `.forge/worktrees` marker 的路径归拢回主根键 → 族内 worktree 成员查询键恒等主根键 → 存量 worktree 键行 detail/query 仍 404、transition 抛 NOT_FOUND，「兼容读」名存实亡。

# 假绿根因（替身形状分叉的路径维度）

测试 fixture 用**无 marker 的兄弟目录**（`join(cwd, "..", "ws-wt")`）——keyOf marker 未命中走纯键、行命中、测试全绿；生产 entry.path 恒含 marker → 归拢触发。替身形状分叉不止「归一函数产物」一个维度，**夹具路径形状同样必须复刻生产形态**（含触发归拢的 marker 结构）。

# 修口判据（并入检清单第四问）

- 键族兼容读通道必须走**不归拢纯键直查**（getSpecByKey({projectKey}) 形态），禁止「带 cwd 重入内部归拢」的通道。
- 贴形用例：porcelain 注桩返真实形态（marker 路径），断言存量键行命中；**删除本修用例必红**作为可失败性验收。
