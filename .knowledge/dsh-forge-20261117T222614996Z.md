# dsh 宿主插件安装机械实锚事实（forge 组合器真机取证轮结论）

以下均为 plugin-forge-combo v0 真机取证轮（2026-11，六轮 e2e）实证结论，可被官方包版本升级推翻——引用前核对当版行为。

1. **desktop profile 落点 = `{userData}/profile`，不是 `{DSH_HOME}/profiles/desktop`**：打包 dsh-desktop 的 profileDir 实锚经进程命令行取证；`{DSH_HOME}/profiles/desktop` 恒不产生。desktop profile 须应用首启初始化，`dsh plugin --profile desktop add` 之前应用至少启动过一次（requireDesktopProfile 拒绝未初始化 profile）。
2. **裸名行 client 半侧不装载（逐件 file: 终态既裁）**：仅靠 bundle patch 裸名行激活的插件，其 client bundle 不经 web 面服务（20 路 HTTP 探针全 404、页面零 @dsh-forge 引用，两轮复现确认）——聚合分发「单一安装物」的裸名行机制 client 半侧失败，逐件 file: 安装为终态。host 半侧相对 `file:` 嵌套依赖解析与冷启动五件装载**成功**。
3. **patch 插行的生效机制 = boot 期 insert 行**：`dsh --dump-config` 可见五行 insert + config；`dsh.profile.bundles` 对账面**不产生** patch 插行——断言生效形态锚 dump-config，不锚 bundles 对账。
4. **patch config 下发为完整对象整体替换**（官方 override 语义）：不与单装缺省合并——forge 下发的 config 必须自含全部键（缺键即失缺省）。
5. **取证环境铁律**：npm dsh 最小链取证隔离克隆一律 `--from-default-profile web`（携 llm-deepseek 凭据 + 官方应用背板）；headless 模板克隆三重阻断（npm 版本门拒装 dsh-headless/dsh-web-app registry 旧版、克隆背板缺插件服务 pending、缺凭据 MISSING_CREDENTIAL）。
6. **pnpm 11 将 link:/file: 依赖物化进链接包自身 node_modules**：依赖闭包的断言不可锚 node_modules 物化布局——锚冷启动装载行为（bundle 全解析 + 版本双校验）。
7. **取证顺序纪律复证**：先廉价校验装载版本（manifest 双校验）再做大取证，版本不符立即停；worker 会话 toolFilter 无文件读写工具时 doc 型验收会 blocked（合法 pending 形态：`did not activate … pending (waiting for service …)` 非缺席）。
