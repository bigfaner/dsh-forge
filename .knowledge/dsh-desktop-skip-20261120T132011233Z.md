# dsh desktop boot 同名换装首装世代冻结（上游缺陷判例）

来源：plugin-forge-combo 收口批（fix-41，bug 0b5230e1，2026-11，四轮排歧定谳）。

## 事实

dsh desktop（0.13.2）boot 对**同名换装包**（卸 A 装 B，包名相同内容不同）的 bundle 层供**首装世代冻结 config**：dump-config 组合实况恒为新世代内容，而 boot 运行面恒落首代共库落点。四轮排歧均不刷新：内容标记（probe-solo 时 boot 求值 pre-marker combo=该值当时磁盘零在场）、版本 bump 0.2.0、缺席 boot 不复位、安装静默门不达（desktop add 的 pnpm 经 lock-recovery runner detached 异步落盘，manifest 尾写晚于 CLI exit）。装载缝在官方 dsh-app-boot/desktop，非插件侧可修。

## 处方

1. **换装生效前提 = 世代更替**：同名包换装后必须经完整重装周期（或宿主侧世代刷新）才可信 config 重物化——在旧世代上断言新 config 恒红。
2. **上游缺陷的测试侧承接 = 独立名目条件 skip**：skip 判据 fail-loud（世代断言先于 skip 执行 + task_logs 留痕），上游修复后断言链自动复绿——不假绿也不死锁。
3. **安装静默门**：desktop add 的 CLI exit ≠ 安装完成（detached runner 异步落盘）——换装序列须补 waitForInstallQuiescence（世代内容断言 + 清单面 mtime 三采样稳定）再断言。
