# 收口报告引用即产物清单

1.7 真机收口 REPORT 写「两态取证双 PASS」但引用的 bound/unbound-prompt.txt 等产物全盘未落盘——AC 核销只剩自述。评审按引用路径逐个检索才揭穿（bug 1c0f6100，补归档闭环）。

约定：**收口 REPORT 的「引用」语义 = 可打开的文件清单**——写报告时引用一个路径即欠一个产物；评审对账法 = 逐引用路径检索（本判例已实证有效）；产物统一落 proposals/<slug>/walkthrough/（不进 git）。
