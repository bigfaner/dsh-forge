# 现象与裁定

真机取证记录「C4Dynamic 降级为官方代码块（0.3.0 世代曾出图）」——spec 路判「归撰写面」，主会话核伪（夹具源经 parse+render 双预校验合法）后按疑似装载径不对称立判例。1.9 修复轮裁定：**内容依赖不复现**——现场 echo 丢 shape 声明 → mermaid render 抛 unknown shape → fail-soft 降级；静态核销（esbuild 闭包含 c4Diagram chunk）+ 双面真机复验（出图面 enhanced 2/2 + 降级面 console 捕获可归因 render fail）闭合，零产品代码改动。

# 判据

「降级 vs 缺陷」的定谳必须**双面证据 + 静态核销**三件齐：
1. 出图面：合法源真机出图（enhanced/SVG 计数）；
2. 降级面：坏源降级时诊断信号可归因（console/emit 捕获具体 render error）；
3. 静态核销：渲染能力在装载闭包内在场（如 esbuild 产物 chunk 含目标渲染器）。
单面留痕（只记「降级了」）不定谳——既可能冤枉实现，也可能放过真缺口。

# 关联

上一世代同象判例 852332e3（坏源静默降级）根因是夹具源非法——两代同象不同根因，靠双面证据才分得开。
