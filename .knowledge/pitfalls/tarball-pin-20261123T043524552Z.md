# 翻车链（终版三：验证器定谳语义 + 零依赖终态）

- **0.7.0（ff55faad）**：去重冲突态传递链被挤隐藏仓。首修 = 显式 pin。
- **0.7.1（d211bc24）**：reused 全量复用快径下 pin 不物化，双 flags 拒装。二修 = 部分内联（string_decoder/readable-stream bundled）。
- **0.8.0（d00302ef）**：部分内联仍拒——**验证器定谳语义全景暴露：walk 声明依赖的完整传递闭包**（mammoth 全清单 8 flags：@xmldom/xmldom、argparse、base64-js、dingbat-to-unicode、jszip、lop、underscore、xmlbuilder）。两种 flag 纹路：可解析者落宿主 asar（`…\resources\app.asar\node_modules\…`——判定集合外）、不可解析者直接「does not resolve」。部分内联 = whack-a-mole（内联多少少报几条，宿主 asar 可解析者遮蔽深链）。

# 终态判据（零依赖 + 构建期全 bundling）

- 唯一终态 = **声明零运行时依赖**：运行时引擎（mammoth/pdfjs 等）构建期 esbuild bundling 进 dist（对齐 ui 半 bundle 先例），`dependencies` 收敛为零（引擎降 devDependencies 供开发期），结构守卫断言防回归。
- 附带收益：tarball 打包链随零依赖简化（传递闭包为空，无物化/内联面）；安装代验证 walk 零对象恒过。
- 反模式存档：声明层 pin（对 reused 快径不鲁棒）、部分内联（whack-a-mole）——两代修法均已实证证伪。
