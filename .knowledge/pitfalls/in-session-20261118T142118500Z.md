# in-session 卸载→重装会翻坏宿主 profile 原生依赖——装卸场景走重启代际轮换

## 翻车形态

e2e 在宿主运行中经 plugin-manager 卸载→重装插件，翻动 profile node_modules 原生依赖——better-sqlite3 `require 非函数`（代际损坏）宿主进程 fatal 退出（bug 4afd1811）。同族判例 r22/r27/r30 三度复发。

## 规避

- 装卸场景（卸载回切/重装切换/单装派生）一律**宿主重启代际轮换**派生：装齐 → 重启 → 卸载 → 再重启 → 断言。AGENTS 1.8 已立「in-session 形态不作验收证据」——本判例补充其技术根因：运行中装卸翻动原生模块代际，不止证据效力问题，是真实损坏源。
- 宿主 plugin-manager 原生依赖保持面属官方宿主面，不归插件侧修；测试驱动库的装卸 API 应标注「跨重启使用」。
