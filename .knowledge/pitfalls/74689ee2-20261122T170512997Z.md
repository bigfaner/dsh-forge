# 翻车链

markdown-kit 容器新增 convertDocument/getOutline 时落了 session.cwd 锚 + 路径穿越守卫，但同参数消费点 validateMermaid 的 docRel 仍是裸 readFileSync（bug e6787e6e，三路评审 architecture 路揪出）——同参异义：同一 `docRel` 形参在不同工具里守卫语义不同，旧消费点成为守卫盲区（可越界读）。

# 根因

新增/收紧契约（参数守卫、类型收窄、错误码）时只看新消费点，未回扫仓内**同参数既有消费点**——契约的语义边界 = 全部消费点，不是新代码。

# 规避

- 新守卫契约落地前：`grep <参数名>` 全仓回扫同参消费点，逐点对齐或显式声明豁免理由。
- 同形参跨工具语义必须同构（cwd 锚/穿越守卫/typed error 三件套成套走）；不对称即缺陷（守卫不对称 = 守卫盲区）。
