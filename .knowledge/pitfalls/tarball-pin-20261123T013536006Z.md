# 翻车链

markdown-kit 0.7.0 tarball 经 plugin-manager 安装：staging 代内 pnpm 解析 145 包，generation peer validation 报「readable-stream: string_decoder resolves outside the generation and installation closure」拒装（bug ff55faad）。0.6.0 同依赖链曾安装通过——失败非确定性，对 store/去重状态敏感。

# 根因

tarball 安装代的依赖解析在 hoisted 去重冲突态下，**纯传递链**（顶层依赖 mammoth → 二层级 readable-stream@2.3.8 → 三层级 string_decoder@1.1.1）会被挤出代内可见树（仅存 `.pnpm` 隐藏仓），解析落代外宿主主树——物化清单（profile.install）只列顶层外部依赖，二层级传递依赖不在任何显式清单上，全靠解析侥幸。

# 规避

- **「曾通过」≠ 闭包自含**：依赖面未变的版本升级也必须真机安装复验（store/去重状态一变即翻脸）。
- 鲁棒修法 = 传递链显式 pin 入插件 dependencies（精确无前缀版本、与锁文件解析值逐处一致）——直接依赖落代内 node_modules 根（私有副本），不依赖去重侥幸。
- 安装复跑验证可能**继发 flags**（修一个暴露下一个）——迭代至验证全绿为止，禁止只修首报。
- 物化清单（bug 62211111 径）与插件 dependencies 两处口径须对齐。
