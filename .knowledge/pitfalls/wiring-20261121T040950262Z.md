# 翻车链

fix-1（0736d4a6）为 mermaid 渲染失败路径落了 `MermaidRenderOutcome` 归一 + `onRenderFail` 诊断缝，但只接线宿主/apps 径；client 束径（`ui/client.ts`，纯安装形态官方宿主装载面）漏接——安装形态渲染失败静默零出图零诊断（bug 6e9639cc，三路交叉评审 code-reviewer S5 定位，1.9 收口接线）。

# 根因

同一条诊断缝有**多个装载径消费点**（宿主构建期 import 径 / client 束安装径）——缝落在公共面不等于全径接线；修一处时对「还有谁消费这条缝」缺穷举。

# 规避

- 落缝/接线类改动，验收必须**按装载径逐径核销**（本仓插件径两分：apps 构建期 import 径 + client bundle 安装径），单径测试绿不算全。
- 跨径接线差异（宿主径走诊断发射面、client 束走 console 豁免形态）应成 pin 断言（1.9 已落 `tests/client-console-pin.test.ts`），防后续新径再漏。
