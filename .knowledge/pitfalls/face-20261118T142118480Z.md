# 装配期解引用可选 face——调用期现查纪律的最易违反形态

## 翻车形态

插件装配段（apply/工厂函数）解引用可选 face（如 workspaceRegistry）并缓存结果，官方宿主该 face 晚于插件装配 provide → 装配期读到 undefined → 后续调用链 typed 拒绝「registry face 缺席」。实例：add-project 注册链在装配期取 workspaceRegistry（projects-port.ts:50），同宿主 knowledge 插件因调用期现查同一 face 而成功——一成一败对照定谳（bug e6351546）。

## 规避

- 可选 face 一律**调用期现查**（惰性取 + try/catch fail-soft），装配期只声明 inject 依赖面、不解引用。
- inject 硬声明的缺席语义 = impl 不入 store、fiber PENDING、face 到位自动装载（cordis fiber.ts:603-628）——承重依赖走 inject 声明，非承重可选依赖走调用期现查，两者都不允许装配期解引用缓存。

## 判例锚

- 来源：host-integration-fixes（bug e6351546，修口 c3b5980f）
- 对照正例：knowledge 装载期回填的 workspaceRegistry 枚举（同宿主成功径）
