# 占位端点/死 face 退役面登记必须配核销触发条件

## 翻车形态

「防占位转永久」仅靠代码注释自觉：①project 插件 forgeProjects.deriveTaskStoreDir 占位端点（恒抛 typed unavailable + 退役面登记注释）在官方宿主形态提前到期——add-project 向导派生行必炸（本提案起源问题之一）；②deriveTaskStoreDir 在 UI 侧四处死 face 副本（声明在座零调用点）漂移无人察觉，直至终审 grep 才收敛。

## 规避

- 退役面登记（占位端点/死 face/迁移注记）必须携带：**核销触发条件**（何事件发生时必须归并/删除）+ **计划归属**（哪个提案/里程碑承载）。
- 死 face（声明在座零调用点）在收敛任务中按消费副本清单逐点退役，端点清单 pin 同步更新；保留的活 face 在清单中点名「保留不动（防误收敛）」。
- 占位端点的「诚实降级」语义（typed unavailable）只是缓冲，不是归宿——宿主形态一变即成炸点。
