# 共用 DOM 锚作断言判据——多插件共栖界面的假红源

## 翻车形态

多插件共栖同一 dock 区域时，`data-dswf-ov-wrap` 这类**两插件都渲染**的锚被用作「卸载后残段判据」——project 单装态 wrap=1 实为 project 自有概览根，spec 判残段假红两轮（bug d8dac1f3，CT-OVERVIEW-5）。产品行为正确，纯断言锚词汇缺陷。

## 规避

- 共栖 DOM 的断言锚必须**归属唯一**：残段/缺席判据只能用「仅被检插件渲染」的判别性锚（如 task-loop 专属 AC 段锚、题写 chip）。
- 共栖锚清单由共享常量包维护（本案 lib/ui），契约作者/脚本作者检查项加「锚归属唯一性」自判。
- 修复此类假红属测试脚本缺陷：经契约修订留痕径，禁止 runner 就地调和。
