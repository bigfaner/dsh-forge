# 翻车链（续版二：声明层修法被证伪 → 物化层换层）

- **0.7.0 首发（ff55faad）**：hoisted 去重冲突态下纯传递链（mammoth→readable-stream@2→string_decoder@1.1.1）被挤出可见树，generation peer validation 拒装。首修 = string_decoder 显式 pin 入插件 dependencies。
- **0.7.1 复发（d211bc24）**：显式 pin 仍拒装且 flags 扩双条——**reused 全量复用快径**下升级装不物化新增依赖：pin 与传递链同样落 `.pnpm` 隐藏仓（判定集合外）。「pin → pnpm 必物化」隐含前提被证伪——上一版「显式 pin = 鲁棒修法」结论部分作废。

# 修正后的判据（物化层换层）

- 依赖**声明层**修法（pin/overrides）对 pnpm 解析/store/复用状态**不鲁棒**——reused 快径是结构性盲区。
- 鲁棒形态 = **物化层**：传递链 bundledDependencies 内联进 tarball 插件目录（插件内 node_modules 解析恒在插件目录内——mermaid 零传递依赖自 bundled 恒过的先例形态）。root isolated linker 拒 bundled 字段时，走打包链物化（真实物化 + pnpm pack + 自读 tgz 闭包断言——本仓 `scripts/pack-bundled.mjs`）。
- 机检配套：self-containment 扩 `auditBundledClosure`（内联根真实目录/manifest+相对引用闭合/ESM-CJS exports 入口解析）接入 prepack。
- 回归面 = **三版×两态安装矩阵**（新生代物化 + reused 复用升级）+ 冲突态复验 rig——单态通过不算。

# 「曾通过 ≠ 闭包自含」（不变判据，三次实证）

0.6.0/0.7.0 的「曾通过」均为解析状态侥幸；依赖面不变也不豁免真机安装复验。
