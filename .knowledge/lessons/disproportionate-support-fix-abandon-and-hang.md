# 收益不成比例的支撑面 fix 链：放弃 + 挂账

## 判例

fix-1 → fix-2 → fix-3 链走到第三环（dock 休眠短路前置适配）时识别出：这是 e2e 支撑面的持续性手术，与本提案核心目标（循环防复发机制）收益不成比例。用户裁决彻底放弃，零源码/测试改动，仅裁决记录落盘。

## 可复用配方

1. fix 链逐环评估投入产出：当某环属支撑面持续手术而非缺陷修复时，及时上报裁决，不惯性续修。
2. 放弃裁决记录三节留盘：放弃对象（原简报）、放弃原因（不成比例判据）、挂账去向（专项提案统一收口）。
3. 放弃 ≠ 丢弃：底层问题（dock 休眠态漂移）挂账到后续专项，不在当前提案里顺手修。

## 边界

- 放弃须用户/主会话裁决，agent 不自行放弃已派发任务。
- 「收益不成比例」要有具体判据（改动性质 + 与提案核心目标的关系），不是模糊的「难修」。
