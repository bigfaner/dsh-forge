# 注释改写后重读全文

## 教训

1. 同一注释块经多轮改写后，交付前重读**整个注释块/文件头**，不只看本轮改动行——重复短语、断句残迹易在拼接处残留。
2. 残迹的代价是双重的：读者困惑 + 每位评审独立报一次，制造重复评审噪音（本案双评审各报一次）。
3. 自查动作：改写注释后对注释块整体通读一遍，或 grep 疑似重复片段。

## 适用条件

- 任何经两轮以上编辑的注释/文档段落。
- 症状信号：同一条小缺陷被多位评审分别报告，多为「局部编辑未通读」类残迹。

## 反例边界

- 单轮新增注释无拼接残迹风险，无需额外通读。
