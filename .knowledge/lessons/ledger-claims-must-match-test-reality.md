# 台账宣称须与测试现实对齐

## 规则

1. 台账/注释写「客户端镜像」「恒一致」「恒相等」类强宣称前，必须逐位核对实现，并确认有跨端契约测试覆盖该一致性——宣称不实会被评审证伪（bug 0c677db2：卷宗宣称客户端镜像，实现实为服务端单源裁定的投影）。
2. 无测试背书的强宣称应降级为「当前观察」或补测试后再宣称。
3. 台账引用测试文件名/路径必须与实际一致（Mi1 判例：指称断裂导致读者按图索骥落空，台账自伤）；引用前核对路径存在性。

## 边界

适用于台账、卷宗、注释中的一致性/镜像类强宣称；描述性事实记录（不含恒等宣称）不强制配测试。
