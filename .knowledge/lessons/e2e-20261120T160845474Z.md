# 官方新首启模态的 e2e 收起面并集扩展（「开始使用」判例）

来源：input-history-migrate-and-upgrade / fix-1 / commit cb95db72，2026-11。

## 事实

dsh 官方宿主新世代引入首启「开始使用」模态（aria-label=开始使用；按钮=添加 API Key / 登录 / 头部关闭；**无**「稍后配置/继续」）——e2e/support/modals.ts 既有 `ensureNoBlockingDialog` 只认「稍后配置/^继续$」按钮形态，对该模态失效：mask（`_mask_*` 官方 Modal 遮罩）恒拦后续点击，30s click 超时，两轮确定性同红（非 flaky）。

## 判例要点

1. **挡路模态身份必须探针定谳再改代码**：trace.zip 常只含 error-context（无弹层 DOM）——需临时探针（git 外）拉起同形态实例轮询 `[role="dialog"]` dump 全文（标题/按钮清单/外层 class）；
2. **归因三态先分岔**：A 官方新首启模态→扩收起面（测试支撑面合法）；B 宿主共享态污染→清场不改码；C 上游缺陷→条件 skip（fail-loud + 自动复绿）；
3. **收起面扩展形态**：`dismissButtonOf()` 单源并集（旧「稍后配置/继续」∪ 新「开始使用」头部关闭钮），双消费方（dismissOnboardingModals / ensureNoBlockingDialog）共用，modals.test.ts 桩适配同笔；
4. 支撑面扩展零产品码触碰——`e2e/support/**` 属测试侧合法改动面。
