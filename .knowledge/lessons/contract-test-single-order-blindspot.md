# 单一序契约测试的盲区判例

## 现象

契约用例只覆盖「主树行后置」一种顺序，既有用例全部通过；评审以反例序（主树行先置 / 非主树行 createdAt 更新）触发红灯，暴露选主谓词翻盘缺陷——全绿本身即测试面盲区的证明。

## 规则

1. 自 declare 契约（代码内自声明的不变式/裁定规则）必须配**反向序**与**平手态**用例，不只钉一条Happy path 序。
2. 选主/裁定类契约最低用例集为三态：锚定对象**在场**（恒裁）/**缺席**（退化裁定）/**时序字段平手**（tie-break 裁定）。
3. 评审时以反例序主动构造红灯验证判别力，不以既有绿为通过证据。

## 边界

适用于自 declare 契约与裁定谓词类逻辑；外部声明契约（上游 pin 语义）的用例面以其各自验证纪律为准。
