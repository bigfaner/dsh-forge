# 并发 worker 同 worktree 提交夹带

多任务循环并行跑在同一 worktree（plugins 分支）时，一 worker 的 `git add <指名路径>` 会把另一并发 worker 已暂存/已改动的无关文件扫进自己的提交（判例 8996f62b：ContextMeter re-copy 提交混入 18 件 md-mermaid rename，提交说明零提及；提交时点两 worker 交叠）。

**规避**：
1. 提交前 `git status --short` 回显核对暂存面与本次任务 scope 一致，多余文件 `git restore --staged` 退出；
2. 提交说明须覆盖 diff 全部语义面（发现夹带即在后续提交补注留痕，历史不重写）；
3. 派发侧：同 worktree 并行批尽量错峰收尾，或固定每批独占提交窗口。

**台账附带纪律**：resolveBug/listBugs/getBug 一律用全 uuid（短 id 如 `51849f72` 服务端不命中，ERR_BUG_NOT_FOUND）——worker 汇报「台账 id 未命中」先查是否短 id 截断。
