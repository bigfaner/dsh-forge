# 判据（评审检清单——新增面四问）

拆解/评审新增或改动面时逐面问：
- 新增「表行/映射行/通道」→ 必须有触达该行自身的 pin（整面测试不算）+ 单边缺席降级行为测试；
- 新文件与既有文件同族（如 pairs：forge-paths/register）→ 同构测试成对补齐，不允许「一半有一半无」的不对称；
- 装配闭包/接线层 → 下层函数覆盖不算覆盖，惰性求值/桥接需直接单测；
- **纯文本资产**（技能 SKILL.md / 提示词 / 指引文案）与**工具三面**（execute / render / output schema）：
  - 派任务前先问「哪条断言读这个文件」——任务声明的质量门不读被改文件即零覆盖，补一条直接读该文件的文本契约（`toContain` 新口径 + `not.toContain` 旧口径；读文件不加 try/catch，找不到即红）；多个 `not.toContain` 分开成独立 `it`/`it.each`，使每个禁词单独可证红；
  - 工具返回形状改动，execute、render、schema 三面各须有断言，render 断言的子串须取自夹具数据而非固定文案（防恒真）。
