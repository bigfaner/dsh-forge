## 三、去留裁决项（单列 · 待用户实机裁决）

**裁决问题**：产品 dock 是否需要新建「开始页」body（rb-start 卡片导航形态），还是记账裁除（官方 dockkit 入口卡已承载同等导航）？

| 选项 | 内容 | 代价 / 影响 |
|---|---|---|
| **A 保留开始页** | 新建产品开始页 body：dock 零页签展开落之；卡片 = 项目概览 / 知识库 / 审核工作台（对齐原型实物） | 新增一个自绘 dock body 面；「知识库」卡目标 = 中区面板（跨区导航）、「审核工作台」卡目标 = 产品未实现面（空指或隐藏）——两卡目标面需先定义 |
| **B 裁除记账** | 维持现状（无开始页）；官方 guide 入口卡（产品概览卡 order 0）承载首航导航 | 零实现；与 D1–D4/D10/D30「对齐原生 dsh」总裁决方向同向（官方件自带面零差异记账族） |

**裁决输入（走查观察，非裁决）**：
1. 官方 dockkit 已有入口卡/空态机制，产品概览卡已排最前（order 0）——原型开始页的「首航导航」职能在官方件内**已有承载面**。
2. 原型三卡中两张（知识库 → 中区面板、审核工作台 → 未实现）并**非 dock 内目标**——开始页若保留，卡面语义需用户先定目标面（构成事实上的新裁决面，超出「不新增裁决」边界，故本轮只归档不动工）。
3. 原型 rb-start 的 🧭 罗盘 emoji 为总纲 mock 饰件（M3.1 五轮 emoji 退役断言范围 = 侧栏+概览，未覆盖此面）——若保留开始页，饰件形态随走查定。

**建议（供裁决参考，非裁决）**：倾向 **B 裁除记账**——官方入口卡同职能 + 两卡目标面缺失使保留收益低；最终以用户实机走查后拍板为准。
