混合消息一条消息多块并存：普通文本段 + md 块，块间分隔
thinking / tool单块折叠卡；shell 类 = 终端风格块（首行命令 $ 前缀，其后输出；错误红显）；其它工具 = 桌面 ioCard 双段展开卡同型（hairline 边框 + 粘性标签列｜内容 + 0.5px 分隔线 + 150px 限高滚动）

流式 / turn-status光标脉冲 + shimmer 渐变文本（官方同构，暗色 #7aaaff）
