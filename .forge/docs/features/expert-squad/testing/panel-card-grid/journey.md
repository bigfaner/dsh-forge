# Journey：专家卡片网格主视图 · 激活 → 四态渲染 → 检索过滤 → 卡片字段与页脚

**用户故事**：US12 面板浏览与检索（主视图 F1）；US6 禁用专家（面板呈现半）。

## 搭建前置条件

- 专家团插件已装载（client bundle 注册 main keyed `expert-squad` 面板 + panellist 行「专家团」）。
- 工作台已绑定工作区（workspace 路径就绪——面板取数缝 `/api/expert-squad/list?workspace=…&includeDisabled=true` 的取值来源）。
- 专家目录中存在启用与禁用的专家若干（含 project 层夹具档案与随包内置专家）。

## Happy Path

1. **用户在左栏点「专家团」行激活面板** → 预期：main keyed 槽呈现面板（标题「专家团」+ 搜索框 + 全部/启用/禁用三态过滤钮 + 召唤钮）；取数期间呈骨架卡片（中间态不落空态分支）；数据到达后切换为卡片网格。
2. **用户浏览卡片网格与页脚** → 预期：每张大卡可见状态灯、名称、英文标识 chip、岗位（禁用附「· 已禁用」整卡降透明度）、人设摘要（三行截断）、技能标签 chips、工具白名单 chips、更新时间页脚；面板页脚计数「N 位专家 · 显示 M」如实反映全量与过滤后数量。
3. **用户在搜索框输入关键字** → 预期：即时过滤（名称/英文标识/技能命中，大小写不敏感），网格与页脚计数同步收窄。
4. **用户切换状态过滤（启用/禁用）** → 预期：启用态只留启用卡；禁用态只留禁用卡（降透明 + 「· 已禁用」）；与搜索条件叠加为 AND 语义。
5. **用户清空搜索并切回「全部」** → 预期：网格恢复全量卡片与完整计数，无残留过滤态。

## 边界用例

1. **（引步骤 1）取数失败**：分叉前置 = list 路由报错/非 200 → 呈 ErrorBar（role=alert，含错误信息）与「重试」钮；点重试重新拉取，成功后恢复网格——错误态不误落空态分支。
2. **（引步骤 1）目录零专家**：分叉前置 = list 返回空数组 → 呈建档引导空态（「还没有专家——在会话里对 HR 说『招募一个专家』」），页脚「0 位专家」。
3. **（引步骤 3）关键词无命中**：分叉前置 = 搜索词不匹配任何名称/标识/技能 → 呈「无匹配专家」空态，页脚计数显示 0；清词后恢复。
4. **（引步骤 4）禁用卡呈现形态**：分叉前置 = 某专家被禁用（启停通道生效）→ 状态灯 off、岗位附「· 已禁用」、整卡降透明度；禁用态过滤下恰为其一。
5. **（引步骤 3）搜索与状态叠加**：分叉前置 = 搜索词与状态过滤同时生效 → 只呈现同时满足两条件的卡片（AND），页脚「显示」数同步。

## Journey Invariants

- 面板恒有头部（标题/搜索/三态过滤/召唤）与页脚计数骨架；网格区四态互斥：loading / error / 空 / 数据。
- 中间态禁落空态分支：取数中只呈骨架；错误只呈 ErrorBar——空态文案仅在列表确认为空时呈现。
- 过滤是纯客户端投影（零额外请求）；搜索与状态过滤恒 AND 叠加，页脚「N 位专家 · 显示 M」与呈现行集一致。
- 禁用卡信息不消失：禁用态在全量视图降透明呈现，档案可随时重新启用。
