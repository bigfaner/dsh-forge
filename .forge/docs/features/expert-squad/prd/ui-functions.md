# UI 功能：专家团管理面板

落位：`new-page` —— dsh desktop 工作台 `main` 槽 keyed 面板（单一入口模式，annotutor 先例）；委派、招募、追问一律走既有会话流（`existing-page:conversation`），不入面板。

v2 范围修订（用户裁决）：大卡片网格（信条/技能/白名单/委派统计）；详情 Dialog 查看/编辑双模式；无入职向导、无委派按钮——修改/委派经会话对话；**[+ 招聘（HR）] 按钮打开 HR 预设招聘对话**。

## 导航架构

- 工作台面板入口（`main` 槽 keyed 行）→ 专家团面板（卡片网格为主视图）
- 面板内仅一层：卡片网格 → 详情 Dialog（查看 ⇄ 编辑）
- 招募/修改/委派/追问经会话对话完成（主会话或 HR 预设）；面板头部留指引文案，不设招募/委派按钮

## F1 专家卡片网格（主视图）

```
┌────────────────────────────────────────────────┐
│ 专家团    [搜索____] [全部|启用|禁用] [召唤]    │
├────────────────────────────────────────────────┤
│ ┌───────────────┐ ┌───────────────┐            │
│ │● 代码评审员     │ │● 架构顾问      │            │
│ │ 资深评审        │ │ 方案设计       │            │
│ │ 信条三行截断…   │ │ 信条三行截断…  │            │
│ │ 技能标签        │ │ 技能标签       │            │
│ │ [review][tsc]  │ │ [design]      │            │
│ │ 工具白名单(强制) │ │ 工具白名单(强制)│            │
│ │ [read][edit]…  │ │ [read][grep]  │            │
│ │────────────────│ │───────────────│            │
│ │ 委派6次  更新昨日│ │ 委派3次 更新…  │            │
│ └───────────────┘ └───────────────┘            │
├────────────────────────────────────────────────┤
│ 4 位专家 · 显示 4                               │
└────────────────────────────────────────────────┘
```

- 大卡：状态灯、名称、岗位（禁用附「· 已禁用」且整卡降透明度）、信条三行截断、技能标签 chips、工具白名单 chips（等宽字体）、页脚 = 累计委派次数 + 更新时间
- [召唤] 按钮 → 打开 HR 预设招聘对话（消息式 Modal，建档回执后列表联动刷新）
- 搜索按名称/技能标签即时过滤；状态过滤（全部/启用/禁用）
- 四态：骨架卡片 / 空态（指引找 HR 招募）/ 错误条（重试）/ 数据
- 点击卡片 → F2 Dialog

## F2 详情 Dialog（查看/编辑双模式）

```
┌─ ● 代码评审员 ─────── [编辑] [✕] ─┐
│ 资深评审 · 启用中                  │
│ 信条：以最小改动为美…              │
│ 能力描述：承接代码评审任务，输出    │
│ 按严重度分级的意见清单（文件:行 +   │
│ 证据 + 建议）…                    │
│ 技能标签 [review] [tsc]           │
│ 工具白名单 [read] [edit] [grep]   │
│ ▸ 履历时间轴（2）        ←默认折叠 │
├──────────────────────────────────┤
│                        [禁用/启用]│
└──────────────────────────────────┘
```

- 查看态：meta / 信条 / **能力描述（专家具体能做什么）** / 技能 chips / 白名单 chips / 履历时间轴（置底默认折叠）——不暴露 frontmatter 技术细节
- 编辑态（点 [编辑]）：岗位 / 信条 / **能力描述** / 工具白名单与技能标签（**统一 chips 编辑器**：点击候选选用、点击已选移除、输入回车新增），预填；[保存] 校验（裸 `{{`、空岗位字段级报错）通过后写档案 + Toast 热刷新生效，回查看态
- [禁用/启用] 即时生效，状态灯与卡片同步；履历时间轴仅查看态呈现且默认折叠（履历由派发执行追加，不手编）

## 对话式操作（会话流，`existing-page:conversation`）

- 招募：对 HR 预设说「招募一个 XX 专家」→ HR 经管理工具建档 → 面板列表刷新可见
- 修改：对话或面板 Dialog 编辑，两路同写档案正本
- 委派与追问：主会话委派专家 → continuable 子会话执行 → 成果回显会话流 → 追问同上下文续聊

## 非功能（UI 侧）

- 视觉对齐 DESIGN.md 与官方组件（复用官方件，产品层只做组合注入）
- 样式注入遵循插件样式生命周期契约（factory 同步段或自管 disposer，二选一）
