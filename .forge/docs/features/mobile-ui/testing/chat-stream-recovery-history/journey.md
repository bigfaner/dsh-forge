# Journey：对话流式渲染 · 断线恢复 · 历史上翻分页

**用户故事**：US-2 流式对话（批次①）。
**Golden Path**：本旅程即特性黄金路径——用户打开会话 → 浏览历史 → 发送消息 → 看流式回复 → 弱网断线自愈，覆盖 session/message/交互三实体递进。

## 搭建前置条件（回放驱动）

- Playwright **mobile project**（390×844 触摸移动 UA）加载 mobile dist 单文件产物（`/remote/` 形态）。
- 数据面 = `page.route` 回放 `e2e/fixtures/mobile/`（1.1 录制产物）：`proxy-rpc.jsonl`（/remote/__rpc 通道交换）、`api-ref.jsonl`（官方 /api 参照腿）、`forge-stream.jsonl`（SSE timed 帧序，snapshot 首帧 + event 增量帧距保持）。零真实 host、离线可重复。
- 已配对会话打开于 `#/chat/:sessionId`；fixture 会话历史 ≥ 10 条（历史窗口常量 = 最近 10 条）。

## Happy Path

1. **用户打开会话** → 预期：默认仅加载最近 10 条消息，按投影层语义渲染（`user/message`→蓝右气泡、`assistant/chunk`→流式/折叠 thinking 卡、`tool/call+result`→折叠活动卡）；顶栏与输入行固定。
2. **用户向上滚动消息区到顶** → 预期：触发上翻分页，拉取更早一批历史消息并锚定插入（当前阅读位置不跳动，hasMore 锚耗尽前每翻一批追加一批）。
3. **用户继续上翻直至最早消息** → 预期：hasMore 锚耗尽后不再发分页请求，顶部出现历史起点（无加载指示器残留）。
4. **用户在输入行键入消息并发送** → 预期：用户气泡乐观上屏；请求经 `session.prompt` 通道发出（意图转发，手机端零校验）。
5. **assistant 回复流式到达（SSE 增量帧）** → 预期：回复气泡流式增长（live-chunk→settle 投影：chunk 增量实时拼接，`assistant/message` 终态帧覆盖为终稿）；仅消息区竖直滚动，触底时自动跟随。
6. **流式期间新消息在视野外到达** → 预期：出现「滚动到底」按钮带未读红点计数；点击后滚动到底、计数归零。
7. **SSE 连接中断（回放注入断流）** → 预期：出现断线覆盖层，对话引擎降级为轮询（退避 750ms→5s），期间用户仍可看到最近已 settle 消息。
8. **连接恢复（回放恢复 SSE 帧）** → 预期：覆盖层消失，自动重连续流（EventSource 原生重连 + 心跳判活），断线期间错过的消息经轮询/续流补齐，无需用户刷新。

## 边界用例

1. **（引步骤 1）历史不足 10 条**：分叉前置 = fixture 会话消息 < 历史窗口常量 → 打开会话一次加载全量，无「上翻加载」入口残留。
2. **（引步骤 2）分页请求在途时用户连点上翻**：分叉前置 = 上一批尚未返回 → 不重复发同锚请求，返回后单批插入、位置锚不重置。
3. **（引步骤 4）revision 守卫冲突**：分叉前置 = 发送在途时 SSE 带来更新快照 → 乐观气泡以服务端快照为准对齐，不出现重复消息或错序覆盖。
4. **（引步骤 5）chunk 帧高频到达**：分叉前置 = 多帧密集增量 → 经 rAF 合帧渲染（不逐帧 DOM 写入），settle 后文本与终态帧逐字一致（断言用户可见文本，不断言内部缓冲）。
5. **（引步骤 5）长消息/活动卡折叠**：分叉前置 = 单条消息超过折叠空间纪律阈值 → 默认折叠（摘要行 + ~3 行渐隐预览），展开就地撑开且调用段在结果段上方。
6. **（引步骤 7）轮询期间用户再发消息**：分叉前置 = 断线覆盖层在显 → 发送仍可发出（降级轮询不阻塞意图转发），恢复后回复照常流式续接。
7. **（引步骤 7）断线跨越多轮退避周期**：分叉前置 = 中断时长 > 5s → 退避封顶 5s 后周期稳定，不无限加速或停止；恢复后续流不重放已渲染消息。
8. **（引步骤 8）恢复后心跳判活**：分叉前置 = SSE 通道恢复但心跳帧缺席 → 引擎判定连接不健康，维持降级轮询；心跳帧到达后才切回流式（正确性由重连续流状态收口，轮询仅体验降级）。

## Journey Invariants

- **纯 view 层铁律**：全旅程手机端只发「用户输入与动作意图」（session.prompt）；投影、分页、恢复状态机全部为渲染侧行为，任何一步都不改变宿主循环行为。
- **投影一致性**：任一时刻消息流是 wire 事件序（snapshot/event）的确定性投影——live-chunk 被 settle（`assistant/message`）覆盖后不可回退为流式态；同屏无重复消息。
- **滚动主权**：仅消息区滚动；顶栏与输入行在流式、分页插入、覆盖层出现/消失全程位置固定。
- **恢复单向自愈**：断线→轮询→重连续流对用户透明（除覆盖层与退避期延迟）；恢复后消息序与不断线基准完全一致。
- **回放等价**：全部断言基于回放数据面的用户可见行为；1.11/1.29 真实通道落地后，同一旅程叙述直连通道形态回归（仅前置数据面替换）。
