# Journey：设置面板模型切换 · models 检索/分组/最近使用

**用户故事**：US-4 切换模型与推理等级（批次①）。
**回溯**：proposal v7 定稿（设置面板 + 唯一子视图模型列表）+ ui-functions F3。

## 搭建前置条件（回放驱动）

- mobile project 加载 mobile dist；`page.route` 回放 `e2e/fixtures/mobile/`：`sessionModelCatalog` 通道返回 100+ 多提供商模型目录（官方 model catalog 形状），`session/selectModel` 交换在 api-ref 参照腿；SSE 帧含当前会话模型。
- fixture 目录覆盖三类模型：支持推理档位（`reasoning.efforts` 非空）、不支持推理档位（缺省）、分属 ≥3 个提供商；手机页 localStorage 初始为空（最近使用从零积累）。

## Happy Path

1. **用户点 composer 滑杆设置钮** → 预期：最小化设置面板展开（无标题、无说明文本），仅见两行：模型行（当前模型值 + ›）与推理等级分段控件；选档即生效。
2. **用户点模型行 ›** → 预期：进入唯一子视图 `#/models` 模型列表：返回钮与搜索框同行（sticky）；目录按提供商分组折叠（组名 + 计数）；当前模型行右侧对勾。
3. **用户在搜索框键入模型关键词** → 预期：约 300ms 防抖后呈现过滤态扁平列表（命中项跨提供商去分组直列），面板高度恒定不抖动。
4. **用户清空搜索框** → 预期：恢复提供商分组视图，折叠状态与进入时一致。
5. **用户点选一个支持推理档位的其它模型** → 预期：选中态 = primary 边 + 7% tint；经 `session/selectModel` 通道转发选择意图后返回设置面板，模型行显示新模型，推理档位按新模型 `reasoning.efforts` 重新呈现。
6. **用户再次进入模型列表** → 预期：上一次使用的模型出现在「最近使用」置顶区（localStorage 持久化），当前模型对勾位置正确。
7. **用户切换推理等级档位** → 预期：分段控件选中档即生效（意图转发），无额外确认步骤。

## 边界用例

1. **（引步骤 2）选中不支持推理档位的模型**：分叉前置 = 目标模型 `reasoning.efforts` 缺省 → 返回设置面板后推理等级分段控件隐藏（不显示灰置禁用）。
2. **（引步骤 3）搜索无命中**：分叉前置 = 关键词不匹配任何模型 → 过滤态为空列表（无命中提示即可），面板高度恒定；清空后恢复分组视图。
3. **（引步骤 3）防抖窗口内连续输入**：分叉前置 = 300ms 内多次键入 → 仅以最终关键词发起一次过滤，不出现中间态闪烁。
4. **（引步骤 5）选择意图提交在途时重复点选**：分叉前置 = selectModel 请求未返回 → 面板呈现提交中状态，重复点击不并发多发；返回后模型行与最终回执一致。
5. **（引步骤 6）最近使用按配对域隔离**：分叉前置 = 同一手机页存在两个配对域的历史记录 → 各域只读各自 localStorage 最近使用集，互不串显。
6. **（引步骤 6）localStorage 缺席/清空**：分叉前置 = 首次访问或存储被清 → 最近使用区不渲染（或空态），目录分组视图正常，无报错覆盖层。
7. **（引步骤 7）当前模型档位越界恢复**：分叉前置 = 切换模型后旧档位在新模型 efforts 中不存在 → 档位回退到新模型默认档（或首档），不残留旧选中。
8. **（引步骤 1）preset 锁定会话**：分叉前置 = 会话模型被 preset 锁定（host 侧语义）→ UI 不展示锁定说明文本，切换意图由 host 裁决后以回执呈现（失败维持原值，无前端预检）。

## Journey Invariants

- **最小化面板不变式**：设置面板恒无标题/说明文本，仅模型行 + 推理档位两行入口；模型列表是唯一子视图。
- **纯视图层状态边界**：最近使用只存手机页 localStorage（按配对域隔离），零 host 改动；模型/档位变更本身是经通道转发的意图，落地由 host 裁决。
- **选中态全站统一**：模型行与档位选中态 = primary 边 + 7% tint；当前模型以对勾标识，选中态与对勾互不混淆。
- **检索不抖动**：防抖 ~300ms、过滤态扁平化、面板高度恒定——检索全程无布局跳变。
- **回放等价**：模型目录与选择回执均来自回放 fixtures 的用户可见行为；真实通道落地后同一旅程直连回归。
