# 用户故事：mobile-ui

角色来源（见 prd-spec 背景）：**手机端用户**（全部故事）、**桌面端用户**（宿主可见性）。每批独立真机验收。

## 手机端用户

### US-1 配对进入独立手机视图（批次①）

**当** 我用手机扫码配对进入 `/remote/` 时，**我要** 加载手机专属的受限视图，**以便** 获得为触屏设计的完整体验而非桌面裁剪分支。

- Given 已配对的手机 → When 打开 `/remote/` → Then 加载 mobile 独立单文件产物（非桌面裁剪分支），页面可交互。
- Given 桌面 web-app 存在于同一 host → When 检查产物引用 → Then 手机产物与桌面工程零模块引用。

### US-2 流式对话（批次①）

**当** 我在会话中发送消息时，**我要** 看到流式回复与断线自愈，**以便** 在弱网下也能持续对话。

- Given 打开的会话 → When assistant 回复中 → Then 消息流式渲染，仅消息区滚动，顶栏与输入框固定。
- Given 事件流断线 → When 连接中断 → Then 降级为轮询（退避 750ms→5s），恢复后自动续流，期间出现断线覆盖层。
- Given 打开会话 → When 历史加载 → Then 默认只加载最近 10 条，上翻到顶分页拉取更早消息。

### US-3 回答 ask 面板（批次①）

**当** 会话产生待回答问题时，**我要** 在分页面板逐题作答，**以便** 在小屏上准确完成多题输入。

- Given 存在多个 pending 交互 → When 打开 ask 面板 → Then 一屏一题，左上角显示序号/总数，可上一个/提交/下一个分页。
- Given 题目为单选 → When 点击某一选项 → Then 该选项即时呈选中态（圆形 radio，可改选）；提交经 `forge:proxy/user-questions-answer` 生效。
- Given 题目为多选 → When 勾选选项组合 → Then checkbox 方框对勾，任意组合可勾选/取消。
- Given 题目含 other 选项 → When 用户输入值 → Then 单选表示选中 other；多选表示额外选中 other（不影响已勾选项）。
- Given 多题 → When 分页作答 → Then 一屏一题、序号/总数、上一个/提交/下一个可用。

### US-4 切换模型与推理等级（批次①）

**当** 我调整会话模型时，**我要** 在最小化设置面板内直接切换，**以便** 快速变更而离开对话上下文。

- Given 点开 composer 滑杆设置钮 → When 面板展开 → Then 仅见模型行（当前值 + ›）与推理等级分段控件，选档即生效。
- Given 进入模型列表 → When 100+ 模型多提供商 → Then 检索（~300ms 防抖）、提供商分组折叠（计数）、最近使用置顶（localStorage，按配对域隔离）均可用；当前模型右侧对勾。
- Given 所选模型不支持推理档位 → When 选中该模型 → Then 推理等级分段控件隐藏。

### US-5 浏览抽屉会话列表（批次②）

**当** 我打开抽屉时，**我要** 按项目树浏览会话并看到未读，**以便** 快速定位目标会话。

- Given 打开抽屉 → When 列表呈现 → Then 项目树分组折叠规则同桌面端、不展示会话数量与归档、支持置顶。
- Given 存在未读会话 → When 查看徽标 → Then 双级未读徽标由手机端 localStorage 游标本地计算（打开会话/触底即推进游标并即时归零；零网络往返依赖，换设备未读重置可接受）。
- Given 点底部连接状态 → When 弹层展开 → Then 可查看详情并断开连接。

### US-6 发起新会话（批次②）

**当** 我在 hero 新建会话时，**我要** 默认落在当前分支/worktree 与突击模式并可乐观切换，**以便** 快速开工且不被强制切环境。

- Given 打开 hero → When 初始状态 → Then 默认模式=突击、分支=当前所在分支/worktree，不强制切换。
- Given 我选择切换分支 → When host 建会话守卫拒绝 → Then 弹确认框（选回/仍要切换；回执驱动，无预检调用），UI 无预检说明文本。

### US-7 查看任务进度（批次③）

**当** 有任务循环运行时，**我要** 通过悬浮球掌握进度并转发暂停/派发意图，**以便** 离开桌面也能推进任务。

- Given 任务运行中 → When 查看悬浮球 → Then 可拖拽、贴边收纳为透明半圆；点击展开任务浮层（标题=提案名/副标题=slug）。
- Given 任务卡运行中 → When 操作 → Then 显示暂停按钮；底部统一派发；状态徽标对齐桌面端状态集；无审批、无进度百分比。
- Given 存在多个运行中 run → When 查看任务浮层 → Then 顶部有 run 切换 chips，悬浮球只反映最近 running run。
- Given 数据 stale → When 查看操作按钮 → Then 按钮置灰，操作不可发。

### US-8 进入 worker 会话（批次③）

**当** 我点开任务卡时，**我要** 进入对应 worker 会话查看执行过程，**以便** 了解细节而不干扰宿主循环。

- Given one-shot worker → When 进入会话 → Then 只读，无法发送消息。
- Given continuable worker → When 进入会话 → Then 可发送消息（注入下一轮）；模式/worktree 只读继承自主会话；← 图标退出。

### US-9 阅读循环卡与文档（批次③）

**当** 消息流中出现循环哨兵与文档产出时，**我要** 看到结构化循环卡与可阅读的文档卡，**以便** 掌握循环脉络与产出内容。

- Given 桌面循环注入哨兵消息 → When 渲染 → Then 按 kind 显示色条循环卡；同 runId 非最新卡退化为单行 chip，时间线不重排。
- Given agent 产出文档 → When 消息流出现文档卡 → Then 显示类型徽标卡（文件名 + size）；点开进入全屏阅读页，html/md/csv 默认渲染可切纯文本，表格居中，txt 恒纯文本。

## 桌面端用户

### US-10 宿主守卫不受手机端影响（贯穿）

**当** 手机端发起任何动作意图时，**我要** 全部经 host 守卫校验后落地，**以便** 任务循环行为只由桌面端逻辑决定。

- Given 手机端转发暂停/派发/分支切换意图 → When host 处理 → Then 校验通过才执行，失败只回传确认框/提示数据；循环无任何因手机端操作而改变行为的路径。
