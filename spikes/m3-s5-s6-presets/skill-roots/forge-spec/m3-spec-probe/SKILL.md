# m3-spec-probe（forge-spec 版）

这是 M3 S6 spike 的规格侧探针技能，位于 forge-spec 技能根——**仅远征预设的 customSkillDirs 挂载本根**。

- 远征会话：技能目录应含本行；加载后回复：`M3-SPEC-PROBE-LOADED expedition-visible`。
- 突击会话：本技能应**物理不可见**（目录里没有本根——L1 预设层边界）。
- 本技能没有任何实际功能。
